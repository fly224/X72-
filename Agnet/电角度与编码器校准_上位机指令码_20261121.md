|---|---|---|---|---|
| 取写权限 | **30068** | 2 B `comm_auth=0, ctrl_auth=0` | 2 B：`status`+权限 | — |
| 封锁输出 | **30054** | 3 B：`cw`(u16) + `halt=1` | 2 B：`status`+`cw` 低字节 | — |
| 电流零点（Z/^ 的前置） | **30069** | 1 B：`action=4` | 2 B：`status`+`action` | 无（查 30090 `flags.bit0`） |
| **电角度校准** | **30069** | 1 B：`action=5` | 2 B：`status`+`action` | **30092 kind 8** |
| **编码器自校准** | **30069** | 1 B：`action=8` | 2 B：`status`+`action` | **30092 kind 7**（仅成功） |
| 中止所有辨识 | **30069** | 1 B：`action=14` | 2 B | — |
| 作业参数 | **30082** | 192 B | 2 B：`status`+`n_ok` | `30000(30082)` 可回读 |
| 判据/状态 | **30090** | 100 Hz 主动上报 | — | `flags` / `fault` / `mode` |

```
电角度：30068 → 30054(halt) →[cal=0 则 4]→ 30069(5) ── 30092 kind8 ──→ 自动落盘
编码器：30068 → 30054(halt) →[cal=0 则 4]→[z=0 则 5]→ 30069(8) ── 30092 kind7 ──→ 断电 >6 s
```

**一句话分工**：`30069` 只负责"启动作业"，`30092` 才是"结果"，`30082` 是"作业参数"，`30090` 是"能不能做"的判据。

## 1. 两条校准分别在做什么

### 1.1 电角度校准（action = 5，旧 ASCII `Z`）

- **目的**：测出 **极对数 `ratio`、方向 `dir`、电角度零点 `offset_rad`、机械零点 `zero_mech`**。
- **手段**：开环强制角按 120° 电角步进共 60 步，再正反各扫 2 圈做线性拟合（`motor_ident.c`）。
- **生效范围**（`servo_isr.c`）：

| 结果 | 是否进环路 | 说明 |
|---|---|---|
| `dir` | **是** | 写 `s_dir_sign`，速度/位置/电流全域生效 |
| `zero_rad` | **是** | θ 偏置 → Park、位置、齿槽查表 |
| `ratio` | **否** | 只记录；Park 用编译常量 `BSP_POLE_PAIRS` |

- **结果自动落盘**：成功后 0.5 s 内由 `Param_PersistTask1ms()` 写入（标志 `PS_FLAG_ZERO`），不需要额外 `action=1`。
- ⚠ **重做 Z 会改变坐标零点**，此前示教/保存的所有绝对位置全部失效。

### 1.2 编码器自校准（action = 8，旧 ASCII `^`）

- **目的**：让 MT6835 **芯片自己**算由磁铁偏差与安装偏心引起的非线性并写进芯片 EEPROM（INL 从 ±0.5° 降到 ±0.07°）。不占 CPU、不占 Flash。
- **手段**（`encoder_cal.c`）：开环拖动（d 轴电流 2.5 A，电角速度按 300 rad/s² 升频）→ 稳定 3 s 且"至少转了 1 圈"→ 拉高 `CAL_EN` → 每 100 ms 轮询 `0x113[7:6]`，直到芯片报成功（`3`）或失败（`2`）。
- **转速**：`AUTO_CAL_FREQ=0x03` 出厂默认，必须落在 **400~800 rpm**，固件取 **600 rpm**；64 圈 ≈ 6.4 s。
- **产物**：写进 **MT6835 内部 EEPROM**，不改固件参数。
- ⚠ **成功后必须给编码器断电 >6 s 再上电**（手册 9.2 第 5/6 步）。固件无法切断 3.3 V，只能由人操作。

## 2. 前置条件与联锁

| 条件 | Z(5) | ^(8) | 判据 / 做法 |
|---|:--:|:--:|---|
| 主机持写权限 | ✓ | ✓ | 先发 `30068 [00 00]`，否则 30069 回 `status=4` |
| 已封锁（`armed=0`、MOE=0） | ✓ | ✓ | `30054 cw=0x06, halt=1`；判据 `30090 flags.bit2(en)=0` |
| 无故障 | ✓ | ✓ | `30090 fault==0`；否则 `30069 action=3` 清故障，等 0.6 s |
| 电流零点已标定 `cal=1` | ✓ | ✓ | `30090 flags.bit0`；否则先 `action=4`（0.2 s） |
| 电角度已对齐 `z=1` | — | ✓ | `30090 flags.bit1`；否则先 `action=5` |
| 执行器空闲 | ✓ | ✓ | 与上一次辨识间隔 **≥0.75 s**（仲裁窗口 `ACT_GRACE_MS=500` + 250 收尾） |

补充约束：

- **动作 4~13 在 `en=1` 时统一回 `status=3`**，且不会执行；`action=14` 是唯一例外（中止）。
- **辨识期间不要发 `30019` / `30054` / `30056`**：它们会 `Act_Acquire` 抢执行器，把辨识打断成超时。
- 两条校准**不能并发**：第二条会拿到 `BUSY`（→ `status=2`）。
- `^` 会写芯片 EEPROM，**绝不能与其他辨识同时跑**。

## 3. 指令码详解

### 3.1 30068 AppPermission（2 B，crc_extra 134）

| 偏移 | 字段 | 值 |
|---|---|---|
| 0 | `comm_auth` | 0 = 主机持权 |
| 1 | `internal_auth` | 0 |

```python
lk.set_permission(0, 0)      # → 30068 [00 00]
```

不做这一步，所有写操作回 `status=4 (NO_AUTHORITY)`。

### 3.2 30054 AppControlWord（3 B，crc_extra 108）

| 偏移 | 字段 | 说明 |
|---|---|---|
| 0 | `cw` u16 | `bit0=CW_SWITCH_ON`；封锁时写 `0x06` 即可 |
| 2 | `halt` u8 | **`halt≠0` 无条件封锁并清 cw**，比写 `cw=0` 更稳 |

```python
lk.set_controlword(0x06, halt=1)
```

应答 2 B：`status` + `cw` 低字节（`bit0=1` 表示真的 armed）。

### 3.3 30069 SystemCmd（1 B，crc_extra **169**）

| 方向 | 载荷 |
|---|---|
| 下发 | `action` u8 @0 |
| 应答 | `status` u8 @0、`action` u8 @1（同 msgid，靠长度区分） |

`status`（`AppParamStatus_t`）：

| 值 | 名称 | 含义 |
|---|---|---|
| 0 | SUCCESS | **已入队**，不代表执行成功 |
| 1 | READ_ONLY | 只读参数 |
| 2 | OUT_OF_RANGE | 动作号非法，或子模块拒绝（BUSY / CAL / FAULT / PWM…） |
| 3 | WRITE_STATE_ERROR | **仍在闭环**（armed=1 或 MOE 开着），先 `halt=1` |
| 4 | NO_AUTHORITY | 先发 30068 |

动作号（`servo_cmd.h`，与 ASCII 单字符一一对应）：

| action | 含义 | 旧 ASCII | 耗时 | 结果 kind |
|---|---|---|:--:|---|
| 4 | 电流零点标定 | `C` | 0.2 s | 无（查 `cal` 位） |
| **5** | **电角度 / 极对数 / 方向** | **`Z`** | **~22 s** | **8** |
| 6 | 磁链 ψ / Kt | `+` | ≈13 s | 1 |
| 7 | R / L 注入 | `@` | ≈3 s | 2 |
| **8** | **编码器自校准** | **`^`** | **≤30 s** | **7（仅成功）** |
| 9 | 摩擦三点标定 | `$` | 13.3 s | 9 |
| 10~13 | 机械扫频 / 摩擦曲线 / 惯量 / 齿槽 | `( ) < }` | 10~28 s | 6/4/3/5 |
| 14 | 中止所有辨识 | — | <0.1 s | 无 |

```python
lk.action(5)     # 电角度校准
lk.action(8)     # 编码器自校准
lk.action(4)     # 电流零点（前置）
lk.action(3)     # 清故障（前置）
lk.action(14)    # 中止
```

### 3.4 30082 AppDebugParam（作业参数，crc_extra 218）

与这两条校准相关的只有两个 float 槽：

| 槽 | 名称 | 单位 | 范围（固件夹取） | 默认 | 作用 |
|---|---|---|---|---|---|
| **0** | `align_id` | A | 0.2 ~ 4.0 | **2.0** | Z 对齐注入的 d 轴电流 |
| **1** | `ol_vlim` | ×vbus | 0.02 ~ 0.60 | **0.06** | 开环电流环输出电压的**圆限幅**（Z 的 120° 步进、`^` 的开环拖动都受它约束） |

写：`30082` 192 B，float 写掩码 u32 @64（bit i = 槽 i 有效），应答 `[status, n_ok]`——**看 `n_ok`，不是 `status`**。

```python
lk.dbg_write(floats={"align_id": 3.0})   # Z 报 STUCK 时加大
lk.dbg_write(floats={"ol_vlim": 0.12})   # 开环拖不动时加大（0.10~0.15）
```

读：`30000 READ_PARAM(struct_id=30082)` → 设备回 192 B（float 0..63 / `nvalid_float@68` / `nvalid_int@72` / i32@128..）。回读是确认「改没改进去」的唯一办法。

### 3.5 30090 AppCtrlStatus（40 B，100 Hz）

| 偏移 | 字段 | 用途 |
|---|---|---|
| 0 | `cw` u16 | 真实控制字 |
| 2 | `mode` u8 | 1=位置 3=速度 4=力矩 12=MIT |
| **3** | **`flags`** | bit0 `cal`、bit1 `z`、**bit2 `en`**、bit3 `ff`、bit4 `dead`、bit5 `harm`、bit6 `ktc`、bit7 `cog` |
| 12 | `rpm` | 实测转速 |
| 16 | `pos` | 单圈机械角（rad） |
| 20 | `vbus` | 母线电压 |
| **36** | **`fault`** | u16 故障位（bit5 超速、bit6 母线过压…） |

判据就三句：`flags.bit2==0`（已封锁）、`flags.bit0==1`（cal）、`flags.bit1==1`（z，仅 `^` 需要）。

## 4. 结果帧 30092 AppIdentResult（40 B，crc_extra 92）

### 4.1 帧格式与接收规则

| 偏移 | 字段 | 类型 |
|---|---|---|
| 0 | `kind` | u8 |
| 1 | `ok` | u8（1 成功 / 0 失败） |
| 2 | `n` | u16（点数/步数/圈数） |
| 4 | `v[0..7]` | 8 × f32 |
| 36 | `resid` | f32 |

- **事件帧**：出结果那一拍起在 100 Hz 遥测流里**连发 5 次（约 50 ms）**，内容相同。
- 上位机要：① 用 `ts >= 下发时刻` 过滤旧帧；② 同 kind 只取第一帧；③ **不要轮询它**（发 30092 给固件没有意义）。

### 4.2 kind 8：电角度（Z）

**成功（ok=1，n = 步进次数）**

| v | 含义 | 单位 |
|---|---|---|
| 0 | `ratio` 极对数（实数） | — |
| 1 | `dir` | +1 / −1 |
| 2 | `off_deg` 电角度零点 | ° |
| 3 | `zero_deg` 机械零点 | ° |
| 4 | `n_step` | 步 |
| 5 | `n_sweep` | 圈 |
| 6 | `n_fail` | 失败步数 |
| 7 | `resid` | 拟合残差 |

**失败（ok=0，v[0] = 错误码）**

| v | 含义 | 单位 |
|---|---|---|
| 0 | **`err`** | 见 §7.1 |
| 1 | `dmech_avg` | mdeg（正常步进 ≈ **8571 mdeg** = 8.571°） |
| 2 | `dmech_min` | mdeg |
| 3 | `dmech_max` | mdeg |
| 4 | `ratio` | — |
| 5 | `n_step` | 步 |
| 6 | `n_fail` | 步 |
| 7 | `resid` | — |

> 失败也会推帧（2026-11-21 起）。`dmech_avg` 的三种典型形态：**几十 mdeg** = 基本没动（STUCK）；**≈4000** = 只走到一半；**min/max 相差数倍** = 打滑/失步。

### 4.3 kind 7：编码器自校准（^）

**成功（ok=1，n = 圈数）**

| v | 含义 | 单位 |
|---|---|---|
| 0 | `turns` 累计圈数 | 圈 |
| 1 | `rpm_avg` | rpm |
| 2 | `rpm_min` | rpm |
| 3 | `rpm_max` | rpm |
| 4 | `chip_status` 最后一次 `0x113[7:6]` | 0/1/2/3（3=成功） |
| 5 | `elapsed_ms` | ms |
| 6 | `ol_mode` | 本版恒 **1**（直接走开环拖动） |
| 7 | `target_rpm` | rpm（本版 600） |

**失败：不推 30092。** 这一版固件在失败分支只写 ASCII（已关闭），MAVLink 上完全静默 —— 上位机只能**等超时**，再结合 `30090 fault` 判断。这是已知缺口。

## 5. 完整下发序列

### 5.1 电角度校准（Python）

```python
import time, struct, sys
sys.path.insert(0, r"G:\FOC\驱动开发\PG_X72_CAN\host")
from mavlink_link import SerialLink

lk = SerialLink(); lk.connect("COM27", 921600); time.sleep(1.2)

def wait_ident(kind, timeout):
    """等本次新产生的 30092（kind 匹配），返回 ok/n/v[]。"""
    t0 = time.time()
    while time.time() - t0 < timeout:
        m = lk.last_msg.get(30092)
        if m and m["ts"] >= t0:
            raw = lk._payload_of(m)
            if raw and len(raw) >= 40 and raw[0] == kind:
                return {"ok": raw[1], "n": raw[2] | (raw[3] << 8),
                        "v": list(struct.unpack_from("<8f", raw, 4))}
        time.sleep(0.02)
    return None

# --- 前置：权限 / 清故障 / 封锁 / C ---
lk.set_permission(0, 0)
st = lk.ctrl_status()
if st["fault"]:
    lk.action(3); time.sleep(0.6)
lk.set_controlword(0x06, halt=1); time.sleep(0.4)
if not st["cal"]:
    lk.action(4); time.sleep(0.5)

# --- Z ---
a = lk.action(5)
assert a.get("ok"), "Z 被拒（返回 3 说明还在闭环）"
r = wait_ident(8, 50)
if r and r["ok"]:
    v = r["v"]
    print("ratio=%.2f dir=%+d off=%.2f° zero=%.2f° resid=%.2f"
          % (v[0], int(v[1]), v[2], v[3], v[7]))
else:
    if r:
        v = r["v"]
        print("Z 失败: err=%d dmech=%.0f/%.0f/%.0f mdeg"
              % (int(v[0]), v[1], v[2], v[3]))
    else:
        print("Z 超时：50 s 内没收到 30092 kind 8")
```

### 5.3 上位机（`servo-web/index.html`）实现对照

| 功能 | 函数 | 说明 |
|---|---|---|

## 6. 时间预算与超时

| 作业 | 实测/标称 | 建议主机超时 | 备注 |
|---|---|---|---|
| `action=4` C | 0.2 s | 3 s | 无 30092，查 `cal` 位 |

## 7. 失败排查

### 7.1 Z（kind 8，`v[0]`）

| 码 | 名称 | 含义 / 处理 |
|---|---|---|
| 1 | BUSY | 上一次还在跑，或 MOE 还开着 |
| 2 | CAL | 没做 C → `action=4` |
| 3 | FAULT | 启动前有故障 → `action=3` |
| 4 | PWM | MOE 打不开（查硬件/驱动故障） |
| 5 | TIMEOUT | 总时长超限 |
| 6 | **STUCK** | 转子几乎没动：`align_id` 太小 / 相线断 / 卡死 → 2.0 → 3.0 A |
| 7 | **RATIO** | 极对数不合理（非整数或超范围）：方向反了、磁钢松动 |
| 8 | FAULT_RUN | 运行中触发故障（多为过流） |

### 7.2 ^（错误码只在内部/ASCII 里，MAVLink 看不到）

| 码 | 名称 | 含义 / 处理 |
|---|---|---|
| 1 | BUSY | 已有辨识在跑 |
| 2 | CAL | 没做 C |
| 3 | ZERO | 没做 Z |
| 4 | FAULT | 有故障 |
| 5 | PWM | MOE 打不开 |
| 6 | **SPEED** | 3 s 内没转够 1 圈 → `ol_vlim` 提到 0.10~0.15 / 检查抱闸 |
| 7 | TURNS | 圈数到不了（堵转 / 限流） |
| 8 | **CHIP** | 芯片报失败（`0x113[7:6]=0b10`，即 `chip_status=2`）→ 转速是否稳定在 400~800、磁铁是否偏心过大 |
| 9 | TIMEOUT | 30 s 超时 |

### 7.3 现场判读顺序

1. `30069` 返回几？`3` → 先 `halt=1`；`4` → 先 `30068`；`2` → 看子模块（BUSY/CAL/FAULT）。
2. 有 30092 → 看 `v[0]`；
3. 没 30092 → ① 是否 45 s 内没结束；② `30090 fault` 是否置位（`bit5` 超速 / `bit6` 过压最常见）；③ 电机是否真的在转（`30090 rpm` / 30040 `enc_sum`）。

## 8. 落盘、坐标系与断电

| 项 | Z | ^ |
|---|---|---|
| 结果存哪 | 固件参数页（`dir/zero/ratio`，自动 0.5 s 落盘） | **MT6835 内部 EEPROM** |
| 断电要求 | 无 | **成功后必须断电 >6 s 再上电** |
| 对坐标的影响 | **零点改变 → 所有示教/绝对目标失效** | 无（只改线性度） |
| 是否受 `action=1` 影响 | 不需要（自动存）；急停前可手动补一次 | 不受影响（不写固件 Flash） |
| 重做前置 | `cal=1` | `cal=1` + `z=1` |

## 9. 上位机实现要点（坑清单）

1. **`crc_extra` 必须对**，否则整帧被当坏帧静默丢弃：`30068=134`、`30054=108`、`30056=26`、`30069=169`、`30082=218`、`30092=92`、`30090=90`、`30000=43`。
2. **解析步长是 `12 + len`**（10 头 + payload + 2 CRC），写成 `14 + len` 会失步，现象是"帧数 0"。
3. **30092 连发 5 帧**：按时间戳过滤 + 同 kind 只取第一帧，别把 5 帧当成 5 次结果。
4. **`status=0` 只代表入队**：Z 的成败必须看 `30092 kind 8`；`^` 失败没有帧，只能靠超时。
5. **动作间隔 ≥0.75 s**：紧跟会拿到 `BUSY`，与参数错误无法区分。
6. **辨识期间不要发 30019 / 30054 / 30056**：会抢执行器。上位机应在动作期间把控制面板的保活停掉（`servo-web` 用 `guardIdent()` 做互斥）。
7. **不要用 ASCII 的 `C/Z/^` 与 MAVLink 的 `30069` 混着发**：两套入口进同一个 `do_align()/EncCal_Start()`，第二条会拿到 `BUSY`；调试页的 `^` 只作应急。
8. **`ratio` 不进环路**：算出来只用于核对；Park 仍用编译常量 `BSP_POLE_PAIRS`。要改极对数必须重编译。
9. **Z 报 STUCK 先看三相电流**：某相明显偏小是相线断，会伪装成"电流不足"。
10. **`^` 成功后立刻使能是无效的**：芯片参数要重新上电才加载，期间别急着跑控制。
