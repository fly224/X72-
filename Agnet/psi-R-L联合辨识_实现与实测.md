# ψ / R / L 联合在线辨识：实现与实测

> 目标：消除折算惯量 `J` 与磁链 `ψ` 的强耦合
> 代码：`Board/motor_flux_ident.c` / `.h`（约 480 行）
> 命令：`+`
> 整理时间：2026-11-16

---

## 1. 要解决的问题

折算惯量由转矩反算：`T = Kt·iq = 1.5·p·ψ·iq`，所以 **`J ∝ 1/ψ`**。

之前 J 用的是 `Kt = 0.0936`，而 ψ 是从"3000 rpm 电压饱和点"反推的 4.455 mWb——那是个**间接**值，且模型里写的是 7.593 mWb，两者差 41%。所有跟转矩有关的东西（J、加速度前馈系数 `J/Kt`、力矩换算）都带着这个不确定性。

**41% 的误差意味着 `J` 可能是 5.3e-5 也可能是 9.1e-5**，加速度前馈的 0.7 折扣就是在赌这个。

---

## 2. 为什么不能"断电滑行测反电势"

最干净的办法是断开 PWM 让转子自由滑行，用示波器量相电压 = BEMF，此时 `ψ = V_peak/(p·ωm)`，不依赖 FOC 本身。

**但硬件不支持**：
- `telemetry_tx.c:217` 的 `ua/ub/uc` 是 `(duty−0.5)·vbus` 的**指令值**，不是实测
- 网表里只有 `VBUS_ADC`（母线分压），**没有三相电压分压网络**
- 电流采样点在**下桥分流电阻**上，三相浮空时那里没有电流，测不到 BEMF

要做就得改板：三路分压 + 钳位，接到空闲的 ADC 通道。

---

## 3. 关键洞察：空载转速扫描无法分离 R 和 ψ

第一反应是用稳态 dq 方程做多转速最小二乘：

```
vd = R·id − ωe·L·iq
vq = R·iq + ωe·L·id + ωe·ψ
```

空载、id=0 时，`vq = R·iq + ωe·ψ`。扫几个转速点，理论上两个未知两个方程。

**但这是共线的，原理上解不出来**：

空载时 iq 是被摩擦"锁"在 ωe 上的（`iq = 摩擦曲线(ωe)`），近似 `iq ≈ a + b·ωe`。代入：

```
vq = R·(a + b·ωe) + ωe·ψ = R·a + (R·b + ψ)·ωe
```

**只能解出 `R·a` 和 `(R·b + ψ)` 两个组合**，R 和 ψ 在里面纠缠着。不管扫多少点，方程组的秩都是 2 而不是 2 个独立未知。

---

## 4. 解法：用 id 作为独立的第二个维度

`id` 是唯一能独立给定、又不与 ωe 相关的量。在**同一个转速**下扫 id：

```
∂vd/∂id = R                    ← R 直接出来，与摩擦/iq 无关
∂vq/∂id = ωe·L                 ← L = 斜率/ωe
```

两个斜率都只依赖 id，**不受 iq 与 ωe 的共线性影响**。有了 R 和 L，再用任意一个点的 vq 解 ψ：

```
ψ = (vq − R·iq − ωe·L·id) / ωe
```

### 工况设计

| 组 | 转速 | id 序列 | 用途 |
|---|---|---|---|
| 主 | 1000 rpm（ωe=1466） | 0 / −1 / −2 / −3 A | R（vd 斜率）、L（vq 斜率）、ψ（各点平均） |
| 副 | 300 rpm（ωe=440） | 0 / −2 A | ψ 交叉验证 |

**为什么主转速必须 1000 rpm**：`vq` 对 id 的斜率 = `ωe·L`。

| 转速 | ωe·L（L=87 µH） | id 扫 3 A 的总变化 |
|---|---|---|
| 300 rpm | 0.035 V/A | 0.105 V ← 与死区电压同量级，测不准 |
| 1000 rpm | 0.127 V/A | **0.382 V** ← ADC（15 mV/LSB）能分辨 |

**为什么副转速 300 rpm 仍能验 ψ**：`vq` 里 `ωe·ψ` 项在 300 rpm 是 `440 × 0.0043 = 1.9 V`，而 `R·iq` 只有 0.05 V——**ψ 的贡献占 97%**，很容易测。它不参与求 R/L，只做独立性检查。

## 5. 实测结果

```
[CMD] FI ok pts=6
[FI] 0 id=-0.00 iq=0.48 vd=-0.00 vq=6.55 we=1466.08
[FI] 1 id=-1.00 iq=0.56 vd=-0.51 vq=6.42 we=1466.08
[FI] 2 id=-2.00 iq=0.63 vd=-0.79 vq=6.28 we=1466.08
[FI] 3 id=-3.00 iq=0.70 vd=-1.03 vq=6.16 we=1466.08
[FI] 4 id=0.00  iq=0.25 vd=0.04  vq=2.04 we=439.82
[FI] 5 id=-2.00 iq=0.33 vd=-0.75 vq=1.95 we=439.82
[CMD] FI R=327.84mohm L=89.07uH psi=4.333mWb
[CMD] FI Kt=0.0910 Ke=0.06V/(rad/s) r2=0.965/0.999 dev=1.85% moe=0
```

### 5.1 ψ 得到独立交叉验证

| 方法 | ψ | Kt | 独立性 |
|---|---|---|---|
| **`+` 联合辨识** | **4.333 mWb** | **0.0910** | id 扫描 + 两转速回归 |
| 3000 rpm 电压饱和反推 | 4.455 mWb | 0.0936 | `vq = ωe·ψ`（假设 R·iq 可忽略） |
| 模型 `three_loop_params.m` | 7.593 mWb | 0.1595 | 厂家标称/初始值 |

**前两者差 2.7%，且方法完全独立**——一个用低速 id 扫描，一个用高速电压饱和点。模型值偏大 75%，可以确认是错的（可能是相/线电压口径混淆，或峰值/有效值混淆）。

**`dev = 1.85%`**：1000 rpm 组和 300 rpm 组各自算出的 ψ 只差 1.85%，这是很强的自洽性证据（两组 ωe 差 3.3 倍，R·iq 项占比差 3.3 倍）。

### 5.2 L 与注入法一致

| 方法 | L | 说明 |
|---|---|---|
| `+` 联合辨识 | **89.07 µH** | 实际工作点、含饱和 |
| `@` 单频注入 | 80.1 µH @1.55 A | 小信号、d 轴 |
| 模型 | 113.5 µH | — |

两者差 11%，都在 80–90 µH 区间。`r2 = 0.999` 说明 vq 对 id 的线性度极好。

### 5.3 R 偏低 18%，原因是死区

| 方法 | R |
|---|---|
| `@` 虚拟角锁死 | **400 mΩ** ← 推荐用这个 |
| `+` 联合辨识 | 327.84 mΩ |
| 万用表 | 420 mΩ |

`vd` 通道的信噪比不够：`id` 从 0 到 −3 时 vd 只变化 1.03 V，而**死区电压约 0.18 V（占 17%）**。更麻烦的是死区不随电流线性变化（小电流时占比大），导致 `vd` 对 `id` 是**凹函数**，回归斜率被拉低。

分段斜率可以看清这一点：

| 区间 | 局部斜率 | 折算 R |
|---|---|---|
| id 0 → −1 | 0.51 | 0.520 |
| id −1 → −2 | 0.28 | 0.289 |
| id −2 → −3 | 0.24 | 0.249 |

斜率单调下降 = 典型死区+饱和特征，不是纯电阻行为。

**结论：R 用 `@`（虚拟角锁死、ωe=0、只用 |v|/|i| 比值、死区可标定）。`+` 的价值在 L 和 ψ。**

## 7. 踩的四个坑

### 7.1 超速判据在降速时误触发（最有价值）

第一次跑 `+`，副组一开始就 `f=0x20`（超速）。

诊断打出：`f=0x20 om=104.01 wref=31.42 se=1 ce=0`

`wref=31.42` 是 300 rpm 的 rad/s。**从 1000 rpm 切到 300 rpm 时，给定瞬间变成 31.4，而门限 `1.5·|ref|+10 = 57` 立刻收紧，电机还在 104 rad/s 上正常减速 → 被判超速。**

这不是辨识模块的问题，是**超速判据本身的设计缺陷**：判据的目的是抓"失控加速"，不是抓"正常减速"。

修法两层：
1. **给定幅值峰值保持**：`s_spd_wpeak` 升速立即跟上、降速按 `0.9999/拍` 缓慢回落（10 s 衰到 37%）。门限跟"最近到过的最高转速"走。
2. **8 拍消抖**：连续 0.4 ms 超限才判故障。真失控时 0.4 ms 只多跑 2 rad/s，不影响兜底。

第一次只加了峰值保持、衰减系数写 `0.999`——**1.2 s 就衰到新给定水平**，还是误触发。改成 `0.9999` 才对。

### 7.2 R 的 iq 混淆项

`vd = R·id − ωe·L·iq`，但 `iq` 随 `id` 变（0.48 → 0.70 A，因为 id 注入改变了磁链），所以：

```
∂vd/∂id = R − ωe·L·(∂iq/∂id)
```

必须扣掉：`R = k_vd + ωe·L·k_iq`。这一项在 1000 rpm 是 0.009 Ω（相对 0.34 Ω 只有 2.7%），但不扣会系统性偏大，而且误差方向随工况变，看起来像"R 有时准有时不准"。

### 7.3 齿槽反向一个点都没采到

`}` 的第一版结果：`fwd=1.067 rev=1.067` 完全相同。

根因：反向 SETTLE 结束时**重新取了 `s_cog_th0`**，导致反向的 `rel = (th0+2π) − θ` 起始值就是 2π，**立刻满足"转完一圈"**直接退出，7.2 s 只跑了正向圈。

修法：**分箱用角度、进度用另一个量**
- 分箱：`br = θ − θ0`（θ0 恒为正向下标那一点，两向共用）
- 进度：正向 = `br`，反向 = `2π − br`

### 7.4 扫频"高频测不到"其实是转子没静止

改完 8 拍差分后第一次测，141 Hz 以上全是 `0.0000`、相位恰好 `72.00°`（正是补偿量）——说明 `atan2(0,0)` 退化，速度累加项是 0。

加诊断打出 `wmean / wamp / iamp` 后重测（先 `C` 标定让电机停住），结果全部正常：

```
[CMD] MI end wmean=2.7934 wamp=4.3478 iamp=0.2046
```

**`iamp=0.2046` 与给定的 0.2 A 吻合**——iq 解调是对的。上一次失败是因为刚跑完 `+`（电机在 1000 rpm 滑行），扫频启动时转子未静止。

**教训：所有机械辨识前必须 `C`（电流标定会等 200 ms 且要求静止），或者至少 `D` 后等 2 s。**

## 9. 局限

1. **R 有 18% 系统性偏差**（死区），用 `@` 的值。
2. **只测 Ld**，`Ld = Lq` 是表贴式假设。分离 Lq 需要 id/iq 双轴扫描或高频注入的二次谐波。
3. **需要 1000 rpm 才能测准 L**，这个转速在 30 V 母线下没问题（上限 2500 rpm），但若在低压台上调试（<15 V）可能上不去。
4. **id 注入 −3 A 会产生弱磁**，绕组铜损 3²×0.4 = 3.6 W，连跑 9 s 约 32 J，温升可忽略，但不适合连续重复跑。
5. **ψ 的 3% 不确定度主要来自 R 的不确定度**（`ψ = (vq−R·iq−ωe·L·id)/ωe` 里 R·iq 项），若 R 修正到 0.40，ψ 会降到约 4.28 mWb。
