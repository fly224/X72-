# 重复定位精度：20 圈单向 ×100 与 90° 摆动 ×100

日期：2026-11-18
对象：X72 关节模组（STM32G474 + MT6835 21 bit，母线 30.77 V，空载）
链路：手写位置环（梯形规划 + P25 + 速度前馈）→ 手写速度环（2 kHz）→ 手写电流环（20 kHz）

---

## 结论

| 项目 | n | 平均偏差 | 重复性 σ | 极差 | ±3σ |
|---|---|---|---|---|---|
| **正向 +20 圈** | 100 | **+3.7″** | **21.3″** | 103.4″ | 64.0″ |
| **反向 −20 圈** | 100 | **+9.8″** | **17.2″** | 83.4″ | 51.5″ |
| **90° 摆动（冷态，开机 15 min）** | 100 | +3.0 / −0.7″ | 19.2 / 18.1″ | 104.8 / 103.3″ | 57.7 / 54.4″ |
| **90° 摆动（热态，连续运行 50 min）** | 100 | −4.2 / +5.0″ | **8.6 / 7.6″** | 39.2 / 39.7″ | 25.7 / 22.7″ |

单位角秒，1″ = 4.848 µrad。

**回答"是否停在同一角度"**：不是完全同一点，而是随机散布。
- **冷态**：σ ≈ 17–21″（83–103 µrad ≈ 0.005–0.006°），±3σ ≈ ±0.018°
- **热态**：σ ≈ 8–9″（39–44 µrad ≈ 0.002°），±3σ ≈ ±0.007°

同一台机器、同一套参数，**热态重复性比冷态好一倍以上**，机理见 5.5。
20 圈与 90° 摆动的 σ 处于同一水平，说明**行程长度不是误差来源**。

**空程（反向间隙）**：
- 正反 20 圈均值差 = 3.7 − 9.8 = **−6.1″**
- 90° 双向差 = −3.7″（冷）/ **+9.2″**（热）

均在 ±10″ 内，**电机侧无可测空程**。减速器背隙在输出端，编码器装在电机侧，本测试量不到。

## 一、测试条件

| 项 | 值 |
|---|---|
| 母线电压 | 30.77 V（全程 30.63–30.90） |
| 位置环参数 | Kp=25 1/s，Vmax=25 rad/s，Amax=200 rad/s²，梯形规划 |
| 速度环 | 2 kHz，7 段增益调度（本工况落在 0.583 / 0.0408） |
| 电流环 | 20 kHz，Kp=0.5341，Ki·Ts=0.12566 |
| 齿槽前馈 | 开启（n=128，pp=1.13 A，ph=145.05°） |
| 测量基准 | 30040 帧 `enc_sum`（int64，2²¹ 脉冲/圈），Python double 换算 |
| 采样 | 每个到达点取稳态后 8 帧均值（100 Hz 遥测） |
| 单程耗时 | 20 圈 5.5 s；90° 0.18 s |

每项流程：从 A 出发单向走到 B（记录 B），再返回 A，重复 n 次。
**单向重复性要求每次从同一方向、同一段距离接近目标**，所以必须回程。

## 二、过程中发现并修复的 5 个固件缺陷

这一轮最大的产出其实不是精度数字，而是把三个"看起来像硬件/整定问题、实际是软件"的坑挖了出来。

### 2.1 `CMD_NUM_BUF = 8` 只能存 7 个字符（阻塞级）

`P130.5027`（8 字符）第 8 个字符触发 `cmd_num_feed` 的"非法字符 → 整条命令作废"分支，
目标被静默丢弃。现象极具误导性：

```
[CMD] POS on: tgt=4.8390 ... moe=1        <- 看起来使能正常
pos st=3(DONE)  e=-0.000                   <- 看起来已到位
enc 恒 -0.000                              <- 电机纹丝不动
```

而 `P30.0000`（7 字符）精确到位到 29.9999。
20 圈目标 `P131.5827` 正好 8 字符，所以 100% 失败，且没有任何错误提示。

修复：`CMD_NUM_BUF` 8 → 16（ZI +8 B），并把注释写清"必须能装下最长合法数值"。

### 2.2 `S` 命令不刷新 deadman（阻塞级）

deadman（2 s）只被动作命令续期，`S` 是只读查询。20 圈单程 5.5 s 远超 2 s，
中途被 `do_disable("deadman 2s")` 封锁。

修复（上位机侧）：保活改为**每 1.35 s 重发同一目标**。重发只置 `s_restart`，
规划器用 `profile_start(p_meas, v_meas)` 以实测位置与速度重新起步，
目标不变、速度连续——实测 8.5 s 轨迹中速度稳定在 24.5 rad/s，无停顿。

### 2.3 `POS_ERRMAX_DFLT = 1.5 rad` 太小

纯 P 环起动时 `p_ref` 以 Vmax 前进，而电机要等误差累积到速度给定足够克服静摩擦才动，
起动瞬态跟随误差实测 **4–5 rad**，1.5 会被冲破。ERR 后 `PosLoop_Step` 返回 0，
但 `st` 可能停在 DONE、`e≈0`，与"给定没生效"无法区分。

修复：1.5 → **6.0 rad**（仍能抓堵转：堵转时误差会到几十 rad）。

### 2.4 位置环下温度降额失效

`servo_isr.c:1740` 判据为 `(s_spd_en ? s_spd_iqmax : s_cur_iq_max)`。
位置环 `s_spd_en=0`、`s_pos_en=1`，于是用 5 A，而速度环输出已限 3 A——
`derate > 0.6`（GaN 约 85–93 °C 窗口）时 `lim = derate×5 > 3`，**完全不降额**。

修复：条件改为 `((s_spd_en) || (s_pos_en))`。

### 2.5 MIT 运行中 `>iq` 与 `T/U/V` 静默失效

ISR 中 MIT 优先级高于 `s_cur_iq_ref` 与 `CurStep_Refs`，回显 "updated" 但实际被覆盖。

修复：`do_current` / `do_step` 增加 `Servo_IsMit()` 拒绝分支。

## 三、测量方法学上的三个坑

### 3.1 `enc_sum` 与控制器 `theta_multi` 差一个常量

`enc_sum`（30040）是相对**上电点**的累积；控制器位置环用 `theta_multi`（带绝对零点）。
本次差 **4.8390 rad**。目标必须用 `P` 回显的 `tgt=` 作基准再加增量，
否则会出现"目标 +20 圈、实际 −4.84 rad"的错觉。

### 3.2 控制器位置是 float，多圈累积会吃掉精度

`|θ|` 越大 ulp 越大：

| 位置 | float ulp |
|---|---|
| 1.57 rad | 0.1″ |
| 125.7 rad（20 圈） | 1.6″ |
| 2910 rad（463 圈） | ~200″ |

曾累积到 463 圈，此时 `P` 命令直接返回 `tgt=nan`。
**测试前必须先归零**，把工作区间压在 ±126 rad 内。

### 3.3 `P` 空回车是"保持当前位置"，不是查询

`cmd_num_apply` 里 `s_num_n==0` 且 `s_num_tgt==CMD_NUM_POS` 时直接
`do_pos(1, 0)`（保持），后面的查询分支是死代码。
所以每次 `P\r` 都会把目标重设为当前——测量脚本里要清楚这一点。

## 五、分析

### 5.1 为什么是 8–21″，而历史记录是 5.6″

历史 `位置环_精度与重复定位精度.md` 记的是 **σ = 27 µrad（5.6″）、双向差 +48 µrad**，
本次冷态 83–103 µrad、热态 39–44 µrad。差异不在控制参数（同一套 Kp=25 / Vmax=25），而在**测试几何**：

1. 历史测试在单一小范围（±1.57 rad）内往返，**每次都停在同一齿槽相位**；
2. 本次 20 圈跨越 20 个完整机械周期，停止点落在任意齿槽/摩擦相位上，
   而齿槽转矩峰峰 1.13 A（是 30 rpm 运行电流的 9 倍），不同相位的"锁定力"不同；
3. 热态 8.6″ 已经接近历史 5.6″ 的水平，说明剩下的差距主要是热态差异 + 跨相位。

### 5.2 散布是白噪声，不是漂移

- 正向：前半 σ 21.4″、后半 σ 20.9″，前后 10 次均值漂移 −1.8″
- 反向：lag-1 自相关 0.03
- 正向：lag-1 自相关 0.11

**单次测试内（20 min、100 次）逐次独立、无累积漂移。**
（跨测试之间存在热态改善，见 5.5；那是分钟级的摩擦状态变化，不是位置累积误差。）

**这意味着单次测试内的 σ 不是靠"多等一会儿"能压下去的**，它是纯 P 位置环 + 干摩擦系统的固有极限。

### 5.3 误差来源分解

| 来源 | 估算 | 依据 |
|---|---|---|
| 控制器 float 量化 | 1.6″ | 125.7 rad 处 ulp |
| 编码器量化 | 0.04″ | 2²¹/圈，8 帧平均后再降 √8 |
| 摩擦锁定（主因） | 8–18″（热/冷） | 关齿槽后 σ 仍 16–17″ |
| 齿槽前馈残差 | ~2″ | A/B 差 |

摩擦锁定的机理：位置环是**纯 P**（`v_cmd = v_ff + Kp·e`，无积分），
停止后 `v_cmd = Kp·e`。要让电机继续微动，`Kp·e` 产生的速度给定必须大到让速度环输出
超过静摩擦（约 0.15 A）。令 `Kp=25`、速度环 `Kp=0.583`：

```
e_dead = I_fric / (Kp_spd · Kp_pos) = 0.15 / (0.583 × 25) = 0.0103 rad ≈ 2130″
```

即误差小于约 0.01 rad 时位置环**根本无法产生有效修正**，实际停点由"停下来那一刻
摩擦齿合在哪"随机决定。实测 σ 18″ 远小于这个死区，说明速度环积分在兜底，
但兜底的过程本身带随机性。

### 5.4 空程

正反均值差 −6.1″、90° 双向差 −3.7″（冷）/ +9.2″（热），均在 ±10″ 内。
**电机侧无可测空程**（编码器直连电机轴）。

### 5.5 热态把 σ 降了一半

同一工况两次测量（间隔约 35 min 连续运行）：

| 状态 | A σ | B σ | A range | B range |
|---|---|---|---|---|
| 冷态（开机 15 min） | 19.2″ | 18.1″ | 104.8″ | 103.3″ |
| 热态（连续 50 min） | 8.6″ | 7.6″ | 39.2″ | 39.7″ |

**机理**：位置环是纯 P，停止后要靠速度环积分把 `Kp·e` 累到足以克服静摩擦（见 5.3）。
冷态润滑脂黏度高、静/动摩擦差大（Stribeck 曲线陡），
"停在哪儿"由摩擦齿合位置的随机性主导；热态润滑脂变稀、静摩擦下降，
同样的位置误差更容易推动电机微调，停点因此更确定。

**这与驱动板温度无关**（GaN 仅 26→34 °C，远未进入降额区），
而是电机本体/减速器的热态。可惜电机 NTC 恒读 2.0 °C（见上一轮报告），
本次无法给出绕组温度，只能以"连续运行时长"作近似。

**工程含义**：重复定位精度指标必须标注热态。冷机第一次下发的定位指令，
散布会比稳定运行后大一倍。若应用对首件精度敏感，建议上电后先空跑数次预热。

## 六、改进建议（按性价比排序）

| 措施 | 预期 | 代价 |
|---|---|---|
| 位置环加**积分项**（或速度前馈残差积分） | 消除 0.01 rad 死区，σ 有望降到个位数角秒 | 需整定 Ki，过大会在到位时超调/爬行 |
| 末端**降低接近速度**（最后 0.01 rad 限到 1 rad/s） | 减小停止冲击，σ 改善 | 定位时间 +0.1~0.2 s |
| 位置环 Kp 25 → 40 | 死区按比例缩小 | 需重测稳定性，可能激发 200–400 Hz 振铃 |
| 齿槽前馈保留 | 消除 27″ 静态偏置 | 已实现，无额外代价 |
| 输出端加编码器 | 才能真正评估减速器背隙 | 硬件改动 |

**当前状态可用于**：需要 ±0.02° 量级重复定位的关节应用。
若要求 ±0.005°，必须先给位置环加积分。

## 七、复现方式

```bash
python param_probe.py COM27 --tag cold        # 可选：先做参数基线
python pos_rep_multi.py COM27 --test sway --n 100
python pos_rep_multi.py COM27 --test fwd  --n 100 --revol 20
python pos_rep_multi.py COM27 --test rev  --n 100 --revol 20
```

脚本会自动：检查故障 → 使能位置环 → 归零（|θ|>5 时）→ 往返测试 →
每 1.35 s 重发目标保活 → 落盘 CSV → 输出统计。

数据文件：`pos_rep_fwd.csv`、`pos_rep_rev.csv`、`pos_rep_sway.csv`，
日志：`pos_fwd100.log`、`pos_rev100.log`、`pos_sway100.log`、`pos_sway100_nocog.log`。
