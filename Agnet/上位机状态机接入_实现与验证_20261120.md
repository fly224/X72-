## 三、固件 bug：`ServoCmd_ActiveMode()` 判定顺序

原实现：

```c
if (Servo_IsMit())        return 12;
if (Servo_IsSpeedMode())  return 3;    // ← POS 也命中
if (Servo_IsPosMode())    return 1;
```

`Servo_IsSpeedMode()` 返回的是派生量 `s_spd_en`，而 **POS 会派生 spd_en**（位置环本身串速度环）。于是位置模式下 30055 的 `active_mode` 报 **3(VEL)**，上位机镜像与示波器都会显示错。

已改为直接用真值，彻底绕开派生关系：

```c
switch (Servo_GetSrc()) {
case SERVO_SRC_MIT: return 12;  case SERVO_SRC_POS:    return 1;
case SERVO_SRC_SPEED: return 3; case SERVO_SRC_TORQUE: return 4;
default: return 0; }
```

## 四、实机联调受阻（当前状态）

### 4.1 现象

| 通道 | 现象 |
|---|---|
| 30025 / 30027 / 30040 遥测 | **正常**，905 帧 / 3 s，seq 步长全为 1（**没有周期性复位**） |
| ASCII 命令（S / K） | **完全无回显**，连发 3 次、灌 400 字节冲帧状态机均无效 |
| MAVLink 写命令 ACK | **全部收不到**（`last_ack` 全 None，抓包里只有三条遥测） |
| 电机 | 使能命令发出后不转（`iq_ref` 恒 0、`theta` 不变） |

### 4.2 已排除

- 不是串口占用：停掉上位机进程后同样无回显
- 不是半帧吞噬：灌 400 字节（>267 字节最大帧）后仍无回显
- 不是 `ActiveMode` 改动：回滚成 switch 版本后现象不变
- 不是看门狗复位：3 s 内 905 帧 seq 连续，无重启
- 不是守卫误拦：绕过 server 直接用 `SerialLink` 发帧，同样无 ACK

### 4.3 根因（已用诊断固件证实）：**MCU 的 RX 物理层断了**

把 `s_rx_total`（累计接收字节，不取模）、`NVIC->ISER`、`USART1->ISR` 打包进 30040 的
`elec_angle` 字段读回（诊断完已改回真实角度）：

| 判据 | 实测 | 说明 |
|---|---|---|
| 发 20 字节后 `rx_total` 增量 | **0** | 一个字节都没进中断 |
| `NVIC->ISER[1]` bit5 (IRQ37) | 1（补了显式使能后） | 中断已使能 |
| `USART1->CR1` | 0x2D | UE/RE/TE/RXNEIE 全在 |
| `USART1->ISR` | 0xD0 | **无 RXNE、无 ORE** |
| `huart1.gState` | READY | 发送侧正常 |

三条同时成立 → **数据根本没到 MCU 的 RX 引脚**。TX 方向是好的（100 Hz 遥测一直能收），
所以断的是"PC → 板子"这一根：ST-Link VCP 的 TX ↔ 板子 PB7(USART1_RX)。

**不是软件问题。** 之前 22:38 曾读到一次 `ORE=1`，那是 22:25 上位机发的残留字节积压；
清掉 ORE 并补上 NVIC 使能后，新字节再也没到过。

### 4.4 顺带修掉的三个固件缺陷

1. **NVIC 使能不再依赖 HAL 初始化时机**：`ServoCmd_Init()` 里显式
   `HAL_NVIC_SetPriority/EnableIRQ(USART1_IRQn)` + 清一次 ORE。
   原来只在 `HAL_UART_MspInit()` 里开，而 MspInit 在 `huart1.gState != RESET` 时会被跳过。
2. **ACK 卡死不再阻塞分发**：原实现里一条 ACK 发不出去，`MavHost_Task()` 每拍开头就
   `return`，后续所有命令都不 dispatch。现加 `MAV_ACK_STUCK_MS=30` 超时丢弃。
3. **gState 卡死自愈**：连续 20 ms 非 READY 就 `HAL_UART_AbortTransmit` + 强置 READY
   （与 `telemetry_tx.c` 遥测侧同款）。自愈计数写在 30055 的 `p[45]`
   （高 4 位 Abort 次数、低 4 位 ACK 丢弃次数）。
4. 保留 `s_rx_total` 累计计数与 `ServoCmd_GetDiag()`，下次链路异常可直接复用。

### 4.5 待现场处理

断电 5 s 后检查 **PC → 板子的 RX 线**（ST-Link VCP 的 TX 到 PB7，含 GND）。
判据：上电后发 `S` 能回 `[CMD] st en=0 ...` 即恢复。
