**分成两组看**：#1–#4 是**电气量**（需要电角度、电压、电流），#5–#9 是**机械量**（需要转速、角度、转矩）。

**两类激励**：电气辨识用「电角度可控 + 电压已知」，机械辨识用「转矩已知 + 转速可测」。这个对偶关系决定了所有实现细节——比如电气侧要锁电角度，机械侧要锁转矩。

## 1. 可观测性边界（决定算法能做到什么）

单编码器装在**电机端**，减速器与负载对控制器是一个黑箱。

| 参数 | 单编码器 | 原因 |
|---|---|---|
| 折算惯量 `J_eq = J_m + J_l/N²` | ✅ | 转矩/加速度可直接测 |
| 等效摩擦（Stribeck） | ✅ | 稳态 iq 即摩擦转矩 |
| 谐振频率 / 阻尼 | ✅ | 电机端速度含谐振响应 |
| 齿槽转矩 | ✅ | 按机械角重采样即可 |
| **减速比 N** | ❌ | 输出端无参考，N 与 J_l 不可分离 |
| **背隙** | ❌ | 需两端角度差 |
| **扭转刚度** | ❌ | 同上 |
| **传动误差（1×/2×）** | ❌ | 同上 |

**关键推论**：`N` 未知时，`J_eq` 只能作为整体使用（速度环设计正好只需要整体值），不能分解出 `J_m` 与 `J_l`。要解锁下一级，需在输出端加绝对值编码器（板上 `THVD1426` RS-485 可用）。

**第二个耦合**：转矩由 `T = 1.5·p·ψ·iq` 算出，所以 **J 与 ψ 成正比**。ψ 的误差会 1:1 传导到 J。当前 ψ 有两个值（模型 7.593 mWb / 电压饱和反推 4.455 mWb，差 41%），固件用后者（`MI2_KT = 0.0936`）。这是 J 最大的不确定源，不是算法本身的问题。

## 2. 电气参数辨识

### 2.1 极对数 / 方向 / 电角度零点（`Z`）

**算法来源**：VESC `mcpwm_foc_encoder_detect()`（`bldc/motor/mcpwm_foc.c:1519`）——一遍扫完同时出三个参数。

**为什么不分开做**：FM_XC 是三个独立流程（极对数、方向、零点各自跑），中间有隐含依赖顺序，任一步失败都要从头来。VESC 把三者绑在**同一次机械旋转**里，几何关系天然自洽。

**流程**（`motor_ident.c`）：

```
RAMP 200ms      电流闭环把转子拖到已知电角度
  ↓
STEP ±120° × 60 步   每步 MI_SETTLE_MS=60ms，记录编码器计数差
  ↓
ratio = 120° / Δθmech      极对数（连续量）
resid = |ratio − round(ratio)|    > 0.25 直接判失败
dir   = sign(Δθmech)        方向
  ↓
SWEEP 正向扫整圈 → 反向扫整圈   各 3 点/电周期，共 2×ratio×3 点
offset = atan2(Σsin, Σcos)      圆形平均（不是算术平均！）
  ↓
delta = (offset − MI_MODEL_ELEC_OFS)/ratio_int × dir
z_new = z_old + delta
```

**三个设计要点**：

1. **`MI_SETTLE_MS = 60` 而非 30**。30 ms 时 `ratio` 偏大 10.6%（12.66 vs 14），且正反两组净位移差 527978 counts——转子还在爬行/过冲，读数取决于到达方向（齿槽 + 摩擦滞回）。
2. **圆形平均而非算术平均**。角度跨零时算术平均会给出 ±180° 的错值。
3. **`MI_MODEL_ELEC_OFS = π/2` 必须与模型同步**。模型 `three_loop_deploy.c` 里写死 `theta_sum = 14·θm + π/2 + 0.00105·ωm`，辨识出的 offset 要先扣掉这段 π/2 再折算。两者不同步 → 闭环电角度恒差 90° → 力矩要么退化为 0（正交），要么反向。

**实测**：

```
[CMD] IDENT ok ratio=13.98 pn=14 dir=+1 off=90.93deg zero=-1.88deg n=60/84 bad=0 moe=0
[CMD] id st=DONE ratio=13.98 resid=0.02 dir=+1 dmin=4.36 dmax=12.74 navg=8.58deg n=60/84 bad=0
```

`bad=0` 说明 84 个采样点全部满足 `Δθmech > MI_DMECH_MIN = 2 mrad`（VESC 没有这个门，卡住时会把 0 也平均进去）。

### 2.2 相电阻 R：稳态矢量模长法（`@` 第一段）

**算法来源**：VESC `mcpwm_foc_measure_resistance()`（`mcpwm_foc.c:1783`）逐行等效移植。

```
虚拟角锁 0（θ=0，不转）
  ↓
200 ms 电流斜坡 → 2 A（CMD_RL_TEST_A，上限 4 A）
  ↓
100 ms 稳定
  ↓
50 点采样，R = Σ|v| / Σ|i|        矢量模长，不是单轴
```

**为什么用矢量模长**：`|v| = √(vd²+vq²)`、`|i| = √(id²+iq²)`，这样不必关心 dq 轴怎么分配，也不必担心电角度误差把电流漏到另一轴。用单轴会因 θ 的残余误差系统性偏低。

**为什么必须读限幅后的 v**：`Servo_GetOpenLoopVdq()` 返回的是圆限幅之后的电压。限幅前的 PI 输出在电压顶死时会偏大，直接拿去算 R 会系统性偏高。

**实测**：

| 项 | 值 |
|---|---|
| 辨识值 | **395.7 ~ 405.1 mΩ**（重复性 ±1.2%） |
| 模型 `three_loop_params.m` | 378.5 mΩ |
| 万用表 | 420 mΩ |

落在两者之间。万用表含引线与接触电阻，本来就应该偏大；模型那个值当初是为让 `Ki = wc·R` 落在历史整定值上反推的，不是纯测量。

**局限**：铜温漂约 +0.4%/K，冷机 400 mΩ 热机可能到 450 mΩ。

### 2.3 dq 电感 L：单频注入 + 单点 DFT（`@` 第二段）

**为什么不能照搬 VESC**：VESC 用 `mcpwm_foc_measure_inductance()`（`:1895`）的 **HFI 六矢量注入 + FFT 的 bin0/bin2**（bin0 取 `1/L` 均值，bin2 取二次谐波分离 Ld/Lq），完全依赖它自己的 `m_hfi` 模块和专用采样时序。X72 没有这套基础设施。

**第一版：d 轴阶跃 + 逐点差分 —— 失败**

原本最自然的做法，拟合 `v = R·i + L·di/dt`：

| 斜率门限 | 有效点 | L | 离散度 |
|---|---|---|---|
| 800 A/s | 27 | 40.9 µH | 61.6% |
| 3000 A/s | 4 | 76.9 µH | 71.1% |

两层原因：
- 阈值 800 时，稳态电流噪声 ±0.05 A / 50 µs = **1000 A/s**，超过门限被当成"有效斜率"——算出的 L 是噪声除以噪声。
- 收紧到 3000 就只剩 4 个点：**L/R = 300 µs，20 kHz 下整个上升沿只有 4~6 拍**。

离线仿真也证实算法本身有 +23% 偏差。**这不是调参能救的**。

**第二版：1 kHz 单频电压注入**

用 ωL 的阻抗而不是时域瞬态——正是 VESC 非要用高频注入的原因。

```
虚拟角锁 0，d 轴注入 vd = 1.0·sin(2π·1000·t)，vq = 0
  ↓
3 个整周期（60 拍 @20 kHz）采样 id
  ↓
单点 DFT（正交解调）：
  I_amp = 2/N · √((Σi·cosφ)² + (Σi·sinφ)²)
  |Z|   = V_amp / I_amp
  L     = √(|Z|² − R²) / ω
```

**三个参数都是被约束出来的**：

| 参数 | 值 | 为什么 |
|---|---|---|
| 频率 | **1 kHz** | ωL = 0.713 Ω，与 R ≈ 0.40 Ω 同量级，两者都能从 \|Z\| 分辨。再低 ωL 被 R 淹没，再高每周期点数不足（1 kHz 正好 20 点/周期） |
| 整周期 | **3 个** | 单点 DFT 只在整周期上才正交，非整周期有泄漏 |
| 幅值 | **1.0 V** | 约 1.56 A 电流幅值，既不饱和到失真，又足够压过死区 |

**必须绕开电流环**：PI 会把外部注入的正弦当扰动压掉，测出来的不是电机 |Z|，而是控制器的抑制比。所以独立加了 `s_olv_en` 分支，直接算占空比。

**实测 + 饱和曲线**：

| 注入 | 电流幅值 | R | L |
|---|---|---|---|
| 0.6 V | 0.87 A | 407.0 mΩ | **87.9 µH** |
| 1.0 V | 1.56 A | 409~412 mΩ | **77.8 µH** |
| 1.5 V | 2.54 A | 400.1 mΩ | **69.0 µH** |
| 2.5 V | 4.55 A | 401.0 mΩ | **59.0 µH** |

**跨幅值 R 恒定、L 单调下降，互为佐证**——这不是噪声，是真实的铁芯饱和。零电流外推 `L₀ ≈ 95 µH`，模型写的 113.5 µH 更像是不考虑饱和的小信号值。

**独立交叉验证**：电流环实测 `tr = 250 µs` 对应带宽约 1.4 kHz；若 L 真是 113.5 µH，按 `Kp = ωc·L` 应该只有 1 kHz（tr ≈ 350 µs）。实测更快，正说明真实 L 更小——与 70~80 µH 吻合。

**局限**：只测 Ld（注入走 d 轴），`Ld = Lq` 是表贴式假设。要分离 Ld/Lq 需要 VESC 那样的二次谐波。死区 0.18 V 占注入 1.0 V 的 18%，会让 |Z| 抬高、L 偏大几个百分点。

### 2.4 编码器非线性：芯片级自校准（`^`）

严格说这是**传感器校准**不是电机参数辨识，但它直接决定 §2.1 的零点和 §3.4 齿槽的角度基准，放在这里。

**为什么不用软件 LUT**：调研了两家参考工程——VESC 只有 `enc_corr[360]` 的**应用**逻辑（`mcpwm_foc.c:3256`，按机械角查表从电角度减掉）和掉电存储，**没有生成表的算法**（表由 VESC Tool/Lisp 外部写）；FM_XC 只有一个常数 `elec_angle_compensation`（`motor_ctl_loop.c:74`）。

而 **MT6835 自带硬件级自校准**（`CAL_EN` 引脚触发），芯片内部有 DSP 和 EEPROM，INL 从 ±0.5° 降到 ±0.07°，**不占 CPU、不占 Flash、不占控制节拍**。软件 LUT 还补不了芯片自身的谐波误差，只能补安装偏心。

**硬件已就绪**：`pin_map.csv:48/295` 确认 `MT6835.4 (CAL_EN) → STM32 PB9`，`.ioc` 里 PB9 已是 `GPIO_Output + PULLDOWN + Locked`。

**流程**：

```
PB9 拉高 → 速度环匀速 600 rpm → 芯片自己判 64 圈 → 写 EEPROM
  ↓
轮询 0x113[7:6]：11 = 成功
```

**判据只认芯片，不认圈数**。第一版用"圈数 ≥ 64"判成功是错的——实机芯片在 **51.6 圈**就报成功，而且参数要转完最后一个周期才写进 EEPROM。只按圈数收工会拿到一张没写完的表。

**实测**：

```
[CMD] EC ok turns=51.60 avg=599.90rpm [595.26..595.90] chip=3 -> !!! POWER CYCLE REQUIRED (>6s) !!!
```

`chip=3` 是芯片寄存器上报，不是固件推测。转速波动 ±0.4 rpm，耗时约 7 s。

**⚠ 必须人工断电**：手册 9.2 第 (5)(6) 步要求成功后等 >6 秒并给芯片断电，重上电才加载 EEPROM。板上无编码器电源开关，`!` 软复位不断 3.3 V，这一步固件做不到。

**SPI 总线冲突处理**：SPI1 被 20 kHz 角度 DMA 独占。`BspServo_ReadEncReg()` 先等 `s_spi_busy` 清零（≤5 ms），再阻塞发 3 字节（2.3 µs），期间 `StartEncoderDma()` 返回 BUSY 丢 1 拍角度——600 rpm 下等效 0.05% 圈数误差。

### 2.5 磁链 ψ / R / L 联合辨识（`+`）

**为什么需要它**：折算惯量 `J ∝ 1/ψ`。ψ 之前只能从"3000 rpm 电压饱和点"反推（4.455 mWb），与模型值 7.593 mWb 差 41%，**J 的不确定度就是 41%**。

**为什么不能断电滑行测反电势**：`ua/ub/uc` 是 `(duty−0.5)·vbus` 的指令值，网表里只有 `VBUS_ADC`，**没有相电压分压**。三相浮空时电流采样点（下桥分流电阻）上没有电流，测不到 BEMF。要走这条路必须改板。

**为什么空载转速扫描解不出 R 和 ψ**：空载 iq 被摩擦锁在 ωe 上，`iq ≈ a + b·ωe`，代入 `vq = R·iq + ωe·ψ` 得 `vq = R·a + (R·b+ψ)·ωe`——**只能解出两个组合量，R 和 ψ 共线**。扫再多点，方程组的秩都是 2。

**解法：用 id 作为独立维度**。同一转速下扫 id：

```
∂vd/∂id = R                ← R 直接出来，与摩擦/iq 无关
∂vq/∂id = ωe·L             ← L = 斜率/ωe
```

两个斜率都不含 iq，共线性被绕开。有了 R 和 L，再用 vq 解 ψ：

```
ψ = (vq − R·iq − ωe·L·id) / ωe
```

**工况**：

| 组 | 转速 | id 序列 | 用途 |
|---|---|---|---|
| 主 | 1000 rpm（ωe=1466） | 0 / −1 / −2 / −3 A | R（vd 斜率）、L（vq 斜率）、ψ（4 点平均） |
| 副 | 300 rpm（ωe=440） | 0 / −2 A | ψ 交叉验证 |

主转速必须 1000 rpm：`vq` 的斜率 `ωe·L` 在 300 rpm 只有 0.035 V/A（3 A 才 0.1 V，与死区同量级），1000 rpm 是 0.127 V/A（0.38 V，ADC 能分辨）。
副转速仍能验 ψ：`ωe·ψ` 在 300 rpm 已有 1.9 V，占 vq 的 97%。

**实测**：

```
[FI] 0 id=-0.00 iq=0.48 vd=-0.00 vq=6.55 we=1466.08
[FI] 1 id=-1.00 iq=0.56 vd=-0.51 vq=6.42 we=1466.08
[FI] 2 id=-2.00 iq=0.63 vd=-0.79 vq=6.28 we=1466.08
[FI] 3 id=-3.00 iq=0.70 vd=-1.03 vq=6.16 we=1466.08
[FI] 4 id=0.00  iq=0.25 vd=0.04  vq=2.04 we=439.82
[FI] 5 id=-2.00 iq=0.33 vd=-0.75 vq=1.95 we=439.82
[CMD] FI R=327.84mohm L=89.07uH psi=4.333mWb
[CMD] FI Kt=0.0910 Ke=0.06V/(rad/s) r2=0.965/0.999 dev=1.85% moe=0
```

**ψ 得到独立交叉验证**：

| 方法 | ψ | 独立性 |
|---|---|---|
| **`+` 联合辨识** | **4.333 mWb** | id 扫描 + 两转速回归 |
| 3000 rpm 电压饱和反推 | 4.455 mWb | `vq = ωe·ψ`（假设 R·iq 可忽略） |
| 模型 | 7.593 mWb | 厂家标称/初始值 |

前两者差 **2.7%**，方法完全独立。模型值偏大 75%，可以确认是错的（可能是相/线或峰值/有效值口径混淆）。
`dev = 1.85%`：1000 rpm 与 300 rpm 两组各自算出的 ψ 只差 1.85%，**这是很强的自洽性证据**。

**L 与注入法一致**：`+` 给 89.07 µH（`r2=0.999`），`@` 给 80.1 µH @1.55 A，差 11%。

**R 偏低 18%，是死区**：`id` 从 0 到 −3 时 vd 只变 1.03 V，而死区约 0.18 V（17%）。更麻烦的是死区不随电流线性变（小电流占比大），让 vd 对 id 呈**凹函数**，回归斜率被拉低。分段斜率 0.51 / 0.28 / 0.24 单调下降就是这个特征。
**所以 R 用 `@` 的 400 mΩ，`+` 的价值在 L 和 ψ。**

**对下游的影响**：

| 参数 | 旧 | 新 |
|---|---|---|
| ψ | 4.455（间接） | **4.333（直接）**，不确定度 41% → **<3%** |
| Kt | 0.0936 | **0.0910**（`MI2_KT` 已更新） |
| J | 5.32e-5 | 5.47e-5（+2.8%，但含义不同了） |

## 3. 机械参数辨识

四项共用一套框架（`mech_ident.c`）：**进环 → 激励 → 同步解调 → 退环**。命令用 4 个独立字符（`(` `)` `<` `}`），不用 `_<n>` 数值命令——实测引导符与数字同批 Poll 时会丢字节。

### 3.0 前提：必须有一条未滤波的速度通路

这是所有机械辨识的**硬前提**，先单独说。

常规测速是 **8 拍累计差分 + 95 Hz 低通**（`BSP_SPEED_AVG_N=8`、`alpha=0.03`）。95 Hz 低通会把 100 Hz 以上的谐振**直接抹掉**——要测的东西被测量通道自己滤掉了。

所以新增 `BspServo_GetOmegaFast()`：**单拍差分、无低通**，带宽到 10 kHz。

代价是量化噪声：±1 count / 50 µs = **±0.06 rad/s**。这个量级听起来很大（30 rpm 才 3.14 rad/s），但同步解调是长时间累加，噪声按 `1/√N` 收敛——300 拍累加后等效到 3.5e-3 rad/s，足够。

**这条通路只用于辨识，不能拿去做速度反馈。**

---

### 3.1 谐振 / 带宽：扫频 + 同步解调（`(`）

**为什么用扫频而不是阶跃 + FFT**：激励频率是自己产生的，可以在每个频点做长时间整周期累加，噪声抑制比一次阶跃好得多；而且能直接给出**相位**，阶跃 FFT 的相位不可靠。

**流程**：

```
iq = 0.2·sin(2πft)     无直流分量 → 不产生净加速
  ↓
每个频点：等 2 个周期（40 ms 起）→ 累加 max(5, 0.2·f) 个整周期
  ↓
Σv·sin、Σv·cos（单点 DFT）→ 幅值与相位
  ↓
20–1000 Hz 对数分布 11 点
```

**累加周期数是频率的函数**：`n = max(5, 0.2·f)`。等效于**累加时长恒定在 0.20–0.25 s**——低频保证至少 5 个周期（20 Hz 时正好 5 个），高频则固定 0.2 s 不再增长。这样每个频点的噪声抑制水平一致，不会出现"低频点特别准、高频点特别差"。

**测量通道：8 拍中心差分（不是单拍）**

单拍差分 `ω = Δθ/Ts` 的量化噪声是 ±1 count/Ts = **±0.06 rad/s**，而 1 kHz 的机械响应只有 0.03 rad/s 量级——**完全被噪声盖住**。这就是原来 ">400 Hz 测不到" 的真正原因：不是没有响应，是测不出来。

改成 8 拍差分（中心在第 4 拍）：

```
ω(t−4) = (θ(t) − θ(t−8)) / (8·Ts)
```

噪声降到 ±2 count/(8·Ts) = **±0.015 rad/s**（好 4 倍），代价是 4 拍延迟（1 kHz 时 72°，按频率精确补偿）与差分器本身的 sinc 低通（1 kHz 处衰减到 0.755，同样按频率补偿）。

为什么不用 16 拍：sinc 衰减到 0.235，补偿要乘 4.3 倍，噪声反而放大。

**另外两处改动**：
- 高频段（>300 Hz）激励幅值从 0.2 A 提到 **0.5 A**：速度响应 ∝ 1/f，1 kHz 时 0.2 A 只产生 0.026 rad/s。高频时转子只微振（1.3 rpm），不会进摩擦非线性区，放大幅值是安全的。
- 高频段累加窗口 0.20 s → **0.40 s**：噪声按 1/√N 收敛。

**四个坑**：

1. **幅值必须 0.2 A 而非 0.4 A（低频段）**。20 Hz 时速度摆幅 `≈ Kt·i/(J·2πf)`，0.4 A 会摆到 130 rpm，摩擦与齿隙全进非线性区，低频增益虚高 5 倍。降到 0.2 A 后正常。
2. **`atan2` 参数顺序**。设 `v = A·sin(ωt+φ)`，则 `Σv·sin = A·N/2·cosφ`、`Σv·cos = A·N/2·sinφ`，所以 `φ = atan2(Σv·cos, Σv·sin)`。写成 `atan2(vs, vc)` 会得到 `90°−φ`——实测表现为低频相位 +156° 而不是 −90°。
3. **相位补偿方向**。8 拍差分代表的是 `(t−4Ts)` 时刻的速度，即测得相位 = `φ − ω·4Ts`，**真实相位要加回来**。原实现用单拍差分、减 1 拍（延迟小且方向相反，只差十几度所以一直没暴露），现在 1 kHz 是 72°，方向错就是 144°。
4. **必须先 `C` 让转子静止**。改完第一次测时 141 Hz 以上全是 `0.0000`、相位恰好 `72.00°`（`atan2(0,0)` 退化），加诊断打出 `wmean/wamp/iamp` 才发现是**刚跑完 `+`、转子还在 1000 rpm 滑行**。重测（先 C）后全部正常。

**实测（高频段 0.5 A，其余 0.2 A）**：

| 频率 | 增益 (rad/s per A) | 相位 | 旧实现（单拍差分） |
|---|---|---|---|
| 20 Hz | 21.25 | +11.2° | 25.52 / −38.5° |
| 43.7 Hz | 7.79 | −72.6° | — |
| 95.6 Hz | 2.26 | **−96.7°** | — |
| 209 Hz | 0.584 | −134.7° | 0.59 / −144.9° |
| 457 Hz | 0.114 | −150.7° | **测不到** |
| 676 Hz | 0.070 | −166.3° | **测不到** |
| **1000 Hz** | **0.036** | **+171.7°（= −188.3°）** | **测不到** |

诊断量：`wmean=2.79 rad/s`（差分通道有效）、`iamp=0.205 A`（≈ 给定 0.2，iq 解调正确）。

**20–1000 Hz 内无谐振峰**，增益单调下降，相位从 −96° 单调降到 −188°（越过 −180°，符合双惯量二阶系统的极高频特征）。

> **20–40 Hz 的相位不可信**：那时速度摆幅约 5 rad/s（48 rpm），会跨越齿槽周期，齿槽力造成严重非线性。增益量级对，相位会畸变。60 Hz 以上相位才单调可信。

**结论：当前 3 Hz 的速度环带宽不是被机械谐振限制的。** 这是整个机械辨识最有价值的一条——它把"带宽上不去"的嫌疑从机械侧排除了。

### 3.2 摩擦曲线：多点稳态（`)`）

**原理**：速度环稳态时 `iq` 就是摩擦转矩（加速度为零，`J·α = 0`）。8 个转速点扫一遍就是摩擦曲线。

```
8 点（MI2_FRIC_RPM）：1, 2, 3, 6, 12, 30, 80, 200 rpm
  ↓
每点：稳定 3 s → 平均 500 ms（8 点共约 28 s）
```

**低速密采样**：1/2/3/6 四点都在 12 rpm 以下，专门覆盖静摩擦衰减区；30/80/200 三点覆盖黏滞区。

**为什么稳定 3 s**：1 rpm 时速度环的积分器要爬很久。实测 1.2 s 时 3 rpm 读到 0.499 A，而 12 rpm 只读到 0.070 A——明显还在爬。

**实测（8 点中摘录 5 点，两次独立运行）**：

| rpm | iq 第一次 | iq 第二次 |
|---|---|---|
| 1 | 0.09 | **−0.03** |
| 3 | 0.19 | **−0.03** |
| 12 | **0.50** | **−0.14** |
| 30 | 0.129 | 0.139 |
| 80 | 0.148 | 0.151 |

**30 rpm 以上稳定（0.13–0.15 A），12 rpm 以下抖到出现负值**——速度环积分器在慢摆，3 s + 500 ms 仍不够。

**能用的结论**：稳态摩擦前馈应从 0.32 调到 **约 0.15**（30–80 rpm 实测值）。
**不能用的部分**：低速段数据作废，需要更长的稳定时间或改用开环恒压爬行。

### 3.3 折算惯量：双幅值差分（`<`）

**为什么不能直接 `J = ΔT/Δα`**：摩擦会污染结果。用两个不同转矩幅值在**同一转速区间**测加速度，摩擦项相减消掉。

```
iq = 1 A  → 从 1 rad/s 加速到 6 rad/s，测 acc1
  ↓ 停 600 ms
iq = 2 A  → 同一区间，测 acc2
  ↓
J = (T2 − T1) / (dw·(1/dt2 − 1/dt1))
  其中 T = 1.5·p·ψ·iq = 0.0936·iq
```

**为什么起始转速取 1 rad/s 而不是 0**：避开静摩擦区。0 附近静摩擦是动摩擦的 2 倍，会严重拉低算出的加速度。

**实测**：

```
[MI] IG J=0.5323e-4 acc=1098.90/2857.14 tq=0.0936/0.1872
```

**J = 5.32e-5 kg·m²**。

对比：之前由"8x 增益最优"反推的是 `2.3e-4`，**差 4.3 倍**。用真实值重算，同样 `Kp=0.583` 对应的带宽是 **13 Hz 而非 3 Hz**——速度环远没有用满机械能力。

**⚠ 最大的不确定源**：`J ∝ 1/ψ`。Kt 用的是 0.0936（ψ=4.455 mWb）。模型值 7.593 mWb 会给出 J = 9.07e-5。单编码器无法独立校准 ψ，只能靠外力拖动测反电势。

### 3.4 齿槽转矩：按角度重采样（`}`）

**为什么必须按角度而不是时间**：转速不稳时按时间 FFT 会把齿槽谐波抹成宽带。按机械角分箱后，`bin k` 直接就是**第 k 阶**。

```
10 rpm 正向转 1 圈（6 s）→ 记 128 箱
  ↓ 掉头，等 800 ms 速度反向建立
10 rpm 反向转 1 圈（6 s）→ 记 128 箱
  ↓
逐箱平均 → 128 点角度表
```

**为什么必须两向**：摩擦的**常值偏置**在正转时是 `+Tc`、反转时是 `−Tc`，单向测量会把它当成齿槽的直流分量留在表里。两向平均后 `Tc` 抵消，只剩真正与角度相关的齿槽分量。

**为什么 10 rpm 而不是 2 rpm**：2 rpm 转一圈要 30 s，超过超时。10 rpm 是 6 s（两向共 14 s）。

**一个必须分清的量**（第一版就在这里翻了车）：

| 用途 | 公式 | 说明 |
|---|---|---|
| 分箱 | `br = θ − θ0` | θ0 恒为**正向**起点，两向共用一个坐标 |
| 进度 | 正向 `br`、反向 `2π − br` | 反向时转子往回走，br 递减，进度递增 |

一开始把分箱和进度写成一个式子，反向时 `rel` 起始就是 2π、**立刻满足"转完一圈"**，7.2 s 只跑了正向圈，结果 `fwd = rev = 1.067 A`（完全相同，一眼看出反向数据是空的）。

**实测（双向平均）**：

```
[CMD] MI end pp=1.169A fwd=1.049 rev=1.289 dc=0.015
```

| 量 | 值 | 含义 |
|---|---|---|
| `pp` | **1.169 A** | 平均后的峰峰值 |
| `fwd` | 1.049 A | 正向单圈 |
| `rev` | 1.289 A | 反向单圈 |
| `dc` | **0.015 A** | 平均表的均值，理论上应≈0 |

**`dc` 从单向时的 0.103 降到 0.015（7 倍改善）** —— 摩擦常值偏置基本被抵消，这是双向测量最直接的收益。

`fwd` 与 `rev` 差 23%，是**两向摩擦不对称**的真实体现（不是噪声）。差得越多，"两向平均"这个动作本身就越需要保留 `fwd`/`rev` 两个单独值一起看。

**阶次分布（单向表分析）**：

```
24 阶  0.3298 A      ← 12 槽 × 2
28 阶  0.1817 A      ← 2 × 14 极对
56 阶  0.0439 A
14 阶  0.0336 A
```

**峰峰 1.17 A 是 30 rpm 运行电流（0.13 A）的 9 倍。** 电流环在 0.1 A 量级做精细调节时，齿槽正在施加 ±0.6 A 的周期扰动——这是低速抖动与 3 rpm 超调的直接来源。

**这张表已经用于前馈补偿**（`Board/cog_ff.c`）：按机械角查表，直接叠到 iq 给定。实测 30 rpm 纹波 −21.4%、100 rpm −30.9%。详见 `齿槽前馈_实现与实测.md`。
前馈正确性依赖两个角度：表的 0 点（测量起点）与编码器零点，任一失配（如重做 Z）都会让表静默失效，所以加载时强制校验，不一致就停用。

### 3.5 摩擦两点标定：工程简化版（`$`）

`3.2` 的 8 点曲线是"看清真相"，`$` 是"拿到两个能用的数"：

```
3 rpm 稳 1.6 s → 平均 200 ms → iq1
  ↓
100 rpm 稳 1.8 s → 平均 200 ms → iq2
  ↓
fric_a = iq1                         （低速起动电流，A）
visc   = (iq2 − iq1)/(ω2 − ω1)        （黏滞系数，A/(rad/s)）
Tc     = 0.0936·iq1                   （仅报告用，N·m）
```

**两个必须的设计**：

1. **标定期间必须关前馈**。否则会把前馈量算进摩擦，形成正反馈。
2. **失败要还原原参数**。判据：转速达不到给定 80% 判 `MOTION` 失败——堵转电流拿去当前馈是危险的。

**与 §3.3 的关系**：`fric_a` 不经过 Kt 换算，直接是 iq（A）。因为 ψ 有 41% 不确定性，按 `Tc/Kt` 换算会把这个误差带进前馈。

**已知偏差**：`$` 用 3 rpm 作为低速点，而 §3.2 证明 3 rpm 的稳态 iq 本身不可信（±0.03~0.19 乱跳）。所以 **`$` 的 `fric_a` 应视为上限，不是准确值**；更可靠的是取 §3.2 中 30–80 rpm 的 0.15 A。

## 4. 参数去向：谁在用

| 参数 | 存储 | 被谁使用 | 是否已生效 |
|---|---|---|---|
| `ratio/dir/zero` | Flash `PS_FLAG_ZERO` | 电角度计算、Park 变换 | ✅ 闭环必需 |
| `bias_u/bias_w` | Flash `PS_FLAG_BIAS` | 电流零漂补偿 | ✅ |
| `R/L` | Flash `PS_FLAG_RL` | **仅记录**，不改电流环增益 | ⚠ 见下 |
| `fric_a/fric_visc` | Flash `PS_FLAG_FRIC` | 摩擦前馈 | ✅（需 `*` 开启） |
| `spd_kp/ki_ts` | Flash | 速度环 | ✅ |
| `J` | **不存**（诊断输出） | 加速度前馈系数 `J/Kt×0.7` | ⚠ 手动 |
| 齿槽 128 点表 | **Flash 单独一页** `0x0807E000` | 齿槽前馈 `s_spd_iq` 叠加 | ✅ 30 rpm −21%、100 rpm −31% |
| 谐振曲线 | **不存** | 用于判断带宽上限 | ❌ |

**R/L 为什么不自动改增益**：按实测 L=80 µH 重算 `Kp = ωc·L` 会把带宽从当前的 1.4 kHz 降到设计的 1 kHz，**性能反而下降**；而且只改固件不改 `three_loop_params.m` 会让模型和代码悄悄失配。要改必须同时改两处：

```c
SERVO_CUR_KP    = ωc·L
SERVO_CUR_KI_TS = ωc·R·Ts
```

**Flash 布局**：`ParamBlob` 56 B = 7 个 doubleword，`magic + version + CRC32` 三重校验，任一不符就当没存过（绝不半套应用）。`PS_VERSION = 2`。

## 5. 失败模式与判据汇总

每个辨识都必须有"结果不可信"的自我判定，否则会把垃圾参数写进 Flash。

| 辨识 | 判据 | 阈值 | 触发后的行为 |
|---|---|---|---|
| 极对数 | `resid = \|ratio−round(ratio)\|` | > 0.25 | 判 FAIL，不写零点 |
| 极对数 | 单步机械角 `Δθ` | < 2 mrad | 丢弃该点，计入 `n_fail` |
| 极对数 | 总时长 | > 20 s | 硬超时 |
| R | 平均电流 | < 0.2 A | 判 FAIL（电流没建立） |
| R | 电流幅值 | 0.5–4 A | 越界拒绝启动 |
| L | 注入电流幅值 | < 0.05 A | 判 FAIL（无响应） |
| L | `\|Z\|² − R²` | ≤ 0 | 判 FAIL（R 测大或 I 测小） |
| L | 结果范围 | 5 µH–3 mH | 越界判 FAIL |
| 编码器 | `0x113[7:6]` | ≠ 3 | 判 FAIL（**不看圈数**） |
| 扫频 | 响应幅值 | < 0.06 rad/s | 数据点作废（量化噪声下限） |
| 惯量 | `J` 范围 | 1e-6–1.0 kg·m² | 越界判 FAIL |
| 惯量 | `den` | < 1e-6 | 判 FAIL（两段加速度无差异） |
| 摩擦标定 | 转速跟踪 | < 80% 给定 | 判 MOTION 失败，还原参数 |
| 摩擦标定 | 采样离散度 | > 15% | 判 FAIL |

**共通护栏**（所有辨识）：`BspServo_IsPwmEnabled()` 检查、电流模式/开环模式互斥、`D` 命令可随时中止、结束后强制封 MOE。

## 6. 算法选择依据：为什么是这些而不是别的

| 决策点 | 选择 | 放弃的方案 | 依据 |
|---|---|---|---|
| 极对数/零点 | VESC 单流程 | FM_XC 三流程 | 三个量在同一次旋转里几何自洽 |
| 角度平均 | `atan2(Σsin,Σcos)` | 算术平均 | 跨零时算术平均会差 180° |
| R | 稳态 `Σ\|v\|/Σ\|i\|` | 单轴 `vd/id` | 不受电角度残余误差影响 |
| L | 1 kHz 单频注入 + DFT | 阶跃差分拟合 | L/R=300 µs，20 kHz 下只有 4~6 拍，噪声主导（实测离散度 61~71%） |
| L | 1 kHz 单频注入 | VESC HFI 六矢量 + FFT bin2 | 需 `m_hfi` 模块，移植成本等于重写观测器 |
| 编码器 | 芯片自校准 | 软件 360 点 LUT | 芯片做不占 CPU/Flash/节拍，且能补芯片自身谐波误差 |
| 谐振 | 扫频 + 同步解调 | 阶跃 + FFT | 频点可控、噪声抑制好、相位可靠 |
| 惯量 | 双幅值差分 | 单幅值 `ΔT/Δα` | 摩擦项相减消掉 |
| 惯量起始转速 | 1 rad/s | 0 | 避开静摩擦区（静摩擦是动摩擦 2 倍） |
| 摩擦 | 多点稳态 | Stribeck 曲线拟合 | 低速段数据本身不可信，拟合没有意义 |
| 齿槽 | 按角度分箱 | 按时间 FFT | 转速不稳时时间 FFT 会抹成宽带 |
| 机械辨识命令 | 4 个独立字符 | `_<n>` 数值命令 | 数值解析在引导符与数字同批 Poll 时偶发丢字节 |

## 7. 已知局限（按影响排序）

1. ~~ψ 的 41% 不确定性~~ **已解决（2026-11-16）**。`+` 命令用 id 扫描 + 两转速回归直接测出 ψ = 4.333 mWb，与电压饱和反推的 4.455 只差 2.7%，两转速一致 1.85%。不确定度从 41% 降到 **<3%**。
   **残余**：ψ 的 3% 仍主要来自 R（`ψ = (vq−R·iq−ωe·L·id)/ωe` 里 R·iq 项），若 R 修正到 0.40，ψ 会降到约 4.28 mWb。以及整个方法仍依赖 FOC 本身，没有"外力拖动"那样的绝对参考。
2. **`+` 的 R 偏低 18%**（327.84 vs 400 mΩ），是死区造成的（vd 只变 1.03 V，死区 0.18 V 占 17%，且随电流非线性）。**R 用 `@` 的值**。
3. **低速摩擦数据不可信**（<12 rpm）。速度环积分器慢摆，需要更长的稳定时间或改用开环恒压爬行。`$` 用 3 rpm 作低速点，所以它的 `fric_a` 应视为上限；可靠值取 `)` 的 30–200 rpm（0.13–0.15 A）。
4. **只有电机端编码器**。减速比、背隙、扭转刚度、传动误差原理上不可观测。
5. **L 只测了 Ld**。表贴式假设 `Ld = Lq`，要分离需 id/iq 双轴扫描或二次谐波。
6. **扫频 20–40 Hz 的相位不可信**。速度摆幅约 5 rad/s（48 rpm），跨越齿槽周期，非线性严重。增益量级对，60 Hz 以上相位才单调。
7. **R 有铜温漂** +0.4%/K，跨幅值恒定只能说明注入期间温度没变。
8. **齿槽表对零点敏感**：重做 Z 之后表的相位失效，前馈会自动停用（`v=0`），必须重测。烧录擦 Flash 也要重测。
8. **`SERVO_CUR_PSI` 仍是 7.59298e-3**（实测值的 1.75 倍）。前馈过量会让 PI 在稳态反向工作，闭环输出仍正确但动态变差。改成 4.333e-3 需重新验证电流阶跃与高速动态。

## 8. 命令速查

```
电气
  C        电流零点标定（200 ms，要求 MOE=0）
  Z        极对数 / 方向 / 电角度零点（9 s）
  @        相电阻 R + 电感 L（0.36 s，必须先 C+Z）
  +        磁链 ψ / R / L 联合辨识（9 s，必须先 C+Z+D；R 偏低但 L/ψ 准）
  #        循环注入幅值 0.6/1.0/1.5/2.5 V（下次 @ 生效，看 L 饱和）
  ^        MT6835 芯片自校准（7 s，之后必须人工断电 >6 s）
  I        查看上一次 Z 的完整结果

机械
  (        谐振扫频 20–1000 Hz（4 s）
  )        摩擦曲线 8 点 1–200 rpm（28 s）
  <        折算惯量 J（5 s）
  }        齿槽转矩 128 点（14 s，正反各一圈；测完自动装进前馈缓存）
  ;        齿槽前馈开关（默认关）
  :        齿槽前馈状态（n/en/v/pp/ph/zd/now）
  _        查询机械辨识状态
  $        摩擦两点标定（4 s，自动写前馈）

共用
  D        封锁（任何辨识期间都有效，会 abort）
  S        状态回读（fl=1 表示 Flash 有通过 CRC 的参数）
  A        立即保存参数到 Flash
  !        软复位（验证冷启动恢复）
```

**流程建议**：

```
C → Z              → 闭环基本可用
@ → # 扫饱和       → 拿到 R 与 L(工作点)
+                  → 拿到 ψ（决定 Kt 与 J）与工作点 L
^ → 断电 6 s → C → Z   → 编码器非线性改善
(                  → 判断带宽上限（不影响运行）
<                  → 拿到 J，重算速度环增益
) 或 $             → 定摩擦前馈
}                  → 齿槽表（若做前馈）
```

## 9. 与参考工程的关系

| 工程 | 提供了什么 | X72 改了什么 |
|---|---|---|
| **VESC** (`bldc-master`) | 极对数/方向/零点的三段式流程；R 的稳态矢量模长法；`enc_corr` 应用逻辑 | 跳过 index 搜索（MT6835 是绝对值）；不用 `enc_corr[360]` 二级修正（改芯片自校准）；每步加有效性判定；加 `resid` 硬判据；`MI_SETTLE_MS` 30→60 |
| **FM_XC** (`FM_Servo_V3`) | 串联型 PI 结构；死区补偿思路 | 辨识部分不用（三流程有隐含依赖顺序） |
| **文献**（Infineon IMR 等） | 软件 LUT 校准的通用做法 | 被 MT6835 芯片自校准替代 |
| **本文档新增** | L 的单频注入法；机械四项（扫频/摩擦/惯量/齿槽） | 无参考实现，按可观测性自行设计 |
