# 力矩模式 —— 控制逻辑与上位机指令集

**固件** `Code=107400` · **协议** 非标准 MAVLink v2 · **串口** 921600 8N1
**日期** 2026-11-22

---

## 0. 一句话概括

力矩模式 = **直接给 q 轴电流 iq（A）**，固件把它经「斜坡 → 限幅 → 温度降额」送进电流环，
实际输出力矩 **T = Kt × iq**（本机 Kt ≈ 91.6 mN·m/A）。

**它没有速度环、也没有位置环**——给多少 iq 就出多少力，电机因此会一直加速，
直到撞上 **300 rpm 的超速保护**。这是设计，不是缺陷。

| 模式 | `30056 mode` | 给定 | 有无速度闭环 |
|---|---|---|---|
| 位置 | 1 | 目标角（0~2π 语义） | 有（外环） |
| 速度 | 3 | 目标转速 | 有 |
| **力矩** | **4** | **iq（A）** | **无** |
| MIT 阻抗 | 12 | 位置+速度+力矩+刚度 | 无（位置/速度是阻抗项） |

## 2. 控制链路（从 iq 到力矩）

```
30025 iq(A)
   │
   ├─ 协议门卫：±5.0 A（超范围回 OUT_OF_RANGE=2）
   │
   ├─ Servo_SetCurrentMode()
   │     └─ 限幅到 s_cur_iq_max（默认 5.0 A，可用 30082 float 12 改，0.05~5 A）
   │
   ├─ 一阶低通斜坡（默认 tau = 20 ms，30095 可改 0~2000 ms）
   │     ar = Ts/(tau+Ts)，Ts = 50 µs（20 kHz）
   │     作用：把 diq/dt 压到 50 A/s 量级，避免激起齿轮间隙/齿槽
   │     tau = 0 时直通（阶跃测试用）
   │
   ├─ 温度降额：iq_ref 被夹到 derate × s_cur_iq_max
   │     derate 由 1 ms 任务按电机/驱动温度算，1.0 = 不降额
   │     ★ 这是所有模式统一的收口，力矩模式也受它约束
   │
   └─ 电流环（20 kHz，编码器电角度 dq）
         id → s_cur_id_ref（默认 0）
         iq → 斜坡后的给定
         ├ 解耦 + BEMF 前馈（ωe·Ld/Lq、ωe·ψ·ktc）
         ├ 死区电压补偿（dead_en，作用在 vd/vq 上）
         └ SVPWM → 三相占空比

实际力矩：T = Kt × iq，Kt = 1.5 × pn × ψ × ktc
         本机 pn=14、ψ≈4.36 mWb → Kt ≈ 0.0916 N·m/A（冷态）
```

**力矩模式不做任何前馈补偿**：摩擦、齿槽、粘滞这些前馈只在速度/位置/MIT 链上生效。
给 `iq=0.5 A` 就是 0.5 A，不会额外加齿槽补偿。

## 3. 起环流程（固件内部，`do_current()`）

```
① 前置检查（任一不满足 → 静默拒绝，30090.en 保持 0）
     fault == 0          有任何故障位就拒
     cal == 1            电流零点已标定
     z == 1              电角度零点已标定
     无辨识在跑          Act_IsBusy() / 开环 / 电压注入
     不在速度模式        速度环会每 2 kHz 覆盖 iq_ref
② 余速门禁：|ω| > 0.9 × 31.4159 = 28.27 rad/s（270 rpm）→ 拒绝
③ 关模型三环 → Servo_SetMode(POSITION) + 位置给定=当前多圈角
   （贴住位置给定，避免电流环积分带着旧值起步）
④ Servo_SetCurrentMode(1, iq)   起电流环，清积分
⑤ BspServo_PwmEnable(1)         最后开 MOE
⑥ s_armed = 1，deadman = 2 s
```

> **② 为什么要门禁**：力矩模式的超速门限是**固定值 300 rpm**（不像速度环会跟着给定走）。
> 带 1000 rpm 余速切进来，0.4 ms 内就会置 `BSP_FAULT_OVERSPEED` 并整机封锁，
> 现象是"一切力矩模式就报故障"，真实原因只是电机还在滑行。
> 这里选择在入口拒绝，而不是放宽门限——那条 300 rpm 是力矩模式唯一的失控保护。

## 4. 三重保护（务必读完再上手）

| 保护 | 门限 | 后果 | 能否改 |
|---|---|---|---|
| **iq 限幅** | `cur_iqmax`，默认 5.0 A | iq_ref 被夹，不报故障 | ✅ 30082 float 12（0.05~5 A） |
| **温度降额** | derate × 限幅 | iq_ref 被夹，不报故障 | ❌ 按温度自动 |
| **超速保护** | **31.4159 rad/s = 300 rpm**，消抖 8 拍（0.4 ms） | `fault=0x0020`，MOE 封锁 | ❌ 固定值 |
| **死区（deadman）** | 2 s 内没收到 30025 | 输出封锁，`en` 归 0 | ❌ |

### ⚠️ 空载时它一定会超速

本机 J = 0.6835e-4 kg·m²、Kt = 0.0916 N·m/A：

```
加速度 a = Kt·iq/J ≈ 1340 rad/s² 每 1 A
即 iq = 0.1 A → 134 rad/s²，到 300 rpm 只要 0.23 s
   iq = 1.0 A → 1340 rad/s²，到 300 rpm 只要 23 ms
```

**所以空载/轻载下给力矩，几十到几百毫秒就会触发超速保护。**
这不是故障，是力矩模式（无速度环）的必然结果。

- 台架验证：把 `cur_iqmax` 压到 **0.05~0.1 A**，只给短脉冲（<0.2 s）
- 实际使用：必须带负载（谐波关节接机构），或用 MIT 模式（有刚度/阻尼，不会飞）

## 5. 标准下发流程

```python
import time
from mavlink_link import SerialLink

lk = SerialLink(); lk.connect("COM27", 921600); time.sleep(1.5)
lk.set_permission(0, 0)                    # 30068，必须先做

# 1) 清故障
if lk.ctrl_status()["fault"]:
    lk.action(3); time.sleep(0.5)

# 2) 确认前置：cal / z
st = lk.ctrl_status()
assert st["cal"] == 1 and st["z"] == 1, "需先做 C（电流零点）与 Z（电角度）"

# 3) 先停稳（余速 < 270 rpm，否则会被拒）
lk.set_keepalive(False)
lk.set_controlword(0x06, halt=1); time.sleep(0.8)

# 4) 切力矩模式
lk.set_mode(4); time.sleep(0.3)

# 5) 限幅与斜坡（可选，建议台架先压小）
lk.dbg_write(floats={"cur_iqmax": 0.5})        # 30082 float 12
lk.torque_cmd(ramp_ms=20)                      # 30095：iq 斜坡 20 ms

# 6) 给 iq —— 这一帧会自己完成装配并起转
lk.set_torque(0.30)                            # 30025，±5 A
time.sleep(0.05)
lk.set_keepalive(True, 4, 20.0)                # ★ mode=4，deadman 2 s

# 7) 读反馈
q = lk.ctrl_status()
print("iq=%.3f A  iq_ref=%.3f  rpm=%.1f  T≈%.3f N·m"
      % (q["iq"], q["iq_ref"], q["rpm"], q["iq"] * 0.0916))

# 8) 收尾
lk.set_keepalive(False)
lk.set_controlword(0x00, 0)
```

## 6. 两种使能顺序（语义不同，都合法）

| 顺序 | 结果 |
|---|---|
| **先给 iq，再 `cw=0x0F`** | 发 30025 那一帧就自己起环出力；`cw` 到达时 `armed` 已是 1，走幂等返回，**不会清零** |
| **先 `cw=0x0F`，再给 iq** | `cw` 用 **iq = 0** 起环（安全初值），之后 30025 只改给定 |

> **重使能不会回到上次出力**（2026-11-21 修）：`cw` 使能一律用安全初值起环
> —— 力矩 0、速度 0、位置=当前角。`s_iq_valid` 只作"曾经收到过给定"的历史记录。
> 所以"点启动之后电机自己按上次 iq 冲出去"这种情况不会发生。

## 7. 反馈与力矩换算

`30090` 相关字段：

| 字段 | 偏移 | 含义 |
|---|---|---|
| `iq` | f[0]@4 | **实测** q 轴电流（A） |
| `iq_ref` | f[1]@8 | **斜坡后**的给定（A，已含限幅与降额） |
| `rpm` | f[2]@12 | 机械转速（rpm） |
| `ktc` | f[7]@32 | Kt 温度补偿系数（1.0 = 冷态） |
| `en` / `fault` | flags bit2 / @36 | 使能、故障位 |

**力矩换算**：

```
Kt(T) = 1.5 × pn × ψ × ktc        pn=14，ψ 从 30082 float 13 读（Wb）
T     = Kt(T) × iq
```

本机 ψ = 4.36 mWb、ktc = 1.0 → Kt = 0.0916 N·m/A。

> **iq 恒定但力矩会随温度下降**：ktc 在 84 °C 约 0.923，即同样 1 A 的力矩少 7.7%。
> 力矩模式给的是电流，不是力矩——要精确力矩需上位机按 ktc 反算 iq。

## 8. 指令逐条

### 8.1 30056 设模式（1 B，crc 26）

```python
lk.set_mode(4)          # payload: mode@0 = 4
```
应答 2 B：`status@0`、`mode@1`。

### 8.2 30054 使能/封锁（3 B，crc 108）

```python
lk.set_controlword(0x0F, 0)      # 使能（ion=1, rfd=1, eo=1, qs=1）
lk.set_controlword(0x06, halt=1) # 封锁
lk.set_controlword(0x00, 0)      # 关
```
`cw@0`(u16)、`halt@2`(u8)。**halt 优先且无拒绝路径。**

### 8.3 30025 给 iq（53 B，crc 191）— 主力指令

```python
lk.set_torque(0.30)              # idq_tar_A = [0.0, 0.30]
```
- 范围 **±5.0 A**，超范围回 `status=2`
- 应答 5 B：`status@0`、`iq 回读@1`（**协议层原值，不是限幅后的**）

> **判断"是否真被限幅"要看 `30090.iq_ref`**，不要看 30025 的回读。

### 8.4 30095 id 与 iq 斜坡（12 B，crc 95）

```python
lk.torque_cmd(ramp_ms=20)        # mask bit1，只改斜坡
lk.torque_cmd(id_a=0.0)          # mask bit0，只改 id
lk.torque_cmd(id_a=0.0, ramp_ms=50)   # mask=0x03，两项都改
```

| 项 | 偏移 | 范围 |
|---|---|---|
| `mask` | @0 | bit0=写 id、bit1=写 ramp |
| `id` | @4 | ±5 A（一般给 0） |
| `ramp_ms` | @8 | 0~2000 ms（0 = 直通） |

应答 10 B：`status@0`、`n_ok@1`、`id_eff@2`、`ramp_ms_eff@6`。

> id 一般保持 0。给正 id 会额外产生铜损而不产生力矩（除非做弱磁）。

### 8.5 30082 改 iq 限幅（192 B，crc 218）

```python
lk.dbg_write(floats={"cur_iqmax": 1.5})     # float 槽 12，0.05~5 A
print(lk.dbg_read()["floats"]["cur_iqmax"]) # 回读生效值
```

> 改小时会**立即**把当前 `iq_ref` 夹住，不会等斜坡慢慢降。

## 9. 故障与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| `30025` 回 `status=3` | 被 `do_current` 拒绝 | 依次查：`fault≠0` / `cal=0` / `z=0` / 辨识在跑 / 在速度模式 / **余速 >270 rpm** |
| `en` 一直 0 | 同上，拒绝是静默的 | 同上；`30090.cw` 也会保持旧值 |
| `fault=0x0020` 超速 | 空载出力加速到 300 rpm | 正常保护。加载 / 压小 `cur_iqmax` / 改 MIT |
| `fault=0x0001` 过流 | 硬件比较器 12 A 或软件 | 检查是否 `cur_iqmax` 设太大、负载卡死、相间短路 |
| iq 上不去 | `cur_iqmax` 太小 / derate 生效 | 读 `30090.iq_ref`；读 `30082` 的 `cur_iqmax` |
| 出力方向反 | 电角度零点 `z` 不对 | 重做 `Z`（action=5） |
| 2 s 后自己停 | deadman | 保活必须用 **`mode=4`**，10~20 Hz |

> **`30025` 是"只发不等应答"以外的**——它其实有应答（5 B），但 `set_torque`
> 走的是只发不等，`ok=True` 只代表帧发出去了。是否生效看 `30090.en` / `iq_ref`。

## 10. 常见误用

| ❌ 不要 | 原因 |
|---|---|
| 空载给 1 A 然后等它稳 | 23 ms 就撞 300 rpm，一定报超速 |
| 用 30025 的 `[0]`（id） | 固件不解析；id 走 30095 |
| 拿 30025 应答的 iq 判断是否限幅 | 那是协议层原值，限幅在内部 |
| 带余速直接切力矩 | 会被拒（270 rpm 门禁），先 `halt` 停稳 |
| 保活传 `mode=3` | 等于没保活，2 s 后封锁 |
| 认为 `iq` 就是力矩 | T = Kt(T) × iq，ktc 随温度变（84 °C 少 7.7%） |
| 期望力矩模式有摩擦/齿槽补偿 | 那是速度/位置/MIT 链的前馈，力矩模式是纯 iq |
