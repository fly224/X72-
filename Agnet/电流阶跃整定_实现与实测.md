# 电流阶跃整定：激励、测量与实测结论

> 2026-11-15 21:5x · 固件 Code **57288 B** / 0 Error 0 Warning
> 本文所有数字都来自实物（COM27，30.78 V 母线，空载减速器关节）

---

## 1. 为什么不能拿 100 Hz 遥测调电流环

| 项 | 数值 |
|---|---|
| 电流环带宽 | `Kp/L = 6283 rad/s ≈ 1 kHz` |
| 10%→90% 上升 | 实测 **150–250 µs** |
| 100 Hz 遥测周期 | **10 ms** |

一次阶跃在遥测里只落 1~2 帧，看到的是"跳变"，量不出上升时间、超调和阻尼。
所以激励与采样必须放进 20 kHz 控制节拍里，串口只回传算好的指标和抽取波形。

## 2. 实现

### 2.1 新增模块 `Board/cur_step.c/.h`

```
PRE  60 拍 = 3 ms   两轴给定 0（建立基线）
STEP 600 拍 = 30 ms 给定 = amp
结束 -> DONE，给定强制回 0，命令层封锁 MOE 并打印结果
```

顺序上必须**先取给定、后记实测**，否则指标会整体差一拍（50 µs）：

```c
if (CurStep_IsActive()) { CurStep_Refs(&id_ref, &iq_ref); }   // Park 之前
... Park / PI / 限幅 ...
if (CurStep_IsActive()) { CurStep_Push(id_now, iq_now, vd, vq); }  // 之后
```

### 2.2 指标怎么算（关键细节）

**原始电流不能直接算超调。** 2 A 时开关纹波的理论值：

```
ΔI = Vbus·D·(1-D)·Ts/L = 30.78 × 0.525 × 0.475 × 50µs / 113.5µH ≈ 3.4 A 峰峰
```

远大于阶跃幅度本身。所以 `CurStep_Push()` 里对实测先做 **4 拍滑动平均（200 µs）**，
控制律仍用原始采样（不受影响）。这一步做完，"超调"才从 34~63%（全是纹波）
降到 5~10%（真实值）。

| 指标 | 定义 | 注意 |
|---|---|---|
| `tr` | 首次 10% → 首次 90% | 分辨率 50 µs |
| `os` | (峰值/给定 − 1)×100 | 峰值取滤波后 |
| `ts` | 最后一次脱离 ±5% 后再连续 1 ms 在带内 | **带内噪声大时不可信，见 §6** |
| `ss` | 末 20% 平均 / 给定 − 1 | 最可靠的指标 |
| `pk` | 滤波后峰值 | |
| `vp` | 限幅后的 \|v\| 峰值 | 用来判断是否碰到电压限幅（约 16.5 V） |

### 2.3 波形

64 个**连续**采样点（50 µs/点，共 3.2 ms），足够看清上升沿和振铃。
早期版本按 0.9 ms 抽取，结果把 20 kHz 纹波混叠成"2.7 kHz 振荡"的假象——
这是本轮踩过的坑，见 §5。

## 3. 命令

| 键 | 作用 |
|---|---|
| `T` / `U` / `V` | iq 阶跃 / id 阶跃 / 双轴，幅值 `CMD_STEP_AMP = 2.0 A`，33 ms |
| `G` | 循环 Kp 缩放 0.50→0.75→1.00→1.25→1.50→2.00（Ki 不动） |
| `H` | 循环 Ki 缩放（Kp 不动） |
| `J` | 重发上次结果（不重跑） |
| `S` | 状态，含 `g=<kp_x>/<ki_x>`、`cur=`、`idq=` |
| `M` / `N` | 常驻电流模式 iq=±1 A（不带阶跃） |
| `C` / `Z` | 零漂标定 / 电角度对齐（阶跃的前置联锁） |

回显示例：

```
[CMD] STEP id amp=2.00A 33ms kp=0.71 kiTs=0.12
[STEP] id amp=2.00 tr=250us os=+4.80% ts=27100us ss=+0.01% pk=2.10 vp=1.69
[STEP] iq invalid (no rising edge)
[TRC] 0.00 2.000 0.011 0.000 -0.008
...
```

`ts=27100us` 不可信的原因见 §6；`tr/os/ss/pk/vp` 可用。

## 4. 实测结果

### 4.1 标称增益下的完整波形（2 A id 阶跃，Kp=0.713 / Ki·Ts=0.119）

```
t(ms)  id(A)          t(ms)  id(A)
0.00   0.011          0.15   1.951   ← 3 拍就到 90%
0.05   0.253          0.20   1.828
0.10   1.453          0.30   1.737
0.45   1.674          1.05   2.072
0.60   1.653          1.50   2.114
0.70   2.063          2.00   2.033
1.00   1.756          3.00   2.012
```

- 上升 **150 µs**（3 拍），超调约 **5%**，之后稳定在 2.0 A；
- 稳态段仍能看到 ±0.2 A 的波动，**与增益无关**（见 §4.3），是纹波采样残差。

### 4.2 增益扫描（2 A id 阶跃，Ki 固定 1.00×）

| Kp 缩放 | tr (µs) | os (%) | ss (%) | vp (V) |
|---:|---:|---:|---:|---:|
| 0.50 | 650 | +6.2 | +0.05 | — |
| 0.75 | 450 | +4.9 | −0.01 | — |
| **1.00** | **250** | **+4.8** | **+0.01** | **1.69** |
| 1.50 | 100 | +10.0 | −0.04 | 2.25 |
| 2.00 | 400 | +8.2 | +0.01 | 1.46 |

| Ki 缩放（Kp=1.00×） | tr (µs) | os (%) |
|---:|---:|---:|
| 0.50 | 1350 | +8.7 |
| 1.00 | **250** | **+4.8** |
| 1.50 | 150 | +19.0 |
| 2.00 | 150 | +9.0 |

**结论：现有整定值就是最优点**（tr 250 µs / os 4.8% / ss 0.01%，vp 1.69 V 远离限幅）。
把 Ki 加大到 1.5× 会让超调翻倍；把 Kp 加到 1.5× 只是把 tr 压到 100 µs 但超调也上去、
且电压用量增加 33%。**不需要改参数。**

### 4.3 后段峰峰值与增益无关 → 是纹波不是振荡

| Kp/Ki | 后段（t>1.6 ms）峰峰值 |
|---|---|
| 0.50/0.50 | 0.442 A |
| 0.50/1.00 | 0.391 A |
| 0.75/0.75 | 0.370 A |
| 1.00/1.00 | 0.451 A |

如果是不稳定引起的极限环，降一半增益必然显著减小；实测基本不变，
所以这是 **20 kHz 开关纹波在采样点的残留**，属于正常现象。

## 5. 三个必须知道的坑

### 5.1 1 A 的阶跃落在"死区主导区"

30.78 V 母线、0.42 Ω 绕组：1 A 只需 **0.38 V** 相电压，
而死区 `670 ns × 20 kHz = 1.34%` 对应的电压误差是 **0.41 V** —— 两者同量级。

后果（实测）：1 A 阶跃时 id 在 **0.67~1.14 A** 之间缓慢摆动，28 ms 都没稳定；
2 A 时（0.76 V > 0.41 V）立刻变干净。

⚠️ **开死区补偿反而更糟**：`du=1.34%` 的线性补偿在 1 A 处过补偿，
实测 os 从 8.5% 涨到 26%，最低掉到 −0.36 A。所以 `B` 保持默认 OFF。

### 5.2 iq 阶跃空载必然触发超速保护

`Kt = 1.5·p·ψ = 0.16 N·m/A`，1 A 空载下 33 ms 就能把电机推到 300 rpm 以上，
实测连续 5 次都返回 `f=0x20`（超速）。**整定请用 id 轴**（表贴式无转矩，转子不动）；
要测 iq 轴必须带负载或把幅值降到 0.3 A 以下。

### 5.3 波形不要抽取

第一版按 18 拍取一点（0.9 ms），把 20 kHz 的纹波混叠成了
"2.7 kHz、±10% 的持续振荡"，差点误判成环路不稳定并去改 L。
改成连续 64 拍后同一次阶跃一眼就能看出是"3 拍上升 + 纹波"。

## 6. 局限

1. **`ts`（调节时间）不可信**：判据是 ±5%，而 2 A 时滤波后仍有 ±0.1 A 级波动，
   偶尔越界就把 `ts` 顶到窗口末端（27~30 ms）。要修得把带宽放到 ±10%
   或改用 RMS 判据——本轮没做，因为 `os/ss/tr` 已经够用来判断整定好坏。
2. **`L = 113.5 µH` 未独立验证**。整定完全建立在这个值上；若实际偏差 2 倍，
   最优增益会跟着变。现在只能通过"扫增益找最优点"间接印证它没差太远。
3. **电流采样点的相位未验证**：2 A 时理论纹波 3.4 A 峰峰，实测只看到 0.4 A，
   说明采样相位稳定；但采样在开关沿附近还是零矢量中心，没有用示波器确认。
4. **只做了空载**：带载（尤其反向力矩、发电状态）时的行为未测。
5. **整定用的是 id 轴**，iq 轴因超速没能验证；两轴共用同一套参数，
   但如果 Ld≠Lq 明显（本电机按表贴式处理），iq 的最优值会不同。

## 7. 复现步骤

```bash
# 1) 标定 + 电角度对齐（脚本会自动判断要不要做）
python Agnet/cur_tune.py COM27 --axis id

# 2) 只看一次阶跃的完整波形
python Agnet/cur_tune.py COM27 --axis id --trace
```

脚本会：`D→X→(C)→(Z)→ 扫 Kp → 扫 Ki → 汇总表`，结束时自动 `D` 封锁。

手动方式：`C` → `Z` → `U`（id 阶跃）→ 看 `[STEP]` 与 `[TRC]` → `G`/`H` 改增益再 `U`。

## 8. 顺带修掉的一个串口缺陷

调这个功能时发现：**ASCII 回显在第一条之后就时有时无，甚至永久发不出**。

根因是 ASCII 与 100 Hz 遥测共用 `huart1` 的 HAL 状态机：

- 原来用 `HAL_UART_Transmit`（阻塞轮询）→ 遥测的 DMA TC 中断会在发送过程中把
  `gState` 置回 READY，于是 TIM6 又起一帧 DMA，两边同时写 TDR；
- 改成 `HAL_UART_Transmit_DMA` 也一样，只是把冲突换了个位置。

最终改为**完全绕开 HAL**：先让遥测暂停（`Telemetry_SetTxPause`），
再逐字节轮询 `TXE` 直接写 `TDR`，等 `TC` 后恢复遥测。
代价是一行 140 字符约 1.6 ms 占用主循环（不占 20 kHz / 1 ms 预算），
换来的是 6/6、8/8 稳定回显（可用 `python -c` 连续发 `S` 验证）。
