## 2. 为什么"先对齐电角度"是硬前提

编码器电角度由下式给出（与 `three_loop_deploy.c:51` 完全一致）：

```
th_e = 14*(dir*theta_m) + π/2 + 1.05e-3*(dir*omega_m)
```

其中 `theta_m` = 编码器单圈机械角 + `s_enc_zero`。**`s_enc_zero` 是 RAM 变量，复位即 0**，
而它在物理上代表"编码器零点与转子 d 轴的夹角"。零点未知时：

- Park 变换用的 d/q 轴与真实磁场**无关**；
- 给定 `iq>0` 产生的力矩方向是随机的 —— 之前实机飞车（`iq_tar=+9` 而 `-436 rpm`、退 2.7 圈）
  就是这个原因。

所以本版把"是否已对齐"做成了可查询状态，而不是靠人记：

```c
/* bsp_servo.c:590 */
void BspServo_SetEncoderZero(float zero_rad) { ...; s_enc_zero_ok = 1U; }
uint8_t BspServo_IsEncoderZeroed(void) { return s_enc_zero_ok; }   /* bsp_servo.c:595 */
```

`MotorIdent` 的成功路径（`finish_ok()`）会调用 `BspServo_SetEncoderZero()`，
因此 `Z` 成功一次即置位。

## 3. 实现

### 3.1 分支位置

`Servo_ControlTick()` 的分派顺序（`servo_isr.c`）：

```
故障          -> 回中 + 封 MOE + 退出电流模式           (line 262 起)
s_ol_en       -> 虚拟电角度 dq 电流环（辨识 Z 用）      (line 300 起)
s_cur_en      -> 编码器电角度 dq 电流环（本次新增）      (line 325 起)
其余          -> Simulink 三环模型                      (line 430 起)
```

辨识分支优先，所以 `Z` 期间即使误发 `M` 也不会抢占（`do_current` 另外会拒绝）。

### 3.2 参数（全部取自模型，20 kHz）

| 宏 | 值 | 来源 |
|---|---|---|
| `SERVO_CUR_KP` | 0.71314153 | `par_c[0]` = ωc·Ld，ωc = 2π·1000 |
| `SERVO_CUR_KI_TS` | 0.11890653 | `par_c[1]×par_c[2]` = 2378.186 × 5e-5 |
| `SERVO_CUR_VLIM_FRAC` | 0.5375 | `0.57735×0.95×0.98`，模型 `par_c[6..8]` |
| `SERVO_CUR_POLE` | 14 | `three_loop_deploy.c:51` 的 `14.0F` |
| `SERVO_CUR_ELEC_OFF` | 1.57079637 | 模型 `theta_off` |
| `SERVO_CUR_COMP` | **1.05e-3** | `14×1.5×50µs`；**初版误写 1.005e-3（差 4.5%），已改** |
| `SERVO_CUR_LD/LQ/PSI` | 113.5µH / 113.5µH / 7.593mWb | 模型 `par_c[3..5]` |
| `SERVO_CUR_IQ_MAX` | 5 A | 与模型 `par_c[10]` 一致 |
| `SERVO_CUR_WMAX` | 31.415927 rad/s（电机侧 300 rpm） | 本版新增保护 |

解耦与 BEMF 前馈与模型 `dec_mode=3` 一致：

```
ωe = 14·ωm
dec_vd = iq·ωe·Lq
dec_vq = id·ωe·Ld + ωe·ψ
vd = Kp·(0-id) + ∫ - dec_vd
vq = Kp·(iq*-iq) + ∫ + dec_vq
```

限幅用圆限幅 + 饱和时积分回退 0.98（与辨识分支同一套，已在实机验证过不炸）。

### 3.3 三道联锁 + 两道保护

`do_current()`（`servo_cmd.c:137`）在开口前逐条检查：

| 检查 | 拒绝时的提示 |
|---|---|
| 故障位 == 0 | `CUR refused: fault=0x.. (send X)` |
| 电流零漂已标定 | `CUR refused: current not calibrated (send C first)` |
| **电角度已对齐** | `CUR refused: elec angle not aligned (send Z first)` |
| 辨识未在跑 | `CUR refused: ident running (wait for IDENT ok)` |
| 已使能但不是电流模式 | `CUR refused: already ON in pos/vel mode (send D first)` |

进入顺序（有意为之）：

```
Servo_SetEnable(0)        // 先关掉模型三环
Servo_SetMode(POSITION)   // 让模型侧状态归位
Servo_SetPosRef(dir*theta)
Servo_SetCurrentMode(1, iq)
BspServo_PwmEnable(1)     // 最后才放 MOE
if (IsPwmEnabled()==0) 回滚
```

ISR 侧在 MOE=0（或 vbus<5 V）时**只保持中点并清积分**，所以放开 MOE 的那一拍
从零积分起步，不会出现"预积分 -> 开通即满电压"的冲击。

## 4. 离线验证（数值复算）

脚本：`Agnet/verify_cur_loop_math.py`（把 C 的控制律逐行等价复算，对象为 `di/dt=(v-R·i-e)/L`）

### 4.1 阶跃响应

```
iq_ref=+1.0 A: tr(10-90%)=250 us  超调=-0.0%  稳态 iq=+1.0000 (-0.00%)  id=-0.0015 A  峰值电压=0.8 V
iq_ref=-1.0 A: tr(10-90%)=250 us  超调=-0.0%  稳态 iq=-1.0000 (+0.00%)  id=-0.0015 A  峰值电压=0.8 V
```

- **250 µs** 对应 `3τ`，与 `ωc = Kp/L = 6283 rad/s (1 kHz)` 的理论一致；
- 1 A 只需 **0.8 V** 相电压，远低于 16.5 V 限幅，说明小电流测试不会碰限幅；
- 正负给定完全对称 —— 这正是"θ 没算反"的判据。

### 4.2 角度误差的影响（现场判据）

| 零点误差 | 稳态 iq | id 泄漏 | iq 幅值损失 |
|---:|---:|---:|---:|
| 0° | +1.0000 | −0.0015 | 0.00% |
| 2° | +0.9993 | −0.0368 | 0.07% |
| 5° | +0.9960 | −0.0897 | 0.40% |
| 10° | +0.9844 | −0.1771 | 1.56% |
| 20° | +0.9386 | −0.3470 | 6.14% |

`id ≈ iq·sin(误差)`。所以**上电后第一件事是看 `S` 里的 `idq`**：
`id` 超过 0.2 A 就说明零点没对齐（约等于 11° 误差），别急着加电流。

### 4.3 保护分支

```
vbus = 3 V：占空比固定 0.5 -> iq = 0.0000 A，无除零、无 NaN
```

（这条是实际存在的坑：`da = 0.5 + valpha/vb`，vb 很小时占空比会变成巨大值，
`(uint16_t)NaN` 是未定义行为。已在分支入口用 `vbus < 5 V` 挡住。）

### 4.4 超速保护的必要性

`Kt = 1.5·p·ψ = 0.1595 N·m/A`（1 A 约 0.16 N·m）：

| 转动惯量假设 | 空载 1 A 到 300 rpm |
|---|---:|
| J = 2e-4 kg·m² | 49 ms |
| J = 5e-4 kg·m² | 121 ms |
| J = 2e-3 kg·m² | 485 ms |

**力矩模式没有速度环，空载必然一直加速**，所以必须有 `SERVO_CUR_WMAX`。
即使最坏情况（J=2e-4）也留出约 49 ms ≈ 4 帧 100 Hz 遥测，够看阶跃与稳态。

### 4.5 静态核查（map / 反汇编）

```
映像符号：Servo_SetCurrentMode (84 B) / Servo_IsCurrentMode (12 B)
          Servo_GetIdqMeas (26 B) / BspServo_IsEncoderZeroed (12 B)
20 kHz 路径引用的数学例程：仅 __hardfp_cosf、__hardfp_sinf（单精度）
Servo_ControlTick 内 VSQRT.F32 数量：3（sqrtf 被内联成单条硬件指令）
映像内 __aeabi_d*（双精度辅助）：0
```

电流分支（`BspServo_RaiseFault` 判定 → `BspServo_SetDuty` 返回）**静态 109 条指令**，
其中两次单精度三角调用。按 20 kHz/8500 cyc 预算，估计占 **6–9%**；
辨识分支（同样是 cosf/sinf + PI）已在 20 kHz 下实机跑过约 9 s 未掉拍，可作旁证。
若要进一步压缩，可把这三处换成 CMSIS-DSP 的 `arm_sin_f32/arm_cos_f32`
（之前实测：double 三角 5170 cyc → 表查 30 cyc 量级），代价是 Flash +2 KB（table）与链接 DSP 库。

## 6. 实机操作手册（串口腾出后照此执行）

命令一览（`?` 可回读）：

```
C   电流零漂标定（MOE=0、转子静止，采 4000 次求平均）
Z   电角度辨识 ratio / dir / offset（约 9 s，结束自动封 MOE）
I   看辨识结果
M   电流模式 iq = +1.0 A（id = 0，编码器电角度）
N   电流模式 iq = -1.0 A
S   状态：en/moe/cal/dm/bias/i/f/cur/idq/clamp
D   立即封锁
X   清故障（含过流峰值留证）
```

### 步骤

| # | 发什么 | 期望回显 | 不通过怎么办 |
|---|---|---|---|
| 1 | `C` | `[CMD] cal ok bias=…` 且电流回到 ±0.05 A | 检查电机是否真的静止 |
| 2 | `X` | `fault cleared` | — |
| 3 | `Z` | `[CMD] IDENT ok ratio≈14 pn=14 dir=±1 off=… zero=…` | 见 §7 表 |
| 4 | `I` | `resid < 0.15`、`bad=0` | `resid` 大 -> 把稳定时间从 60 ms 加到 100 ms |
| 5 | `M` + 每 0.3 s 一个 `S` | `cur=1`、`idq` 的 `iq≈+1.00`、`id≈0`、`moe=1`、`f=0x00` | `id` 偏大 -> 回步骤 3 |
| 6 | `N` | `iq≈−1.00`、`id≈0` | 只在一个方向对 -> θ 符号错 |
| 7 | `D` | `OFF (user) moe=0 en=0` | — |

**判据**（离线复算给出的阈值）：

- `|iq − iq_ref| / iq_ref < 5%`（仿真 0.00%，留采样与零漂余量）；
- `|id| < 0.15 A`（对应零点误差 < 8°）；
- `f == 0x00`、`moe == 1`；
- 正负给定时 `iq` 符号跟随、幅值对称。

**异常处置**（按优先级）：

| 现象 | 含义 | 动作 |
|---|---|---|
| 一进 `M` 就 `f=0x01` | 过流（>12 A 持续 400 µs） | 立即 `D`；查 `ovc=` 的 raw 码值，`raw` 接近 0 或 4095 = 采样/驱动异常 |
| `f=0x20` | 超速（>300 rpm） | 正常保护；`X` 后可减小 `CMD_CUR_TEST` 再试 |
| `id` 明显不为 0 | 零点不对 | 重跑 `Z`，并确认 `dir` 与之前一致 |
| `iq` 符号反、`id` 也大 | `dir_sign` 与实际相序相反 | `Z` 会重新给出 `dir`；若仍反，检查三相接线 |
| `cur=1` 但 `iq≈0` | 电流环没输出 | 查 `moe` 是否 1（0 则 MOE 未开）与 `f` |

## 7. 局限（必须知道）

1. **未实机验证**。全部结论来自数值复算 + 静态核查；真实带宽、噪声、死区影响要上板才知道。
2. **零点、零漂、dir 都只在 RAM**。每次复位要重做 `C` + `Z`；量产必须存 Flash 或开机自动对齐。
3. **`dir=−1` 时遥测的电角度字段仍是原始符号**。本次只修了 `idq_now` 的 Park 角
   （`telemetry_tx.c:197`），`30025 +20 elec_theta_rad` 与 `30040 +8` 未乘 `dir`。
   当前实测 `dir=+1`，不影响；换相序后需要一并改。
4. **没有位置/速度环**。这是纯力矩模式，只用于验证电流环；要定位仍用 `E`/`F`/`P`。
5. **`Kt`、`J`、`Tf` 是估算值**（`Kt=0.16 N·m/A`，J=2e-4~2e-3）。超速时间只能给量级。
6. **`sinf/cosf` 仍是库函数**（`__hardfp_sinf` 静态 700 条指令）。要在 20 kHz 里省周期，
   可换 `arm_sin_f32/arm_cos_f32`（未做，属优化项）。
7. **死区补偿默认关闭**。之前实测开补偿反而恶化（0.10 rpm vs 3.00 rpm），原因写在
   `Agnet/20kHz回归与参数化改造.md`。电流闭环下若要重开，需先测出真实 `comp_du`。
8. **无过温保护**：温度只显示，未参与降额/停机。
