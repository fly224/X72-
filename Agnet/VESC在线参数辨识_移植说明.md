# VESC 在线参数辨识移植：R 与 L

> 2026-11-16 · X72 / STM32G474CEU6 · 固件 `Code=66788 RO=3812 RW=104 ZI=10072`，0 Error 0 Warning
> 参考：`D:/OpenSourceLibrary/bldc-master`（vedderb/bldc）

## 1. 结论

| 参数 | 辨识值 | 模型值 | 万用表 | 判读 |
|---|---|---|---|---|
| 相电阻 R | **395.7 ~ 405.1 mΩ** | 378.5 mΩ | 420 mΩ | 落在两者之间，跨注入幅值一致，可信 |
| dq 电感 L | **80.1 ~ 80.7 µH @1.55 A** | 113.5 µH | — | 模型偏大 30%，且 L 随电流明显饱和 |

重复性：R ±1.2%，L ±0.4%（连续两次）。

**L 不是常数**，实测饱和曲线：

| 注入电压 | 电流幅值 | R | L |
|---|---|---|---|
| 0.6 V | 0.87 A | 407.0 mΩ | 87.9 µH |
| 1.0 V（默认） | 1.56 A | 409~412 mΩ | **77.8 µH** |
| 1.5 V | 2.54 A | 400.1 mΩ | 69.0 µH |
| 2.5 V | 4.55 A | 401.0 mΩ | 59.0 µH |

线性外推零电流 **L₀ ≈ 95 µH**。模型的 113.5 µH 更像是没考虑饱和的小信号值。

**独立佐证**：电流环实测阶跃 `tr = 250 µs`，对应闭环带宽约 1.4 kHz；而模型 Kp = ωc·L 是按 1 kHz、113.5 µH 算的。若 L 真是 113.5 µH，带宽应该只有 1 kHz（tr ≈ 350 µs）。实测更快，正说明真实 L 更小 —— 与 70~80 µH 的测量结果一致。

## 2. 移植映射

| 项 | VESC（`motor/mcpwm_foc.c`） | X72（`Board/motor_rl_ident.c`） |
|---|---|---|
| R 入口 | `mcpwm_foc_measure_resistance()` `:1783` | `@` 命令 → `RlIdent_Start()` |
| R 激励 | 虚拟角锁 0，`m_iq_set = current` | `Servo_SetOpenLoop(1, 0, id)` |
| R 斜坡 | 200 步 × 1 ms `utils_step_towards` | 200 ms 线性斜坡 |
| R 稳定等待 | 50 ms | 100 ms（电流环带宽 1 kHz，留足转子锁定时间） |
| R 采样 | `avg_current_tot += |i|`、`avg_voltage_tot += |v|`（20~200 点） | 50 点 × 1 ms |
| R 计算 | `R = voltage_avg / current_avg` | 同 |
| L 入口 | `mcpwm_foc_measure_inductance()` `:1895` | 同 `@` 流程的第二段 |
| L 激励 | **HFI 六矢量高频注入 + FFT bin0/bin2** | **1 kHz 单频电压注入 + 单点 DFT** |
| L 计算 | `Ld = 1/(offset+amp)`、`Lq = 1/(offset−amp)`，再 ×0.9 修正 | `|Z| = V/I`，`L = √(|Z|²−R²)/ω` |

**关键差异**：VESC 的 L 测量依赖它自己的 `m_hfi` 模块（六矢量注入、专用采样时序、FFT 的 bin0 与 bin2 分别取 1/L 均值与二次谐波来分离 Ld/Lq）。X72 没有这套基础设施，硬搬等于重写一个 HFI 观测器。所以 L 段是**同原理的简化实现**，不是逐行移植。

R 段则是逐行等效移植，包括"用矢量模长而不是单轴"这个细节——这样不必关心 dq 轴分配。

## 3. L 为什么不能照搬，又为什么不能用阶跃

### 3.1 第一版：d 轴阶跃 + 逐点差分（失败）

思路：`v = R·i + L·di/dt` 在任何时刻都成立，给 2 A 阶跃，20 kHz 记录 64 拍，逐点解 `L_k = (vd_k − R·i_k)/(di/dt)_k`。

实测失败：

| 斜率门限 | 有效点 | L | 离散度 |
|---|---|---|---|
| 800 A/s | 27 | 40.9 µH | 61.6% |
| 3000 A/s | 4 | 76.9 µH | 71.1% |

两个问题：
- 门限 800 时，**稳态噪声被当成斜率**：电流噪声 ±0.05 A / 50 µs = 1000 A/s，超过门限，于是"电流没动"的点全被收进来，L 变成噪声除噪声。
- 门限 3000 时只剩 4 个点。根因是 **L/R = 300 µs**，20 kHz 采样下整个上升过程只有 4~6 拍，逐点差分没有分辨率可言。

离线仿真也证实算法本身有偏：理想模型（R=0.38、L=113.5 µH、同样的电流环）跑一遍，拟合出 140.1 µH，偏大 23%。

### 3.2 第二版：1 kHz 电压注入 + 单点 DFT（成功）

这正是 VESC 用 HFI 的原因：**在高频下测 ωL 而不是时域瞬态**。

- ω = 2π × 1000 Hz → ωL = 0.713 Ω，与 R ≈ 0.40 Ω 同量级，两者都能从 |Z| 里分辨
- 频率再低，ωL 被 R 淹没；再高，20 kHz 采样每周期点数不够（1 kHz 正好 20 点/周期）
- 注入 3 个**整周期**（60 拍），单点 DFT 在整周期上才正交，否则有频谱泄漏

`Board/servo_isr.c` 新增一个独立分支：

```c
s_olv_ph += s_olv_dph;                       // 每拍 +2π·f·Ts
vdin = s_olv_amp * sinf(s_olv_ph);
da = 0.5f + (vdin / vbus);
db = dc = 0.5f - (0.5f * vdin / vbus);       // θ=0 的 Clarke 逆变换
RlIdent_PushInject(s_iu, s_olv_ph);          // θ=0 时 id = iα = iu
```

**必须绕开电流环**：PI 会把外部注入的正弦当扰动压掉，那样测到的是控制器的抑制比，不是电机的 |Z|。

计算：

```c
sc = Σ id·cos(ph);  ss = Σ id·sin(ph);
I_amp = 2/N · √(sc² + ss²);
|Z|   = V_amp / I_amp;
L     = √(|Z|² − R²) / ω;
```

效果：离散度从 71% 降到 **0.59%**（60 点全用上），重复性 ±0.4%。

## 4. 命令

| 键 | 作用 |
|---|---|
| `@` | 启动 R/L 辨识（约 0.4 s，转子被磁场锁住不会转） |
| `#` | 循环注入幅值 0.6 / 1.0 / 1.5 / 2.5 V（下次 `@` 生效，用于看饱和） |

回显示例：

```
[CMD] RL ok R=405.09mohm L=80.12uH Z=0.65ohm iamp=1.55A n=60 |v|=0.81V |i|=2.00A moe=0
```

`Z` 与 `iamp` 是中间量：`iamp = V_amp / |Z|`。如果 `iamp` 明显偏离预期（1 V 注入却只有 0.1 A），说明接线/限流有问题。

结果自动进 Flash（`PS_FLAG_RL`），`S` 的 `fl=1` 即可确认。

## 5. 与既有参数的关系

辨识出的 R/L **没有自动改写电流环增益**，这是有意的：

- 若按实测 L=80 µH 重算 `Kp = ωc·L`，带宽会从当前的约 1.4 kHz 降到设计的 1 kHz，**性能反而下降**；
- 而且改了固件常量不改 `three_loop_params.m`，模型和代码两处参数会悄悄失配。

所以当前策略是：辨识值只做记录与对照，要不要改由人决定。真要改，两处必须同时改：

```
SERVO_CUR_KP = ωc·L        (motor_rl_ident 的 L)
SERVO_CUR_KI_TS = ωc·R·Ts  (motor_rl_ident 的 R)
```

## 6. 局限

| 项 | 现状 |
|---|---|
| **只测平均电感** | 注入走 d 轴，测的是 Ld；`Ld = Lq` 是表贴式的假设。要分离 Ld/Lq 需要 VESC 那样的二次谐波（FFT bin2），本轮没做 |
| 死区影响 | 注入 1.0 V 时死区约 0.18 V，占 18%，会抬高 |Z|、进而抬高 L。所以 80 µH 可能仍偏大几个百分点 |
| 饱和 | L 是工作点相关量，80 µH 对应 1.55 A。做弱磁或大电流控制时要用对应工作点的值 |
| R 的温漂 | 铜电阻随温度约 +0.4%/K，冷机 400 mΩ 在热机后可能到 450 mΩ |
| Ld/Lq 分离 | 未做，需要 FFT 或两次不同角度的注入 |
