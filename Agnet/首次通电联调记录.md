## 1. 已修的四个问题（按发现顺序）

### 1.1 位置给定恒为 0 → 使能即满力矩

`Servo_SetPosRef()` 从来没有调用者，`s_pos_ref` 停在 `Servo_Init()` 里的 `0.0f`。位置模式下误差 = `0 − θ`，乘 50.27 直接顶到 ±120 rad/s，电流给定被限幅到 **±9 A**。

实测：`iq_tar=−9.000`、电流尖峰 −16.7 A（`raw=1417`）、400 µs 后过流跳闸。

修：使能前 `Servo_SetPosRef(BspServo_GetThetaCached())`，让误差≈0（`iq_tar` 从 −9 降到 −0.128）。

### 1.2 单点噪声就跳闸

MOE=0 时电流很干净（±0.03 A），但 50 µs 节拍里会采到开关瞬间的单点尖峰。修：连续 8 次超阈值才判故障（400 µs）。

### 1.3 开通冲击被误判（以及修过头）

MOS 从全关到 50% 的第一个周期，会给相间电容充电，采到 −11~−13 A 的瞬态。加了开通消隐。

**第一版给了 20 ms —— 结果把一次真实的 43.8 A 飞车冲击整段遮住，`fault` 仍是 0x00。**已改为 **2 ms**（开通瞬态实测只有几十 µs）。

> 教训：消隐窗口不能长到能盖住真实故障。窗口宽度应当由"瞬态持续多久"决定，不是"我希望别误报"。

### 1.4 `PwmEnable` 静默失败

`BspServo_PwmEnable()` 是 `void`，故障位非 0 时静默拒绝置 MOE，但调用方以为成功了（`en=1 moe=0` 的矛盾状态）。

修：使能后回读 `BspServo_IsPwmEnabled()`，没开就报错并回滚 `en`。

## 2. 两次通电实测

### 2.1 第一次（位置未贴齐）

```
E  → iq_tar=-9.000  rpm=-0.0  dPulse=-178   f=0x01  ovc=-16.7/-15.4 raw=1417/1419
```

过流跳闸，MOE 被封锁。根因见 1.1。

### 2.2 第二次（贴齐 + 消隐）

```
E  → iq_tar=+9.000  rpm=-301.5  dPulse=-2,852,283
S  → iq=+2.048      rpm=-436.5  iw=+3.18        ovc=-43.86/-27.36 raw=406/976
```

**电机飞转 −436 rpm、位置退 2.7 圈、峰值电流 43.8 A，且因消隐窗口过长未跳闸。**

诊断：`iq_tar` 是**正**满力矩，电机却往**负**方向跑 → 力矩方向与角度反馈不一致。

根因：`BspServo_SetEncoderZero()` **从来没有调用者**，`s_enc_zero` 一直是 0。编码器读数到转子 d 轴电角度的映射从未标定，Park 变换用的 θ 与磁场方向无关。

> 这也是"功率级正常"的证据：它能在 −436 rpm 上输出 43.8 A。

## 3. 电角度对齐（已实现，未成功）

新增开环矢量分支（`Servo_SetOpenLoop`，跳过模型直接写三相占空比），`Z` 命令走状态机：

```
1) 检查 MOE=0 / 已标定 / 无故障
2) 给电角度 0 的固定矢量，PwmEnable(1)
3) 等 400 ms 让转子吸合
4) 读 GetThetaCached() → s_enc_zero = -θ（归一化）
5) PwmEnable(0)，退出开环，打印结果
```

实测两次：

| amp | 电流峰值 | 转子位移 | 结果 |
|---|---|---|---|
| 4% | −1.55/−1.68 A | **72 脉冲（0.012°）** | 几乎没动 |
| 8% | −4.05 A | **23 脉冲（0.004°）** | 仍然没动 |

### 卡在哪

电机绕组 **0.42 Ω**。电压开环给 8% × 30 V = 2.4 V → 电流 5.7 A（实测 4 A），力矩推不动减速器；
再往上加（12% → 8.6 A、30% → 21 A）就直接顶到 12 A 跳闸线。

**低阻电机注定"电压开环"没有可用工作点** —— 要么力矩不够，要么过流。

### 两条出路

1. **降母线电压**（最省事）：把母线降到 6–12 V，占空比给 50%×30V 等效能量的电压，电流自然受限，力矩却足够。需要可调电源或串联限流电阻。
2. **实现电流闭环对齐**（正统做法）：在**虚拟电角度**（不是编码器角度）下跑 id=2A / iq=0 的电流环，电压矢量方向由虚拟角度决定，电流由 PI 限制。约 40 行，可以参考模型里的电流环参数（Kp=0.713、Ki=2378.18）。

### 3.1 已实现电流闭环对齐（14:06–14:09）

按用户选择走第 2 条。开环分支改为虚拟角度下的 dq 电流环：

```
ialpha = iu
ibeta  = -(iu + 2·iw)/√3          (由 iv = -(iu+iw) 推得)
id =  cos(te)·ialpha + sin(te)·ibeta
iq = -sin(te)·ialpha + cos(te)·ibeta
vd = Kp·(id_ref−id) + ΣKi·Ts·err    Kp=0.713  Ki·Ts=0.04（模型是 0.119，放慢 3 倍）
限幅 |v| ≤ 0.20·vbus                （2 A 稳态只需 0.84 V，留 7 倍余量）
逆 Park → 三相正弦调制 → 占空比
```

三次迭代：

| 版本 | 现象 |
|---|---|
| 直接给 2 A 阶跃 | 转子转 **−0.87 圈**，电流冲到 **40 A** 过流。根因：Ki 太快，2 ms 就把电压顶到限幅 |
| 降 Ki + 降限幅（0.45→0.20） | 位移降到 **−0.041 圈**，接近"吸合"而非飞转 |
| 加 200 ms 电流斜坡 | 同上，且平稳 |

同时修掉一个真 bug：`Servo_SetOpenLoop()` 原来**每次调用都清积分器**，做电流斜坡（每 1 ms 调一次）时积分永远建不起来 —— 改成只在 `0→1` 跳变时清。

### 3.2 关键进展：使能不再飞车

对齐拿到零点（`th=14.70° → zero=345.30°`）后再使能：

```
E  → iq_tar=+2.365   rpm=0.0   dPulse 变化 -106 脉冲
```

对比之前的 `iq_tar=±9.000` + −436 rpm + 2.7 圈，**位置环现在是稳定的保持力矩**，零点标定方向是对的。

### 3.3 但仍有 47 A 过流，且转子不转

```
S → f=0x01  ovc=-47.49/-14.60  raw=271/1450
```

`raw=271` → 0.218 V。正常偏置 1.64 V，被拉到 0.218 V，对应 **−47 A**。

**特征分析**：47 A 却不产生任何转动（`dPulse` 只变 1 脉冲）。如果是对齐/控制输出大电压，转子必然被推动（前面 −0.87 圈就是证据）。"大电流 + 不转"更像是：

- 上下桥臂直通（死区不足 / 自举不足 / 驱动异常）
- 相间或相对地短路
- 采样通道被开关噪声拉死（但这个幅度 1.42 V 太大，不像纯噪声）

**结论：问题已不在软件层，必须上示波器。** 本轮到此停止盲试。

## 7. 硬件排查建议（软件已到位，剩下靠示波器）

| 顺序 | 测什么 | 判据 |
|---|---|---|
| 1 | 断电，万用表测 U/V/W 相间与相对地电阻 | 三相基本对称（约 0.4~0.8 Ω）；对地无穷大。若某相明显偏低 → MOS 击穿 |

| 3 | `E` 使能瞬间抓 U 相下管 Vds 与相电流 | 看是否有直通尖峰（Vds 同时为低） |
| 4 | 给 `Z` 对齐（id=2A），抓三相电流波形 | 应为稳定的直流偏置（不是振荡/尖峰）；若振荡 → 电流环或采样有问题 |
| 5 | 检查自举电容与驱动供电 | 上管驱动电压不足会导致半周期丢失 → 大电流但不转 |
