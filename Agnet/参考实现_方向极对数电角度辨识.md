---

## 0. 一句话结论

三个算法**共用同一个套路**：把电流环的 θ 换成**自己生成的虚拟电角度**，d 轴给电流产生磁场，转子被磁场拖着走；一边给角度一边读编码器，从"电角度走一圈、编码器走多远"反推参数。

| 算法 | 判据 | 结果写到哪 |
|---|---|---|
| 方向 | 电角度走 1 圈，编码器计数**增/减** | `current_ctl_config.phase_dir`（负则取反 UVW） |
| 极对数 | 每个电周期 `pn = 编码器每转线数 / Δ计数`，累加 4 次取平均 | `pmsm_config.pn` + `motor_pos_sensor_config.pn` |
| 电角度 | 固定 0° 吸合 → 正/反各偏移 0.5 rad 再回零 → 两次读数取平均 | `motor_pos_sensor_config.elec_angle_bias_rad` |

**关键前提**：三者都要求电流环能接受"外部给定的 θ"，而不是必须用编码器算出的 θ。X72 现在没有这个能力（`Z` 只能静态吸合），这是要先补的。

## 2. 共同基座：虚拟电角度 + d 轴电流

三个 Step 函数里都有这几行（以方向辨识为例）：

```c
axis->current_ctl_input.elec_angle_speed_rad_s = 0.0f;
axis->current_ctl_input.elec_theta_rad = axis->direction_id_output.elec_angle_tar_rad;  // ← 虚拟角度
axis->current_ctl_input.idq_tar_A[0]   = axis->direction_id_config.id_tar_max_A;        // ← d 轴电流
axis->current_ctl_input.idq_tar_A[1]   = 0.0f;                                          // iq = 0
axis->current_ctl_input.mode           = 1;   // 电流控制模式
```

要点：

- `elec_theta_rad` **由辨识模块生成**，不是 `motor_pos_sensor` 算出来的 → 所以不依赖零点标定，也不依赖极对数。
- `idq_tar[0]` 是 **d 轴**给定，`iq = 0`：磁场方向与虚拟电角度严格一致，转子被吸向该方向。
- 电流给定一般取电机额定电流（`get_app_Motor_rated_current()`）。

## 3. 方向辨识

### 3.1 算法

```c
/* 每拍（20 kHz 或电流环频率）执行 */
theta = mod2pi(theta + config->elec_angle_add_rad);

/* 检测 2π 回绕：本拍角度比上拍"跳回"超过 90° 即认为刚过 2π */
wrapped = (theta - theta_prev <= -PI/2);

if (wrapped) {
    if (step > 1) {                       /* 第 1 次不计（编码器基准还没建立） */
        int64_t d = enc_sum - enc_prev;
        if      (d > 0) { dir = +1; state = FINISH; }
        else if (d < 0) { dir = -1; state = FINISH; }
        else            { dir =  0; state = RUN;    }   /* 没动，再转一圈 */
        enc_prev = enc_sum;
    }
    step++;
}
theta_prev = theta;
```

完成时（`motor_ctl_sm.c`）：

```c
if (direction == -1) {
    axis->current_ctl_config.phase_dir = -axis->current_ctl_config.phase_dir;  /* 取反 UVW 相序 */
}
```

### 3.2 判据依据

虚拟电角度匀速转一圈，理想情况下转子转过 **1/pn 圈**（一个电周期），编码器计数应单调同向。
若计数反向 → 说明"电角度增加的方向"与"编码器计数增加的方向"相反 → UVW 相序需要取反。

### 3.3 注意

- 只判断符号，不看幅值，所以**不需要知道极对数**。
- `d == 0`（转子卡住或电流太小）会继续转圈重试，不会误判。
- 圈数默认 1 圈就够；工程里 `step > 1` 的判断意味着**实际要 2 次回绕**（第 1 次建基准，第 2 次判定）。

## 4. 极对数辨识

### 4.1 算法

与方向辨识同一个角度斜坡 + 回绕检测，每次回绕算一个样本：

```c
if (wrapped) {
    int64_t d = enc_sum - enc_prev;
    if (d != 0) {
        pn = (uint32_t)roundf((float)enc_line_p_n / (float)d);   /* ★核心公式 */
    } else {
        pn = 1;                                                   /* 异常保护 */
    }
    enc_prev = enc_sum;
}

/* 累加平均 */
if (step + 1 > 4) {
    pn_id     = (uint32_t)roundf((float)(pn_sum + pn) / (float)step);
    state_now = FINISH;
} else {
    pn_id     = pn_sum;
    state_now = RUN;
}
pn_sum += pn;
step++;
```

结果落地：

```c
axis->pmsm_config.pn            = pole_pairs_id_output.pn_id;
axis->motor_pos_sensor_config.pn = axis->pmsm_config.pn;
```

### 4.2 公式推导

- 电角度转 2π = 机械角转 `1/pn` 圈
- 编码器走 `Δcount = enc_line / pn`
- 所以 `pn = enc_line / Δcount` ✓

其中 `enc_line_p_n` 是**编码器每转脉冲数**（MT6835 为 2²¹ = 2,097,152）。

### 4.3 四个坑

1. **必须先做方向辨识**：公式用的是 `enc_line / d`，若 `d < 0`（相序反），`pn` 会算成负数 → 被 clamp 成 0 → 辨识失败。
2. **平均次数是 4**（`step+1 > 4` 才收尾），即至少转 5 个电周期，噪声才被压下去。
3. **`pn = 1` 的兜底很危险**：`d == 0` 时给 1，若真卡住会一路累加 1，最后平均出错误结果。移植时应改成"丢样本 + 超时失败"。
4. **取整误差**：`round(enc_line/d)` 在 `d` 很小时（低速、丢脉冲）会放大误差。工程里靠 4 次平均 + 额定电流保证转速，低速时慎用。

## 5. 电角度辨识（真正的实现）

### 5.1 状态机（手写在 `motor_ctl_sm.c: ElecAngleIdStep`）

| 阶段 | `elec_theta_rad` | 动作 |
|---|---|---|
| 搜索（`state < STABLE_INCENTIVE`） | 固定 `0` | `id = id_max_A`，计时满 `wait_time_s × 3` 后进入下一阶段 |
| step 0 | — | 准备，记 step=1 |
| step 1 | `+= angle_add_rad` 直到 `>= +test_angle_rad` | 正向逼近（默认 0.5 rad） |
| step 2 | `-= angle_add_rad` 直到 `<= 0` | 退回零点 |
| step 3 | 固定 `0` | 等 `wait_time_s` 稳定 → `buff[0] = elec_angle_now_rad` |
| step 4 | `-= angle_add_rad` 直到 `<= -test_angle_rad` | 负向逼近 |
| step 5 | `+= angle_add_rad` 直到 `>= 0` | 退回零点 |
| step 6 | 固定 `0` | 等 `wait_time_s` 稳定 → `buff[1] = elec_angle_now_rad` → 计算 bias → FINISH |

### 5.2 偏置计算（含跨零处理）

```c
if (fabsf(buff[1] - buff[0]) >= PI) {
    /* 两次读数跨过 0/2π 边界（一个接近 2π、一个接近 0） */
    bias = (buff[0] + buff[1] + 2*PI) * 0.5f;
    if (bias >= 2*PI) bias -= 2*PI;
} else {
    bias = (buff[0] + buff[1]) * 0.5f;
}
config.elec_angle_bias_rad = bias;
```

### 5.3 为什么正反各来一次

转子从"正向接近 0"和"负向接近 0"停下来的位置不一样 —— 差一个**摩擦/齿槽造成的滞后**。两次取平均把这个滞后消掉，比单向吸合准一倍。

> 这正是 X72 现在缺的：`Z` 只是静态吸合到 0，没有正反向逼近，所以零点带着摩擦误差。

### 5.4 电角度公式与 bias 的符号

`motor_pos_sensor.c`：

```c
elec_angle_now_rad = enc_counts / enc_line_p_n * 2π * pn - elec_angle_bias_rad;
/* 再归一化到 [0, 2π) */
```

所以 **bias 是"被减掉的电角度偏移"**，辨识时转子在真实电角度 0：

```
0 = enc × 2π/enc_line × pn − bias   →   bias = enc × 2π/enc_line × pn
```

### 5.5 两个必须注意的实现缺陷

1. **bias 是覆盖而不是累加**：`config.elec_angle_bias_rad = bias_new`，而 `buff[]` 读的是"已扣除旧 bias"的 `elec_angle_now_rad`。
   若旧 bias ≠ 0，新值 = `bias_true − bias_old`，**重复辨识会累积漂移**。
   → 移植时要么辨识前把 bias 清零，要么改成 `bias_new = bias_old + buff_avg`。
2. **默认参数全是 0**：`wait_time_s`、`test_angle_rad`、`angle_add_rad` 在代码里没有任何赋值，`grep` 不到默认值，mavlink 的 motor config 里也没有这些字段。
   后果：`wait_time_s × 3 = 0` → 吸合阶段立刻跳过；`test_angle_rad = 0` → 偏移条件立刻满足 → 整个流程空转。
   **这套算法在他们工程里等于"写完了但没调通"。**

## 6. 移植到 X72 的参考实现

X72 已有的基础：`Servo_SetOpenLoop(en, theta_e, id_ref_a)`（虚拟电角度 + dq 电流环，本轮刚做完）、`BspServo_GetPosSum()`（累积脉冲）、`Servo_SetOpenLoop` 内部已限幅。

### 6.1 参数

```c
#define ID_ENC_LINE       (2097152.0f)  /* MT6835 2^21 */
#define ID_ELEC_ADD       (0.002f)      /* 每拍电角度增量：20 kHz 下 2π/0.002 ≈ 3142 拍 = 157 ms/圈 */
#define ID_ID_A           (1.0f)        /* 辨识电流，按额定取，首次可给 0.5 A */
#define ID_WAIT_MS        (800U)        /* 稳定等待 */
#define ID_TEST_ANGLE     (0.5f)        /* 正反向逼近角度 rad */
#define ID_ANGLE_ADD      (0.002f)      /* 逼近时每拍增量 */
#define ID_PN_SAMPLES     (4U)          /* 极对数平均次数 */
```

### 6.2 方向辨识（约 30 行）

```c
typedef struct {
    uint8_t  state;        /* 0=idle 1=run 2=done */
    float    theta;
    float    theta_prev;
    int64_t  enc_prev;
    uint32_t wraps;
    int8_t   dir;          /* +1 / -1 / 0 */
} IdDir;

void IdDir_Step(IdDir *s, int64_t enc_now, float *theta_out, uint8_t *id_en)
{
    if (s->state != 1U) { *id_en = 0U; return; }

    s->theta += ID_ELEC_ADD;
    if (s->theta >= 6.28318548f) { s->theta -= 6.28318548f; }

    if ((s->theta - s->theta_prev) <= -1.57079633f) {      /* 2π 回绕 */
        if (s->wraps >= 1U) {                              /* 第 1 次只建基准 */
            int64_t d = enc_now - s->enc_prev;
            if (d > 0)      { s->dir =  1; s->state = 2U; }
            else if (d < 0) { s->dir = -1; s->state = 2U; }
            else            { s->dir =  0; }               /* 没动，再转一圈 */
        }
        s->enc_prev = enc_now;
        s->wraps++;
    }
    s->theta_prev = s->theta;

    *theta_out = s->theta;
    *id_en     = 1U;
}
/* 结论：dir == -1 时把 phase_dir 取反（X72 对应"交换 U/W 相"或"在 Clarke 里取反 beta"） */
```

### 6.3 极对数辨识（约 35 行）

```c
typedef struct {
    uint8_t  state;
    float    theta, theta_prev;
    int64_t  enc_prev;
    uint32_t step;
    uint32_t pn_sum;
    uint32_t pn_id;
} IdPn;

void IdPn_Step(IdPn *s, int64_t enc_now, float *theta_out, uint8_t *id_en)
{
    if (s->state != 1U) { *id_en = 0U; return; }

    s->theta += ID_ELEC_ADD;
    if (s->theta >= 6.28318548f) { s->theta -= 6.28318548f; }

    if ((s->theta - s->theta_prev) <= -1.57079633f) {
        int64_t d = enc_now - s->enc_prev;
        if (d != 0) {
            float pn = roundf(ID_ENC_LINE / (float)d);
            if (pn >= 1.0f && pn <= 200.0f) { s->pn_sum += (uint32_t)pn; s->step++; }
        }
        s->enc_prev = enc_now;

        if (s->step >= ID_PN_SAMPLES) {
            s->pn_id = (uint32_t)roundf((float)s->pn_sum / (float)s->step);
            s->state = 2U;
        }
    }
    s->theta_prev = s->theta;

    *theta_out = s->theta;
    *id_en     = 1U;
}
```

> 改动点：把"`d==0` 时 pn=1"换成"丢样本"；加 `pn` 合理性上限；样本数用 `ID_PN_SAMPLES` 而不是魔法数 4。

### 6.4 电角度辨识（约 50 行）

```c
typedef struct {
    uint8_t  state;          /* 0=idle 1=search 2..7=step 8=done */
    uint8_t  step;
    uint16_t wait_ms;
    float    theta;          /* 虚拟电角度，供电流环 */
    float    buff[2];
    float    bias;
} IdElecAng;

void IdElecAng_Step(IdElecAng *s, float elec_angle_now, float *theta_out, uint8_t *id_en)
{
    if (s->state == 0U) { *id_en = 0U; return; }
    s->theta = 0.0f;

    switch (s->step) {
    case 0:                                       /* 吸合：固定 0°，等 3×wait */
        if (++s->wait_ms >= (ID_WAIT_MS * 3U)) { s->wait_ms = 0U; s->step = 1U; }
        break;
    case 1:                                       /* 正向逼近 */
        s->theta += ID_ANGLE_ADD;
        if (s->theta >= ID_TEST_ANGLE) { s->step = 2U; }
        break;
    case 2:                                       /* 回零 */
        s->theta -= ID_ANGLE_ADD;
        if (s->theta <= 0.0f) { s->theta = 0.0f; s->step = 3U; }
        break;
    case 3:                                       /* 稳定后取第一次 */
        if (++s->wait_ms >= ID_WAIT_MS) {
            s->wait_ms = 0U;
            s->buff[0] = elec_angle_now;
            s->step = 4U;
        }
        break;
    case 4:                                       /* 负向逼近 */
        s->theta -= ID_ANGLE_ADD;
        if (s->theta <= -ID_TEST_ANGLE) { s->step = 5U; }
        break;
    case 5:
        s->theta += ID_ANGLE_ADD;
        if (s->theta >= 0.0f) { s->theta = 0.0f; s->step = 6U; }
        break;
    case 6:                                       /* 稳定后取第二次并算 bias */
        if (++s->wait_ms >= ID_WAIT_MS) {
            float b0 = s->buff[0];
            float b1 = elec_angle_now;
            s->wait_ms = 0U;
            if (fabsf(b1 - b0) >= 3.14159265f) {           /* 跨 0/2π 边界 */
                s->bias = (b0 + b1 + 6.28318548f) * 0.5f;
                if (s->bias >= 6.28318548f) { s->bias -= 6.28318548f; }
            } else {
                s->bias = (b0 + b1) * 0.5f;
            }
            s->step  = 7U;
            s->state = 8U;                                  /* 完成 */
        }
        break;
    default:
        break;
    }

    *theta_out = s->theta;
    *id_en     = (s->state == 8U) ? 0U : 1U;
}
```

### 6.5 接进 X72 的 `Servo_ControlTick`

X72 现有开环分支已经是"虚拟角度 + dq 电流环"，只需把 `s_ol_theta` 从"固定 0"改成"由辨识状态机每拍更新"：

```c
/* Servo_ControlTick 内，开环分支之前 */
if (s_id_mode == ID_MODE_ELEC_ANGLE) {
    float th; uint8_t en;
    IdElecAng_Step(&s_id_ea, s_elec_angle_now, &th, &en);
    Servo_SetOpenLoop(en, th, ID_ID_A);
    if (s_id_ea.state == 8U) {
        BspServo_SetEncoderZero(-s_id_ea.bias / (float)PN);   /* 注意：bias 是电角度，要除 pn 转成机械角 */
    }
}
```

> **符号提醒**：X72 的 `SetEncoderZero()` 收的是**机械角**偏移，而 `elec_bias` 是**电角度**。
> 关系：`elec_angle = (enc_mech + zero) × pn`，所以 `zero = elec_bias / pn`（符号按各自实现确认）。

## 7. 与 X72 现状的差距

| 能力 | FM_XC 参考工程 | X72 现状 | 差距 |
|---|---|---|---|
| 虚拟电角度 + d 轴电流 | ✅ 三处都在用 | ✅ `Servo_SetOpenLoop` 本轮已实现 | 无 |
| 方向辨识 | ✅ 自动取反 `phase_dir` | ❌ 无 | 需新增 |
| 极对数辨识 | ✅ 4 次平均 | ❌ 硬编码 14 | 需新增 |
| 电角度辨识 | ⚠️ 算法完整但参数全 0、bias 覆盖式写入 | ⚠️ 只有静态吸合 `Z` | 需升级为"正反向逼近" |
| 结果持久化 | ❌ 只存 RAM | ❌ 只存 RAM | 都要补 Flash |

## 8. 建议的落地顺序

1. **先补"外部 θ 注入"**（X72 已有）→ 把 `Z` 从"固定 0 吸合"升级为"正反向逼近取平均"（§6.4）。这一步不需要新硬件，直接能把零点精度提高。
2. **再做极对数辨识**（§6.3），用 14 作为合理性校验（实测值应接近 14，偏差 >1 说明编码器线数或方向有问题）。
3. **最后做方向辨识**（§6.2）——X72 的相序如果是从硬件接线确定的，方向辨识的收益主要是"防止现场换线后失控"，优先级最低。
4. 三者都要**存 Flash**，否则每次上电重标。
