# 速度闭环恢复与验收流程

- 日期：2026-11-19
- 决定：不新增「开环频率闭环」模式，等编码器修复后直接跑常规速度闭环
- 固件：保持当前版本不变（`Code=114568`，0 Error / 0 Warning，已烧录）

---

## 一、为什么现在跑不了速度闭环

| 证据 | 数值 | 含义 |
|---|---|---|
| `W`（速度 30 rpm） | `moe=1` → 0.3 s 内 `f=0x20`；`iterm=−3.00` 顶限幅、`iqc=3.00`、`wmeas=0` | 积分跑飞，被假超速封 MOE |
| `M`（iq=+1 A） | 立即 `f=0x20` | 同源 |
| `N`（iq=−1 A） | `f=0x00`，`idq` 跟踪 −1.00 A，但转速恒 0 | 电流环正常，转矩不成立 |
| 电角度扫描（2.5 A） | 12 个固定补偿角响应 0/23/110/50/36/6.8/80/21/276/77/158/126 rpm | **无单峰** → 误差随位置变化 |
| `Z` | `ratio` 13.97~14.79 跳、`IDENT FAIL ratio_bad n=60/0` | 开环 2 A 步进下转子跟随不稳 + 角度不可信 |

结论：速度环本身没问题，是**执行端（电角度）失效**——给定 iq 打不到 q 轴，反馈又因角度跳变产生尖峰，于是「积分跑飞 + 假超速」。

## 二、恢复步骤（必须按顺序）

| 步 | 动作 | 判据 |
|---|---|---|
| 1 | 换 MT6835 编码器小板，或用官方工具重写 EEPROM 补偿表 | 官方工具读 `0x113` 不再报错 |
| 2 | 上电，发 `C`（电流零点），等 **3 s** | 回显 `CAL start` |
| 3 | 发 `Z` | `ratio≈14.0 / pn=14`，`bad=0` |
| 4 | 发 `^`（编码器自校准，现走开环拖动） | 回显 `EC ok ... -> !!! POWER CYCLE REQUIRED (>6s) !!!` |
| 5 | **断电 >6 s 再上电**（只复位 MCU 无效） | — |
| 6 | 复跑 `Z` | `ratio≈14.0 / pn=14`，`|zero| ≤ 20°` |

> `C` 后必须等 3 s：实测 C 后 1.5 s 紧跟 `Z` 会 `ratio_bad`。

## 三、验收：一条命令

```
python speed_loop_verify.py COM27 --rpm 60 300 1000 --out verify.csv
```

脚本按四段执行，任一段 FAIL 即停并给出原因：

| 阶段 | 检查 | 判据 |
|---|---|---|
| ① 联锁 | `f=0x00`、`moe=0`、`cal=1`、`z=1` | 全部满足 |
| ② Z 对齐 | `ratio` / `pn` / `zero` | `13.5≤ratio≤14.5` 且 `pn=14` 且 `|zero|≤20°` |
| ③ 转矩能力 | 1 A / 0.25 s 下 `peak(0°)` vs `peak(+90°)` | `peak(0°) > 3×peak(+90°)` 且 `>60 rpm` |
| ④ 速度闭环 | 60 / 300 / 1000 rpm 阶跃 | 稳态误差 ≤1%、超调 ≤15%、`f=0x00` |

第 ③ 段是本次新增的关键判据：**正确角度必然是单峰**。如果 `+90°` 与 `0°` 出转矩相当，说明角度仍不可用——这一条能一眼识别「Z 说成功但实际没对齐」。

## 四、速度闭环的既有参数（无需改动）

| 项 | 值 | 位置 |
|---|---|---|
| 速度环 Kp | 0.5833818（随调度表可调） | `servo_isr.c` |
| 速度环 Ki·Ts | 0.04076276（2 kHz 节拍） | 同上 |
| 给定斜坡 | 400 rad/s² 默认（`~` 可调，≥20000 视为不限） | `servo_cmd.c` |
| iq 限幅 | ±3 A（速度模式，`|` 可调至 9） | 同上 |
| 超速门限 | `1.5×|w_ref| + WMAX_ABS`（速度/位置模式） | `servo_isr.c` |
| 协议门限 | ±220 rad/s（≈2101 rpm），内部硬限 400 rad/s | `app_param.c` / `servo_isr.c` |

1000 rpm 属正常范围（历史实测稳态 1000.02 ± 0.34 rpm、误差 +0.020 rpm）。

## 五、修好后可直接跑 30 组温升长测

```
python full_soak.py COM27 --rpm 1000 --groups 30 --minutes 10
```

`full_soak.py` 已修好的前置保护：`C` 默认跳过、`Z` 必须 `ratio∈[13.5,14.5] && pn=14` 且最多重试 4 次、`^` 默认跳过（`--enc-cal` 才执行）、机械辨识只做惯量+摩擦。

## 六、风险提示

1. **`^` 现在固定走开环拖动**（2.5 A、300 rad/s² 升频到 600 rpm）。好处是编码器角度再差也能转起来；代价是转速波纹比闭环大。若新编码器上 `^` 仍 `chip=2`，说明不是固件问题，而是磁钢偏心/气隙/芯片本身。
2. **不要为了"让它转"而长期带 `-<deg>` 补偿运行**：`s_elec_off` 只写 RAM，掉电即 0，且它补的是固定偏置，对随位置变化的误差无效。
3. 若 `Z` 反复 `ratio_bad n=60/0`，先查机械：转子是否被工装卡住、2 A 注入是否能推动（谐波关节起动力矩接近 0.1 N·m）。
