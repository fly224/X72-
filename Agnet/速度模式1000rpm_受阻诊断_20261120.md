# 速度模式 1000 rpm 受阻诊断（2026-11-20 23:1x）

## 一、结论

**1000 rpm 跑不了。** 不是软件参数问题，也不是电流不够：

- 速度模式的联锁要求 `cal=1 && z=1`，当前 `cal=1 z=0`，命令被拒
- `Z`（电角度对齐）连续失败，根因是**转子在 2 A / 4 A 静磁场下完全不跟随**
- 用辨识出的惯量反推：`J = 7.67e-5 kg·m²`，`0.176 N·m` 应产生 **2294 rad/s²** 角加速度，
  0.1 s 就能转过 11 rad。实测 60 步累计位移 **−0.011°**，差 5~6 个数量级
- 因此负载不是"惯量偏大"，而是**被外力锁住**：抱闸未释放 / 机械抱死 / 减速器卡死

## 二、证据链

### 2.1 联锁与命令回显

```
S:  en=0 moe=0 cal=1 z=0 ... ovc=-10.77/-10.72 v=30.83
=1000  ->  [CMD] SPD refused: elec angle not aligned (send Z first)
E      ->  [CMD] EN refused: elec angle not aligned
Z      ->  [CMD] IDENT start id=2.00A: step120x60 then sweep2x, ~9s
           [CMD] IDENT FAIL ratio_bad n=60/0 moe=0
```

`n=60/0` 表示 60 个步进样本全部采到、0 个被丢弃——注入过程本身没有中断、没有跳闸。

### 2.2 转子位移（决定性）

Z 前后用 30040 的 `enc_sum` 直接量（2^21 counts/rev）：

| 时刻 | enc_sum | 备注 |
|---|---|---|
| Z 前 | **38** | 静止 1.5 s 内完全不变 |
| Z 后 | **−26 / −27** | 静止 2 s 内只跳 1 count |
| 净位移 | **−64 counts = −0.011°** | 60 步 × 8.57°机械/步 = 应转 514° |

编码器本身是好的：PWM 关闭时 300 帧读数的范围是 `[-27, -26]`，**摆幅 1 count**，
最大相邻跳变 1。不存在噪声或丢帧。

### 2.3 电流确实建立了

| 项 | 实测 |
|---|---|
| Z 期间三相峰值（30025） | 9.56 A |
| 峰值保持（S 行 `ovc`） | **−10.77 / −10.72 A**（阈值 12 A） |
| 零电流偏置（C 标定后） | `bias=1.64/1.61`，静置读 `i=-0.03/-0.01` |
| 故障字 | 全程 `f=0x00`（电压限幅修复后不再跳闸） |

即：**有电流、无转矩输出**（或转矩被机械吃掉）。

### 2.4 为什么"电流够"却"没转矩"

按 `Kt = 1.5·p·ψ = 0.088 N·m/A`：

| 注入 | 理论转矩 | 自由转子应有角加速度 | 实测位移 |
|---|---|---|---|
| 2.0 A | 0.176 N·m | 2294 rad/s² | −0.011° / 60 步 |
| 4.0 A（在线加大） | 0.352 N·m | 4588 rad/s² | 同样不动 |

即使把 `align_id` 加到 4 A（已通过 30082 在线改、未烧固件），峰值电流冲到 10.77 A，
位移仍是 0。**扭矩再大也没用**——这不是力矩不足的问题。

### 2.5 已排除项

| 假设 | 判据 | 结论 |
|---|---|---|
| 电流环/功率级坏 | 三相电流可达 9.5 A，`f=0x00` | 排除 |
| 电流零点漂移 | C 后静置读 −0.03/−0.01 A | 排除 |
| 过流保护误跳 | `f=0x00`，`ovc` 峰值未触 12 A | 排除 |
| 编码器无输出/噪声 | PWM 关时摆幅 1 count | 排除 |
| 开环电压限幅不够 | 从 0.06 提到 0.10 无效 | 排除 |
| 抱闸由固件控制 | `grep -i brake` 全工程无命中 | **固件无抱闸控制**（不代表硬件没有） |

## 三、需要现场确认的一件事

**断电，用手转输出轴。**

| 手感 | 结论 | 处理 |
|---|---|---|
| 完全转不动 / 有明显保持力矩 | **抱闸未释放**（弹簧制动、需 24 V 释放）或机械抱死 | 找抱闸供电线；无抱闸则查减速器/限位 |
| 能转但很涩、有齿感 | 减速器卡死或装配过紧 | 拆检 |
| 很轻，且 `enc_sum` 跟着变 | 机械与编码器都好 | 那就是"电机在转但编码器不跟"（联轴器/磁钢打滑） |
| 很轻，但 `enc_sum` 不动 | 编码器联轴器打滑 | 紧联轴器 |

最后一种情况有个额外判据：**在 Z 期间听声音/摸机壳**。若电机在转，会有明显旋转振动；
若完全静止，则确认是锁死。

## 四、本轮实际做的操作

1. `C`（电流零点标定）成功 —— `cal=0 → 1`，`bias=1.64/1.61`
2. 通过 **30082 在线调参**把 `align_id` 2.0 → 4.0、`ol_vlim` 0.06 → 0.10，重试 Z（失败），

## 五、局限与不确定项

- Z 期间 ASCII 回显与二进制遥测共用一个 USART，字节级交织会让解析器短暂失步，
  因此 **Z 期间的 enc 读数不可信**；本文所有位移结论只取 **Z 前后静止段**的数据
- 未做示波器测量，无法直接看相电压/相电流波形与抱闸线圈电压
- "抱闸"目前是推断：硬件网表检索无 brake 字样，但也可能是我拿到的网表不含该支路
- 未验证"电机在转但编码器不跟"这一分支（需要人手转轴时同步观察 `enc_sum`）
