# 组合配置实测：死区补偿 0.59% + 5/7 次谐波抑制，1~2000 rpm（2026-11-20）

## 一、结论

**组合配置的可靠区间只有 100~1000 rpm；1/3/60 rpm 直接失稳，30/80/1500 rpm 大幅振荡，2000 rpm 带不动。**

| 区间 | 表现 | 可用性 |
|---|---|---|
| 1、3 rpm | `f=0x20` 失稳，无有效数据 | **不可用** |
| 10 rpm | 9.998 rpm（−0.02%）、CV 0.19%、iq_pp 1.91 | 可用 |
| 30 rpm | 31.21 rpm（+4.0%）、iq_pp **5.14**（±2.6 A 振荡） | 不可靠 |
| 60 rpm | 68.0 rpm（+13.2%，可重复）、iq_pp **6.00**（满幅 ±3 A） | **失稳** |
| 80 rpm | 80.1 rpm（+0.1%）、iq_pp 4.67、iq 均值变号 | 勉强 |
| **100~1000 rpm** | 误差 ≤0.10%、CV 0.73~1.24%、iq_pp 0.54~3.40 | **可靠** |
| 1500 rpm | 1498.5 rpm（−0.11%）、iq_pp 4.8~5.2 | 可用但振荡大 |
| 2000 rpm | 1774~1796 rpm（**−10.7%**）、iq 顶 3 A | **带不动** |

对照：**死区补偿单独（谐波 OFF）在 1~2000 rpm 全段可用**，2000 rpm 能到 1997（−0.13%）。也就是说，**加上谐波抑制后，低速端从 1 rpm 恶化到 100 rpm 才可用，高速端从 2000 降到 1500**。

## 三、与"死区补偿单独"的对比

| 转速 | 死区单独（谐波 OFF） | 组合（死区 + 谐波） | 变化 |
|---|---|---|---|
| 1 rpm | 1.015 rpm / CV 0.12% / iq_pp 1.16 | **失稳** | 严重恶化 |
| 60 rpm | CV 1.4% / iq_pp 1.28 | 68.0 rpm / iq_pp **6.00** | 严重恶化 |
| 100 rpm | CV 1.8% / iq_pp 1.64 | CV 1.04% / iq_pp 1.70 | 持平 |
| 300 rpm | CV 1.4% / iq_pp 1.41 | CV 1.05% / iq_pp 1.29 | 略好 |
| 500 rpm | CV 1.6% / iq_pp 0.60 | CV 0.73% / iq_pp 0.54 | 略好 |
| 1000 rpm | CV 1.8% / iq_pp 1.15 | CV 1.24% / iq_pp 1.24 | 略好 |
| 2000 rpm | 1997 rpm（−0.13%） | **1775 rpm（−11%）** | **严重恶化** |

（死区单独一列的转速值取自矩阵报告，那里有 +3~5% 的测量方法误差；CV/iq_pp 仍可比。）

**净结论：组合只在 100~1000 rpm 与"死区单独"相当或略好，两端都明显变差。**

## 四、机理

1. **低速失稳**：抑制器的 Kp=0.10 V/A、Ki·Ts=0.004 是固定值。1~3 rpm 时 5/7 次只有 2.3~6.8 Hz，积分器在极低频增益极大，几个周期就顶到限幅（0.15×vbus≈4.6 V），直接冲击基波 → `f=0x20`。60 rpm（5/7 次 70/98 Hz）仍处于积分过强区，表现为 ±3 A 满幅极限环（iq 均值≈0，转速反而高出 13%）。
2. **高速带不动**：谐波补偿占用电压预算。2000 rpm 时 BEMF 已约 12 V（母线 30.8 V），叠加补偿后基波裕度不足，速度环 iq 顶 3 A 仍只能到 1775 rpm。
3. **30/80/1500 rpm 的振荡**：这三个转速的 5/7 次频率与抑制器相位特性形成不利组合（iq 在限幅附近来回），表现为 iq_pp 4.7~5.2 而转速均值仍准——属于"准稳定极限环"，不是完全失稳。

## 五、建议

| 场景 | 配置 |
|---|---|
| 常规 1~2000 rpm 运行 | **只用死区补偿，不开谐波抑制**（全段可用） |
| 100~1000 rpm 且需要压 6 次电流脉动 | 可开组合，收益有限（CV 略好、iq_pp 持平） |
| <100 rpm 或 >1500 rpm | **禁止组合**（失稳 / 带不动） |
| 若一定要全段用谐波抑制 | 需把 Kp/Ki 按转速调度（低频降增益、高频限幅收紧），固件当前无此入口 |

## 六、复现

```
python combo_sweep.py COM27        # 60~2000 主表，逐点落盘
python probe_low.py COM27          # 1/3/10/30 rpm 低速段

```

数据：`combo_dead_harm_1-2000rpm_20261120.csv`（7 点）。

## 七、局限

- 空载、正转；带载时电压裕度更紧，高速可用上限会进一步降低。
- 低速 1/3 rpm 的失稳结论明确（两次均 f=0x20）；30/60/80 的振荡边界只测了单点，未做细扫。
- 谐波抑制的 Kp/Ki 不可在线调整，因此"低频增益过强"是机理推断，未用参数扫描证实。
- 2000 rpm 的 1775 rpm 是在母线 30.8 V、iq 限幅 3 A 下测得；提高 iq 限幅或母线电压可能改善。
