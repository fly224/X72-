# 速度轨迹接口 30097：「到达时间」优先

**日期** 2026-11-21 · **固件** Code=112356 / RO=5064 / ZI=26668，0 Error 0 Warning · **验证** 17/17 + 26/26

---

## 一、结论

速度控制的三件事现在各自只有一条入口，互相不重叠：

| 要改什么 | 指令码 | 说明 |
|---|---|---|
| 目标转速 | **30019** | `speed_tar_p_s`（计数/s），运行中改只发这一帧 |
| 轨迹形状 + jerk | **30089** | `mode` 0=梯形 / 1=S 曲线，`j_max` |
| 加速度 | **30019** | `acc_tar_p_ss`（rad/s²，线上按计数/s²） |
| **到达目标的过渡时间** | **30097**（新增） | `t_ramp_s`，时间优先，覆盖上面两个 |

实测（100 → 300 rpm，Δω=20.944 rad/s）：

| 配置 | 反算值 | 实测到达 |
|---|---|---|
| 梯形 t=0.5 s | a=41.89 | **0.510 s** |
| S 曲线 t=0.5 s | a=83.78 / j=335.1 | **0.485 s** |
| 时间模式关 + a=400 | a=400 | 0.075 s（理论 0.052，见 §7 量化） |
| t=0.0005 s | a 需 41888 → 夹到 20000 | 0.031 s，`clamped=1` |

## 二、为什么不扩 30089 而是新增 30097

固件收帧时按元数据**严格校验长度**：

```c
// mavlink_host.c:167
if (meta->len != s_rx_len) { s_rx_crc_err++; return; }   /* 长度不符直接当坏帧丢 */
```

`s_meta` 一条 msgid 只能有一个长度。把 30089 从 8 B 扩到 24 B，会让所有还在发 8 B 的上位机**整条帧被丢弃**（而且计在 CRC 错里，看起来像线路问题）。所以新增一条长度固定的消息，零破坏：30089 保持 8 B，`mode`/`j_max` 语义不变。

---

## 三、公式（为什么是这两个系数）

**梯形**：恒加速，`a = Δω / t`。

**S 曲线**：`ramp_step` 是梯形加速度剖面（a 以 ±j 爬升 → 保持 → 爬回），
到达时间 `t = Δω/a + a/j`。要让这个式子解出恰好 t：

```
取 a = 2Δω/t  →  t = Δω/(2Δω/t) + (2Δω/t)/j = t/2 + t/2
则 j = 4Δω/t²
```

所以 S 曲线用 `a=2Δω/t`、`j=4Δω/t²`，两个系数配套，不是拍出来的。

`Δω` 取「**锁存那一刻**的 `|目标 − 当前斜坡值|`」，语义是"从这一刻起，t 秒后到位"。

---

## 四、必须锁存，不能每拍重算

如果每拍按 `a = 剩余/t` 更新，则 a 随剩余一起减小，微分方程 `dv/dt = e/t` 的解是双曲型，剩余按指数衰减但**永不归零**——现象是"停在半速上"。

所以只在「目标变化超过 0.5 rad/s」那一拍锁一次 a/j，整段过渡用同一组值：

```c
// servo_isr.c:1774
if (fabsf(w_ref - s_spd_w_latch) > SERVO_SPD_T_RELOCK) {   /* 0.5 rad/s */
    const float dw = fabsf(w_ref - s_spd_ref_ramp);
    ... 反算 a/j，夹到 [5, 20000] / [1, 200000] ...
    s_spd_a_latch = a;  s_spd_j_latch = j;
}
s_spd_ramp.a_max = s_spd_a_latch;
s_spd_ramp.j_max = s_spd_j_latch;
```

**副作用（要记住）**：`a_eff` 回读是"本段正在用的值"，所以"先设 t、再改转速"的顺序下，设完 t 立刻回读看到的还是上一段的 a。改转速之后才更新——这是正确语义，不是 bug。

---

## 五、只在速度模式生效

条件里带 `s_pos_en == 0U`。位置模式下 `w_ref` 是 `PosLoop_Step()` 每拍连续产出的，没有"阶跃"语义；在那里按时间重算等于每拍改加速度，会破坏位置规划。配了 t 但在位置模式时，`flags.bit3`（`pos_blocked`）会置位，能区分"没配"和"配了被忽略"。

## 六、协议：30097 AppSpeedTrajCfg（32 B，双向）

| 偏移 | 字段 | 类型 | 方向 | 说明 |
|---|---|---|---|---|
| 0 | `cmd` | u8 | 写 | **1 = 写入 t**，0 = 只读回；应答恒为 0 |
| 1 | `status` | u8 | 读 | 本次写入的状态（0 成功） |
| 2 | `mode` | u8 | 读 | 当前轨迹形状 0/1 |
| 4 | `t_ramp_s` | f32 | 读写 | 0~60 s；**≤0 关闭时间优先** |
| 8 | `a_eff` | f32 | 读 | 本段锁存并实际使用的加速度 |
| 12 | `j_eff` | f32 | 读 | 本段锁存并实际使用的 jerk |
| 16 | `t_left_s` | f32 | 读 | 按剩余量估的剩余时间（S 曲线按平均加速度折半） |
| 20 | `flags` | u32 | 读 | bit0 配了时间模式 / bit1 被夹 / bit2 S 曲线 / bit3 位置环屏蔽 |
| 24 | `acc_cfg` | f32 | 读 | 30019 配的加速度（t=0 时生效） |
| 28 | `j_cfg` | f32 | 读 | 30089 配的 jerk |

`crc_extra = 97`（沿用 3009x 段"msgid 低 8 位"的约定），帧长 10+32+2 = 44 B。

上位机：

```python
lk.set_speed_traj(0.5)      # 写入，返回 a_eff/j_eff/t_left/flags
lk.speed_traj_read()        # 只读回
```

## 七、下发规则

**冷启动（完整顺序）**

```python
lk.set_permission(0, 0)          # 30068  写权限
lk.set_mode(3)                   # 30056  速度模式（只在模式变化时发）
lk.set_speed_accel(400)          # 30019 off32  加速度（时间模式下的回退值）
lk.set_speed_profile(0, 20000)   # 30089  梯形/S 曲线 + jerk
lk.set_speed_traj(0.5)           # 30097  到达时间 0.5 s（可选；不设=用 a/j）
lk.set_speed_rpm(100)            # 30019  目标转速
lk.set_controlword(0x0F, 0)      # 30054  使能（要求 cal=1 z=1 fault=0）
lk.set_keepalive(True, 3, 5.0)   # 5 Hz 重发 30019，deadman=2 s
```

**运行中只改转速**：`lk.set_speed_rpm(300)`，一帧即可，不碰控制字、不重装配环路。

**只改过渡时间**：`lk.set_speed_traj(0.3)`，下一段（下一次目标变化）生效。

**切 S 曲线**：先 `set_speed_profile(1, j)` 再设 t——顺序不能反，因为反算 j 时读的是当前 `profile_mode`；反了会按梯形的公式算 a，S 曲线下实际时间偏长。

| 场景 | 必须发 | 不要发 |
|---|---|---|
| 改转速 | 30019 | 30054（重发无益，写错 halt 会封输出） |
| 改到达时间 | 30097 | 30019（会顺带改转速） |
| 改轨迹形状 | 30089 | 30097（t 仍是旧值，但会重新反算，结果正确） |

## 八、限制与注意事项

1. **100 Hz 遥测的量化下限**。30091 是 10 ms 一点，52 ms 的斜坡最低只能测到 55~75 ms。判"是否按 a 走"要看 `a_eff` 与 `30091.acc`，不要只看到达时间。
2. **时间模式不落盘**。`t_ramp` 只存 RAM，重启回 0（回落到 30019 的 acc）。要固定就用 acc。
3. **时间模式会覆盖 a/j**。`t>0` 期间 30019 的 acc 与 30089 的 j 被忽略（但仍作为"剩余 < 0.5 rad/s 时"的回退值）。
4. **反算值有上限**。a 夹 [5, 20000]、j 夹 [1, 200000]；够不到目标时间时 `flags.bit1=1`，此时实际时间会**长于** t，不会更短。
5. **`Δt` 语义是"从现在起"**，不是"两个稳态之间"。连续调速时每段各自计时。
6. **`t_left` 是估计值**：梯形 Δ/a 精确；S 曲线用 2Δ/a（平均加速度 ≈ 峰值一半），中途读会有 10~20% 偏差。
7. **烧录仍会擦掉齿槽页**（与本次改动无关，但今天复现两次）。烧完 `cog_read` 得 `n_bins=0`，需重跑 `}` 13 s。待做双页乒乓。
