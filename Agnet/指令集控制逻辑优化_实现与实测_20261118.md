## 2. 优化项与证据

| # | 问题（旧行为） | 修复 | 代码位置 |
|---|---|---|---|
| 1 | `s_pending=1` 时新帧仍覆盖 `s_frame`，`dispatch()` 读同一缓冲 → **错分发** | pending 时丢弃新帧并计 `s_drop`，不写 `s_frame` | `mavlink_host.c:126` |
| 2 | 上一帧 ACK 未发完仍分发新帧，`ack_prepare()` 覆盖 `s_ack` → ACK 丢失 | `s_ack_pending` 且 UART 忙时本拍直接 `return`，ACK 发完再分发 | `mavlink_host.c:385` |
| 3 | MIT 首次装配不回读 MOE，故障时被 `PwmEnable` 静默拒绝仍返回 `active=12` | 回读 `BspServo_IsPwmEnabled()`；失败则清 MIT+电流环、置 `s_mit_why=6`、返回 0 | `servo_cmd.c:2891`、`servo_cmd.c:135` |
| 4 | 控制字 `SwitchOn` 一律走 `do_enable()` 位置保持，与 `30056` 选择的模式脱节 | 新增 `arm_with_mode()`：按 `s_op_mode` 用**已就绪给定**装配目标环；无给定才退回位置保持 | `app_param.c:85`、`app_param.c:128` |
| 5 | `30019` 只解析当前模式那一路，切模式后另一路给定丢失 | 新增 `AppParam_SetPosSpeed()`，pos/speed 两字段都缓存，只装配当前模式那一路 | `app_param.c:209`、`mavlink_host.c:279` |
| 6 | `SAVE_PARAM`（30069 cmd=1）是幂等空实现，不真写 Flash | 调 `Servo_ParamSaveNow()` + `CogFf_SaveToFlash()`，失败回 `WRITE_STATE_ERROR` | `app_param.c:291` |

### 2.1 控制字时序变化

```
旧：30056 选模式(只登记) → 控制字 SwitchOn → do_enable() → 位置保持
                         → 必须再补发给定才切到目标环

新：30056 选模式(只登记) → 给定消息 → 缓存 + 按当前模式装配
    30056 切模式(只登记) → 控制字 SwitchOn → arm_with_mode()
                            ├─ 该模式给定已就绪 → ServoCmd_CtrlXxx(target)
                            └─ 未就绪           → ServoCmd_Arm()（位置保持，安全默认）
```

给定就绪标志（`s_iq_valid / s_w_valid / s_p_valid / s_mit_valid`）上电清零，只在显式下发对应给定后置 1；复位后需重新下发给定。

### 2.2 30019 旁带字段的 0 值策略

`30019` 同时携带 `pos_tar_p` 与 `speed_tar_p_s`。上位机常只填当前模式那一路，另一路为 0。为避免切到位置模式后控制字使能**直接把位置打到 0 rad**：

- 显式调用 `AppParam_SetPosP(0)`：视为有效目标（`s_p_valid=1`）。
- `30019` 旁带 `pos=0`：保留上次有效位置目标，不覆盖 valid。
- `30019` 旁带 `speed=0` 且当前为速度模式：视为显式停转，valid=1。

## 5. 局限与后续

1. **突发帧丢弃**：`s_pending=1` 时新帧被丢弃（计入 `s_drop`），上位机需按 ACK 超时重发；不适合高频流式指令。若后续要做 1 kHz 指令流，应改成 4 深度帧队列 + ACK 队列。
2. **给定就绪不持久化**：复位后 4 个 valid 标志清零。冷启动后若希望控制字直接进目标环，上位机需重新下发一次给定。
3. **位置 0 的语义**：`30019` 旁带 `pos=0` 不覆盖有效目标；要显式回零请用 `mode=1` + `30019 pos=0`（`SetPosP` 显式 valid=1）。
4. **存参仍受三道联锁约束**：`MOE=0`、电流零点已标定、电角度已对齐；Flash 擦除期间 CPU 停顿 20–40 ms，故仍禁止使能态调用。
5. **文件仍为 `Board/` 扁平结构**：本轮未做目录重构，避免引入编译工程路径风险。
