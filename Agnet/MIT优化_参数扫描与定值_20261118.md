# MIT 模式优化：参数扫描与定值（2026-11-18）

## 结论先行

上次四模式实跑中，MIT 用 `kp=10/kd=0.5` 出现 `|iq|峰值 5.6 A`（顶着 5 A 限幅）。
根因不是 kp，而是 **kd=0.5 触发了 244 Hz 极限环**——这是一个已知但默认值没跟上
的坑（`MIT模式_实现与实测.md` 8.1 节早已测出 kd≤0.2 才稳定）。

**优化只需改上位机参数，固件无需改动**：`kd 0.5→0.05`、`kp 10→30`。

| 指标 | 优化前 kp10/kd0.5 | 优化后 kp30/kd0.05 | 改善 |
|---|---:|---:|---:|
| 跟踪 RMS | 0.0108 rad | **0.0048 rad** | −56% |
| \|e\|中位 | 0.0060 rad | **0.0027 rad** | −55% |
| \|iq\|峰值 | 5.60 A（顶限幅） | **0.819 A** | −85% |
| 极限环 | 244 Hz，iq_sd 4.25 | 无，iq_sd 0.33 | 消除 |
| 顶限幅帧数 | 132 / 300 | 0 | 清零 |
| 收尾力矩 | 顶着限幅 | 0.00 N·m | 清零 |

## 1. 根因：kd 过大导致负阻尼极限环

控制律（`servo_isr.c:1651`）：

```
τ = kp·e + kd·(v_des − om_d) + τ_ff
iq = τ / Kt            Kt = 0.091 N·m/A
iq 硬限幅 ±5 A         （servo_isr.c:207/1674）
```

D 项的阻尼环穿越频率是 `kd/J`：

| kd | kd/J | 状态 |
|---:|---:|---|
| 0.5 | 9141 rad/s = 1455 Hz | 远超电流环 1 kHz 带宽 → 相位过 90° 变负阻尼 |
| 0.2 | 582 Hz | 边界，iq 峰 5.33 A、9 帧顶限幅（本次复现） |
| ≤0.08 | ≤233 Hz | 干净，iq 峰 <1.1 A |
| 0.05 | 145 Hz | 最优，留足带宽裕度 |

判据：`kd/(2π·J) ≪ 电流环带宽`，本机 J≈5.47e-5、带宽 1 kHz → kd < 0.1。
`mit_test.py` 的默认值早已改成 0.05，但 `mit_run.py` 漏改，仍是 0.5。

起步瞬间的额外冲击：`pd=p0+amp·sin(wt)` 在 t=0 位置在起点却要求
`v_des=amp·w≈1.57 rad/s`，`kd·v_des≈0.785 N·m≈8.6 A` —— kd=0.5 时
这一项本身就超过限幅；kd=0.05 时降到 0.86 A，不再顶限。

## 3. 测量口径修正（过程中发现并修复）

扫描脚本迭代中发现两个测量假象，均已修复，避免把噪声当结论：

1. **绝对基准不同步**：原误差用 `p0/enc0` 绝对坐标，上一组 D 后电机残余滑行
   导致 enc0 与 p0 不同时刻，随机注入 ~0.0475 rad 固定偏置（与 kd 无关，
   足以淹没 0.005 rad 真实误差）。改用**相对轨迹基准** `p_meas − p_meas[0]`
   对齐 `amp·sin(w·t)`，偏置消除。
2. **相位零点**：首帧到达时 `tr>0`，直接 `sin(w·tr)` 引入 `amp·sin(w·t₀)≈0.03 rad`
   假误差。改用首帧实际时刻作相位零点 `sin(w·(tr−t_first))`。

修复后三轮复测稳定：RMS 0.006–0.014 rad、iq_sd 0.33–0.36、零顶限幅。
