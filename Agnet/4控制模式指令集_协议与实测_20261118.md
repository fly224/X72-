# 4 控制模式 MAVLink 指令集：协议实现与实测（2026-11-18）

## 一、结论先行

在首期 5 条操作指令（30000/30054/30056/30068/30069）基础上，补齐 **4 个控制模式的完整给定指令集**，上位机从此可以**纯靠 MAVLink 指令码**切换模式、下发给定、使能运行，不必再回头敲 ASCII 的 W/M/P 或私有 0x02 帧。

- 新增 **4 条给定消息**：30025（力矩）/ 30019（位置·速度）/ 30065+30066（MIT）。
- 覆盖 **4 个模式**：力矩(4)、速度(3)、位置(1)、MIT(12，本板自定义)。
- 完整回归 **3 轮全部 PASS**（门卫 + 4 模式），每轮末 `moe=0 f=0x00` 安全封锁；CRC 错误 1~2/千帧（混合流噪声，不影响功能）。
- 编译 **0 Error / 0 Warning**，烧录 **Verify OK**。
- 模式切换实测 力矩→速度→力矩 正确，验证"自动先封锁再切"联锁无两环同开竞态。

## 二、完整指令码表

物理通道 USART1 @921600；帧格式与 CRC 口径见 `MAVLink操作指令码_协议与实测_20261118.md`。

### 2.1 会话与操作（首期已有）

| msgid | 名称 | Payload | 功能 |
|---|---|---|---|
| 30000 | READ_PARAM | uint32 struct_id | 读结构体（30055 状态信息 / 30054 / 30056 / 30068） |
| 30054 | AppControlWord | uint16 cw + uint8 halt | bit0=使能/封锁；halt=立即封锁 |
| 30056 | AppOpMode | int8 mode | **1=位置 / 3=速度 / 4=力矩 / 12=MIT** |
| 30068 | AppPermissionConfig | uint8 comm + uint8 internal | 权限总闸（comm=0=上位机接管） |
| 30069 | SystemCmd | uint8 cmd | 0空/1存参/2软复位/3清故障 |

### 2.2 四模式给定（本次新增）

| msgid | 名称 | Payload 关键字段 | 工程单位 | 应答（回显同 msgid） |
|---|---|---|---|---|
| **30025** | CurrentCtlInput | `idq_tar_A[1]` @off4 (f32) | iq 电流 A，±5 | [状态, 回读iq(f32)] |
| **30019** | PosSpeedCtlInput | 位置模式: `pos_tar_p`@off0 (i64)<br>速度模式: `speed_tar_p_s`@off28 (f32) | 位置脉冲(2^21/rev) / 速度脉冲·s⁻¹ | [状态, 回读给定(f32, rad 或 rad/s)] |
| **30066** | MitCtlConfig | `kp`@off0 `kd`@off4 `kt`@off12 (f32) | N·m/rad, N·m/(rad/s), N·m/A | [状态, 回读kp(f32), kd(f32)] |
| **30065** | MitCtlInput | `pos_tar_p`@off0 (i64)<br>`tq_set_NM`@off16 `speed_tar_p_s`@off24 (f32) | 位置脉冲 / 力矩 N·m / 速度脉冲·s⁻¹ | [状态, 回读目标p(f32), **实际位置p_now(f32, rad)**] |

**状态字节**（所有应答 payload[0]）：0=SUCCESS / 1=READ_ONLY / 2=OUT_OF_RANGE / 3=WRITE_STATE_ERROR / 4=NO_AUTHORITY。

### 2.3 单位换算（关键，避免踩坑）

- **编码器当量**：MT6835 **2^21 = 2097152 counts/rev**，与固件 `BspServo_GetPosSum()` 同口径。
  - 位置脉冲 → rad：`rad = p × 2π / 2097152`
  - 速度脉冲/s → rad/s：`rad_s = p_s × 2π / 2097152`；再 ×60/2π 得 rpm
- **30019 双语义**：同一条消息，位置模式取 `pos_tar_p`、速度模式取 `speed_tar_p_s`，由当前 `30056` 模式值决定，不是由消息类型决定。
- **MIT 位置是绝对角**：`pos_tar_p` 对应 theta_multi 口径（含上电零点 base），**不是** enc_sum 相对值。上位机应用 30065 应答里的 `实际位置p_now` 作首个目标贴当前位置——直接发 enc_sum 换算值会因差一个 base 而产生 kp·e 冲击、触发超速 f=0x20（本次实测踩过并已解决）。

## 三、控制流程（标准时序）

```
1) 30068 权限     comm_auth=0            # 上位机接管
2) 30069 清故障   cmd=3                  # 首次/故障后
3) 30056 选模式   mode=1/3/4/12
4) 下发给定：
   力矩 → 30025  iq @off4
   速度 → 30019  speed_tar_p_s @off28
   位置 → 30019  pos_tar_p @off0
   MIT  → 30066  kp/kd  →  30065  pos/speed/tq
          （MIT 起步：先 kp=0 发一次 30065，从应答读 p_now，再发 p=p_now 的目标，最后升 kp）
5) 周期重发给定保活（deadman 2000 ms，MIT 另有命令超时）
6) 结束 → 30054 halt=1 或控制字 bit0=0 封锁
```

**MODE 与给定必须配套**：先选模式再发对应给定；发错消息类型时值会被缓存但环不乱切（由 `s_op_mode` 决定装配哪条环）。

## 四、联锁与安全设计

| 项 | 行为 |
|---|---|
| 自动先封锁再切 | 收到给定且已在别的环 → 自动 D 封锁 → 装配新环，避免 ISR 里两环 s_en 同开竞态 |
| 同环保活 | 已在目标环 → 只更新给定，不重开 MOE（避免每帧通断冲击）；MIT 每帧续命令超时 |
| 复用既有联锁 | 全部经 `servo_cmd` 的 do_current/do_speed/do_pos/mit_engage，含故障/C 电流标定/Z 电角度/辨识占用/MOE 回读确认，与 ASCII 命令完全同一套 |
| 门卫 | 所有给定经 `app_param`：权限总闸 + NaN/范围检查（iq±5A、w±100rad/s、位置±1256rad、kp 0~5000、kd 0~100），写入被拒不落缓存、不动环 |
| 状态字回读 | 30055 `Statusword` bit[5:3]=**实际在环模式**（0/1/3/4/12）、bit1=故障、bit0=使能；`Modes_of_operation_display`@off44 也是实际模式，切环被拒时显示真实状态而非期望值 |
| MIT 实测位置回读 | 30065 应答 payload[5..8] = `BspServo_GetThetaMulti()` 实测角，供上位机贴当前位置起步 |

### 实测踩坑（已解决，记录备查）

1. **力矩环判定不能只看 `IsCurrentMode()`**：速度环/位置环内部也会起电流环（共同最后一级）。从速度切回力矩时曾被误判"已在力矩环"→ `do_current` 被其速度联锁拒绝→环没切成却回 SUCCESS。已改为 `IsCurrentMode && !IsMit && !IsSpeed && !IsPos` 四重判定。
2. **MIT 目标口径**：见 2.3 节，必须用应答的 p_now 而非 enc_sum 换算值。
3. **上位机收帧**：`FrameParser` 自维护缓冲，直接喂新字节即可；不要手动 `reset_input_buffer()` 或重喂 `parser.buf`，否则截断在途帧导致 CRC 错。

## 七、明确的局限

1. **给定需周期保活**：deadman 2000 ms，上位机停发会自动封锁（设计如此，与 ASCII 一致）；MIT 另有 `SERVO_MIT_CMD_TMO_MS` 帧超时冻结 v/tau。
2. **存参数（Sys_cmd=1）仍是幂等确认**，未真正写 Flash（缺"从当前状态打包 ParamBlob"的函数），沿用首期限制。
3. **MIT 位置口径有门槛**：上位机必须知道绝对位置（从 30065 应答 p_now 读），不像位置模式可直接给相对脉冲；这是阻抗控制贴当前位置起步的固有要求。
4. **文件仍在 Board/ 扁平目录**，未迁到指南的 communication//database/ 目录（避免大改多构建系统）。
5. 30025 的 `idq_tar_A[0]`(id) 忽略——力矩模式 id 给定恒 0，与固件力矩模式设计一致。
