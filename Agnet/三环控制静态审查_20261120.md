## 二、三环节拍与参数

| 环 | 周期 | 分频 | 常量 (file:line) | 增益 |
|---|---|---|---|---|
| 电流环 | 50 µs / 20 kHz | — | `servo_isr.c:276-277` | `Kp=0.5341`、`Ki·Ts=0.12566` |
| 速度环 | 500 µs / 2 kHz | `SERVO_SPD_DIV=10` (`:876`) | `servo_isr.c:874-875` | `Kp=0.5834`、`Ki·Ts=0.04076` |
| 位置环 | 1 ms / 1 kHz | 在速度环执行拍内 | `pos_loop.h:59` | `Kp=100 1/s` |

**频率分离验证**

```
电流环闭环带宽 ≈ 1/(2π·200 µs)      ≈ 800 Hz   （按 5τ 估算，保守 300 Hz）
速度环开环增益  = Kp·Kt/J = 666 rad/s ≈ 106 Hz
位置环带宽      = Kp = 100 rad/s     =  16 Hz
```

- 电流环 / 速度环 ≥ 3 倍（按保守 300 Hz 算也满足）✅
- 速度环 / 位置环 = 6.6 倍 —— 在可用区间，但偏下限。若位置环出现等幅振荡，先把 `Kp` 从 100 降到 60~70。

**零极点抵消（电流环）**

```
Ki/Kp = (0.12566/50µs)/0.5341 = 4705 rad/s
R/L   = 0.400/85e-6          = 4706 rad/s     ← 差 0.02%
```

这条是教科书级的匹配，说明 `L=85 µH` 与 `R=0.4 Ω` 的整定基准是对得上的。

### 加速度前馈的问题（今天机械辨识才发现）

```
物理应为  J/Kt     = 7.67e-5 / 0.088 = 8.72e-4 A/(rad/s²)
现常量    SERVO_FF_ACC_DFLT = 1.72e-3            → 过强 1.97 倍
```

常量注释写的是 `J/Kt×0.7 = 2.3e-4/0.0936×0.7`，即**按 J=2.3e-4 算的**，而实测 J=7.67e-5（4 次辨识均值，与 12:30 独立复现），相差 3 倍。

后果：加速时前馈给出约 2 倍所需 iq，速度环 PI 必须反向拉回 → 加速过冲、减速不足。

**建议**：`]61`（单位 1e-4，即 6.1e-4 = J/Kt×0.7）在线试，对比 0→1000 rpm 的上升时间与超调，再决定改常量。

| 环 | 限幅 | 抗饱和 | 说明 |

**降额路径**：`s_derate` 在 20 kHz 收口处统一乘，四个模式全覆盖（`servo_isr.c:2033-2037`）。

## 五、联锁与状态机

三环的使能不是各自开关，而是由 `s_src` 派生（`servo_isr.c:76-81`）：

```
POS → s_pos_en + s_spd_en + s_cur_en
SPEED → s_spd_en + s_cur_en
TORQUE / MIT → s_cur_en
```

**入口联锁**（所有闭环命令共享）：

| 前置 | 检查点 | 当前值 |
|---|---|---|
| `cal=1` 电流零点 | `do_speed/do_pos/do_current` | ✅ 1（刚做过 C） |
| `z=1` 电角度对齐 | 同上 | ❌ **0 —— 这就是所有动作被拒的原因** |
| `f=0x00` 无故障 | 同上 | ✅ 0 |

**今天补的 NVIC 使能**（`ServoCmd_Init()`）不影响三环，只恢复串口接收。

## 六、待办（按优先级）

1. **【阻塞】转子不转**：功率级已排除（三相电流平衡、和=0、峰值 5.4 A），剩机械抱死或编码器打滑，需手工盘车确认
2. **加速度前馈系数**：`1.72e-3 → 6.1e-4`，用 `]61` 在线验证后再改常量
3. **位置环 Kp**：若出现等幅振荡，100 → 60~70
4. **参数页掉电保护**：每次 `UV4 -f` 都丢标定（`cal/z/psi` 全归零），必须修，否则每次升级固件都要重做 C+Z
5. 速度环带宽复测：现按 J=7.67e-5 算 106 Hz，机械辨识的 J 有 ±18% 单次离散，带宽对应 87~127 Hz——建议用 `(` 扫频复核穿越频率

## 七、局限

- 全部结论来自代码与常量，**没有一条经过本次实机验证**（闭环跑不起来）
- 电流环带宽用的是"5τ"粗估，没有实测阶跃响应
