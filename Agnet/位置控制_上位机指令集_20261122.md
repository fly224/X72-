## 2. 坐标语义（核心）

### 2.1 `p_now` 的定义

```
p_now = 归一化(位置环内部连续位置)  ∈ [0, 2π)
```

- **每帧都归一化**，所以它永远在 `[0, 2π)`；
- 位置环**内部**是连续的（跨圈定位靠它），但对外只给你环内值；
- `p_now` 与 `30090.pos`（单圈机械角，含编码器零点）只差一个**常数**，本机实测 **+0.3007 rad**。

| 量 | 是否归一化 | 用途 |
|---|---|---|
| `p_now` | ✅ | 当前角度，**显示/输入用这个** |
| `p_tgt` / `p_tgt_c` | ✅ | 目标（补偿前/后） |
| `p_ref` | ✅ | 规划位置 |
| **`err`** | ❌ **真实差值**（规划 − 实测） | 判跟随质量、判到位 |
| `travel` | ❌ | 本次行程 \|目标−起点\| |

> `err` 故意不归一化：否则 `−3.14` 的误差会显示成 `+3.14`，看起来像"越走误差越大"。

### 2.2 目标折算规则（`pos_rad` 怎么解释）

**输入落在 `[0, 2π)` 时按"本圈的角"解释**，固件在所有等价点里取**离当前实测最近**的一个：

```
内部目标 = 输入值 + round((当前实测 − 输入值) / 2π) × 2π
```

| 输入 `pos_rad` | 当前 `p_now` | 实际行程 | 结果 |
|---|---|---|---|
| `0.0` | 0.09 | **+0.01 rad**（正向 0.6°） | 停在 ≈0 |
| `0.0` | 2.71 | **−2.71 rad**（反向 155°） | 停在 ≈0 |
| `0.0` | 6.20 | **+0.08 rad**（正向 4.7°） | 停在 ≈0（跨 0 走近路） |
| `3.14` | 0.50 | +2.64 rad | 停在 3.14 |
| `6.0` | 2.71 | −2.99 rad（等价于正向 3.29） | 停在 6.0 |

**三条性质**（都已实测）：
1. 行程必然 **≤ π**，不会出现"输入 0 却反向跑一整圈"；
2. 到位后 `p_now` 可能显示 `6.2815` 而不是 `0.0000`（过冲几个 mrad 落在 0 的负侧）——**环形误差只有 1~2 mrad，不是没到位**；
3. 输入**不在** `[0, 2π)` 时按**绝对位置**处理（`-0.5` → −0.5，`12.0` → 12.0），保留跨圈定位能力。范围 ±1256 rad。

### 2.3 什么时候读 `p_now`

**必须在"切模式 + 使能"之后读**，因为进入位置模式那一刻会重新定基准：

```python
lk.set_mode(1)                       # 30056
lk.set_controlword(0x0F, 0)          # 30054 使能
time.sleep(0.6)
p0 = lk.pos_status()["p_now"]        # ★ 这时读才对
```

在使能**之前**读到的 `p_now` 是上一轮的基准，用它算相对目标会偏。

## 3. 标准下发流程

```python
import time
from mavlink_link import SerialLink

lk = SerialLink()
lk.connect("COM27", 921600)
time.sleep(1.5)
lk.set_permission(0, 0)                       # 30068

# --- 1) 清故障 ---
if lk.ctrl_status()["fault"]:
    lk.action(3)                              # 30069 action=3
    time.sleep(0.5)

# --- 2) 切位置模式并使能（此刻锁在当前位）---
lk.set_mode(1)                                # 30056
time.sleep(0.3)
lk.set_controlword(0x0F, 0)                   # 30054
time.sleep(0.6)

# --- 3) 读基准（必须在使能之后）---
ps = lk.pos_status()
assert ps["st_name"] in ("DONE", "HOLD"), ps     # 起环应立刻稳住
p0 = ps["p_now"]

# --- 4) 定位到目标角（0~2π 语义）---
TARGET = 0.0                                   # 回到本圈 0 点
lk.set_pos_speed(pos_rad=TARGET)
time.sleep(0.05)                               # 先发一次，保活才有有效给定
lk.set_keepalive(True, 1, 10.0)                # ★ mode=1（位置！），deadman=2 s

# --- 5) 等到位 ---
t0 = time.time()
while time.time() - t0 < 3.0:
    ps = lk.pos_status()
    if ps and ps["settled"]:
        break
    time.sleep(0.01)

print(ps["st_name"], ps["p_now"], ps["err"])
```

**顺序不能反的两处**：
1. 切模式 → 使能 → **再**读 `p_now`（基准在使能那刻定）；
2. 先发一次目标 → **再**开保活（否则保活第一次发之前已经有 0.1 s 空窗）。

## 4. 到位判定

**用 `settled`（或 `st_name == "DONE"`），不要自己拿 `p_now` 和 0 比。**

```python
# ✅ 正确
if ps["settled"]: ...

# ✅ 也需要环形差时
def wrap(d):
    while d >  3.141592653589793: d -= 6.283185307179586
    while d < -3.141592653589793: d += 6.283185307179586
    return d

d = wrap(ps["p_now"] - TARGET)      # 真误差，跨 0 也正确
if abs(d) < 0.010: ...              # 10 mrad = 到位窗口

# ❌ 错误：跨 0 时会把 6.2815 判成"差 6.28 rad"
if abs(ps["p_now"] - TARGET) < 0.01: ...
```

`st` 取值：`0 IDLE / 1 MOVE / 2 HOLD / 3 DONE / 4 ERR`。

| 状态 | 含义 |
|---|---|
| `IDLE` | 未使能（或 deadman 已封锁） |
| `MOVE` | 规划在推进 |
| `HOLD` | 规划完成，误差还没进窗口 |
| **`DONE`** | 到位（规划完成 + \|err\|<10 mrad 持续 100 ms） |
| **`ERR`** | 跟随误差超限 → 同时落 `0x0100` 故障 |

## 5. 保活（deadman）

- `30019` 必须**每 ≤2 s 重发一次**，否则输出封锁；
- `set_keepalive(True, mode=1, hz=10)`，**`mode` 必须传 1**（传 3 等于没保活）；
- 重发**同一目标**时固件会忽略（防止跨 π 跳圈）。所以：
  - 想重新定位到**同一个值**：只有在"已 DONE 且被外力推离 > 50 mrad"时才会重新生效，否则请先发一个别的值再发回来。

## 7. 故障与拒绝

| 现象 | 原因 | 处理 |
|---|---|---|
| `0x0100` 位置跟随误差 | 实际落后规划 > 6 rad 持续 100 ms | `action(3)` 清故障；**不会自动续追原目标**，必须重新下发 |
| `30019` 返回 `status=2` | 参数超范围（`pos_rad` 超 ±1256 / 速度超 ±220 rad/s）**或被拒** | 检查范围；被拒原因看 `30090.fault`、`30090.cal`、`30090.z` |
| 下发后没有任何反应 | ① 未使能（`en=0`）② 有故障 ③ 辨识在跑 ④ 目标与上次相同被去重 | 依次查 `30090.en` / `fault` / `30092` / `st` |
| 保活断了 2 s 之后再下发，电机不动 | **修复前**的缺陷：`do_disable` 没关位置环，`s_pos_prev` 残留 1，重使能时跳过了目标重设，同一目标又被去重 | 已修（`Code=107392`）。自检：`travel` 是否为 0 而 `p_tgt` 等于上次值 |
| `st` 一直 `MOVE` 不 DONE | 撞机械限位 / 负载过大 | 看 `err` 是否持续增大 |

> **`30019` 是"只发不等应答"**，`ok=True` 只代表帧发出去了。
> 是否生效看 `30100.st` / `p_tgt` / `30090.en`。

## 8. 常见误用（反面清单）

| ❌ 不要 | 原因 |
|---|---|
| 用 `30090.pos + 30040×k` 拼坐标 | 既差编码器零点，又会因单圈回绕在 0 附近跳 |
| 用 `p_now` 的差值当行程 | 归一化后跨 0 会差 2π，要用环形差 |
| 认为 `p_now` 单调递增 | 每帧归一化，跨 0 会跳回 0 |
| 靠 `pos_rad` 的 `acc` 字段调定位加速度 | **位置模式不吃这个字段**，规划加速度是固件常量 30 rad/s²（`POS_AMAX_DFLT`），该字段只作用于手写速度环 |
| 输入 `6.2832` 当"0" | 恰好 ≥ 2π，会走**绝对位置**语义；本圈请用 `0.0` |
| 使能前读 `p_now` 算目标 | 基准在使能那一刻才定 |
| 拿 `p_now == 0.0000` 判到位 | 过冲会显示 6.2815，用 `settled` 或环形差 |

## 11. 仍存在的限制

1. **跨上电的绝对位置不保持**：`p_now` 的圈数基准来自编码器 raw 0 点，每次上电重新起算。要跨上电示教，需上位机自己维护基准，或用外部限位/挡块回零。
2. **进位置模式会重定基准**：`p_now` 变成当时的单圈角，单圈内示教点稳定，**跨圈的示教点会偏 2π 的整数倍**。
3. **`p_tgt` 显示的是折算后的值**：你输入 6.0、它可能显示 6.0（因为归一化），但内部目标可能是 −0.2832；看 `travel` 才知道真实行程。

## 12. 修正记录（2026-11-22 第二轮复测）

多轮复测又查出三个问题，都已修在 `Code=107392` 里。对上位机的影响只有一条：
**「目标是否真的被接受」现在可以用 `p_tgt` 回读确认**。

### 12.1 `p_tgt` 恒等于你下发的值（新性质）

因为折算后的目标与输入值只差 `2π` 的整数倍，归一化后又回到输入值：

| 你下发 | 内部目标 | `p_tgt` 回读 |
|---|---|---|
| `0.0`（当前 6.20） | `6.2832` | **`0.0000`** |
| `6.20`（当前 0.09） | `−0.0832` | **`6.2000`** |
| `3.1416` | `3.1416` | **`3.1416`** |

所以：**下发后读一次 `p_tgt`，等于你发的值就说明目标已被接受**；真实行程看 `travel`。

### 12.2 修掉的三个问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | **`do_disable` 漏关位置环**：deadman/故障封锁后 `s_pos_prev` 残留 1，重新下发时跳过对齐与目标重设，同一目标又被去重 → **电机不动**（实测 `travel=0.0005`） | `do_disable` 补 `Servo_SetPosMode(0U, 0.0f)` |
| 2 | 使能/重起环后未清去重锁存，紧接着的同一目标会被忽略 | `Servo_SetPosMode` 的 enable 分支复位 `s_pos_cmd_last`，并同步 `s_pos_tgt_last = 当前位置` |
| 3 | 圈基准用 `roundf(now/2π)×2π` 时，输入 6.0 且实测越过 2π 一点会白走一圈 | 改为取最近等效点 `tgt = 输入 + round((now−输入)/2π)×2π`，行程必 ≤ π |
