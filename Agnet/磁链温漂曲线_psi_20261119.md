# ψ（磁链）温度漂移曲线 —— 实测报告

测试日期：2026-11-19　设备：STM32G474 X72 FOC + MT6835 21 bit 编码器
辨识通道：ASCII `+`（FluxIdent ψ/R/L 联合辨识）　转速：1000 rpm（加热段）

---

## 结论摘要

| 项目 | 结果 |
|---|---|
| **α_ψ（磁链温度系数）** | **−0.1197 %/K**（加热段 −0.1190 / 冷却段 −0.1203，两段差 1.1%） |
| ψ20（外推 20 °C） | 4.390 mWb |
| Kt20 = 1.5·p·ψ20 | **0.0922 N·m/A**（固件现值 0.0910，差 1.3%） |
| 与钕铁硼理论对比 | 理论 −0.11 %/K，实测 −0.12 %/K，比值 1.09 |
| 单次辨识重复性 | ψ：CV **0.048%**，3σ 等效温差 **1.3 K** |
| NTC 热滞后 | **0.54 ~ 2.04 K**（峰值在 48 °C），升温偏低、降温偏高 |
| 工程影响 | 20→50 °C（30 K）温升，**Kt 下降 3.6%**，同 iq 力矩少 3.6% |

**一句话**：ψ 随温度单调下降，系数 **−0.12 %/K**，与钕铁硼永磁的物理特性吻合；两段独立测量（升温 15 点、降温 10 点）斜率一致到 1.1%，结论可信。真正的误差源不是 ψ 本身，而是 **NTC 与绕组之间 0.5~2 K 的热滞后**。

---

## 一、为什么用 `+` 而不是 `@`

| 通道 | 触发 | 前置条件 | 原理 | 重复性（实测） |
|---|---|---|---|---|
| `@` RlIdent | ASCII `@` | D 状态、静止 | 单点 2 A 注入，V/I 求 R、阶跃求 L | R: CV **2.04%** |
| `+` FluxIdent | ASCII `+` | D 状态、**需转动** | 两转速 × id 扫描（0/−1/−2/−3 A），多点回归解 R/L/ψ | ψ: CV **0.048%**，R: CV **0.071%** |

`+` 的 ψ 重复性比 `@` 的 R 好 **42 倍**，原因是它用多点回归且反电势项 ωe·ψ 在 1000 rpm 时高达 6.35 V，信噪比极高。

**先决条件（已在该板验证）**：`+` 必须在 D 状态启动（`servo_cmd.c:2246`），内部自己拉起速度环跑 1000→300 rpm、注入 id 序列，约 9~12 s，结束封 MOE。它**绕过 `do_speed` 直接调 `Servo_SetSpeedMode + PwmEnable`**（`motor_flux_ident.c:345-350`），不设 `s_armed`，因此辨识期间 deadman 不递减（`servo_cmd.c:2775` 在 `s_armed=0` 直接 return），**不需要保活**。

## 二、重复性验证（决定实验可行性）

43 °C 附近连续 5 次 `+` 辨识：

|---|---|---|---|---|
| 1 | 4.275 | 341.30 | 89.51 | 42.46 |
| 2 | 4.275 | 340.81 | 89.96 | 42.85 |
| 3 | 4.272 | 340.81 | 89.78 | 43.01 |
| 4 | 4.271 | 340.55 | 89.02 | 43.24 |
| 5 | 4.270 | 340.84 | 89.12 | 43.24 |

| 量 | 均值 | σ | CV | 极差 | SEM |
|---|---|---|---|---|---|
| ψ | 4.2726 mWb | 0.0021 | **0.048%** | 0.117% | 0.0009 |
| R | 340.86 mΩ | 0.243 | **0.071%** | 0.220% | 0.109 |
| L | 89.48 µH | 0.364 | 0.407% | 1.051% | 0.163 |

**判读**：ψ 单点 3σ 噪声 0.145%，等效温差 1.3 K；而 ψ 温漂约 0.11 %/K，因此每个温度点**单次辨识即可**，无需多次平均。

## 三、ψ(T) 实测曲线

### 3.1 加热段（1000 rpm 恒速，15 点，44.80→50.33 °C）

```
ψ(T) = 4.48977 − 0.0052193·T  mWb     R² = 0.9907
α_ψ = −0.1190 %/K
ψ20 = 4.3854 mWb    Kt20 = 0.09209 N·m/A
```

### 3.2 冷却段（封锁自然冷却，10 点，50.23→41.04 °C）

```
ψ(T) = 4.50061 − 0.005288·T  mWb      R² = 0.9805
α_ψ = −0.1203 %/K
ψ20 = 4.3948 mWb    Kt20 = 0.09229 N·m/A
```

### 3.3 两段对比

| 项 | 加热段 | 冷却段 | 差 |
|---|---|---|---|
| 斜率 b (mWb/K) | −0.005219 | −0.005288 | **1.3%** |
| α_ψ (%/K) | −0.1190 | −0.1203 | **1.1%** |
| ψ20 (mWb) | 4.3854 | 4.3948 | 0.21% |
| R² | 0.9907 | 0.9805 | — |

**斜率一致、截距错开** —— 这正是热滞后的特征：ψ(T) 的真实关系是唯一的，但 NTC 读数在升温时偏低、降温时偏高，导致两条线平移而不改变斜率。

**因此 α_ψ 取两段平均 = −0.1197 %/K。** 若把 25 点直接合并，斜率会被拉陡到 −0.136 %/K（迟滞被误当成非线性），这是错误的处理方式。

## 四、NTC 热滞后定量

在重叠温区按各自拟合线插值，同温度下 ψ 的差值折算成温度：

| NTC 温度 | 加热 ψ | 冷却 ψ | 差值 | 折合温度差 |
|---|---|---|---|---|
| 45 °C | 4.2564 | 4.2630 | +0.0066 | 1.25 K |
| 46 °C | 4.2487 | 4.2581 | +0.0095 | 1.79 K |
| 47 °C | 4.2440 | 4.2545 | +0.0105 | 1.99 K |
| 48 °C | 4.2392 | 4.2499 | +0.0108 | **2.04 K** |
| 49 °C | 4.2334 | 4.2421 | +0.0087 | 1.65 K |
| 50 °C | 4.2294 | 4.2323 | +0.0029 | 0.54 K |

- 滞后在 **47~48 °C 最大（约 2.0 K）**，此时升温速率约 0.2 K/min、降温速率约 0.6 K/min，热流最大。
- 两端小（45 °C 1.25 K、50 °C 0.54 K），因为端点附近温度变化慢，热流小。
- 机理：NTC 贴在定子/散热器上（`bsp_servo.h:110-113`），与绕组铜之间有热阻，稳态时差值是常数偏移、不影响斜率；但温度变化时产生附加滞后。

**这不是 ψ 的问题，而是测温的问题。** 若要做 0.01 %/K 级别的精确标定，需改用准稳态法（每点恒温 ≥ 5τ）或直接测绕组电阻反推温度。

## 五、与钕铁硼理论对比

| 项 | 数值 |
|---|---|
| 实测 α_ψ | −0.1197 %/K |
| 钕铁硼典型（N35~N42，20~100 °C） | −0.11 ~ −0.13 %/K |
| 比值 | 1.09（在材料分散带内） |

结论：**实测值与钕铁硼永磁的物理特性一致**，ψ 的下降就是磁钢退磁，不是测量假象。

作为交叉验证：ψ20 外推值 4.390 mWb 与固件记录的实测标定值 4.333 mWb（`servo_isr.c:194`）相差 **1.3%**，而外推距离 20~25 K，这个偏差量级合理。

## 六、工程含义：Kt 与力矩精度

```
Kt(T) = 1.5 · p · ψ(T) = 21 · ψ(mWb) / 1000
Kt20  = 0.0922 N·m/A
Kt(50 °C) = Kt20 × (1 − 0.001197 × 30) = 0.0922 × 0.964 = 0.0889 N·m/A
```

| 温度 | ψ (mWb) | Kt (N·m/A) | 相对 20 °C |
|---|---|---|---|
| 20 °C | 4.390 | 0.0922 | 100.0% |
| 30 °C | 4.338 | 0.0911 | 98.8% |
| 40 °C | 4.285 | 0.0900 | 97.6% |
| 50 °C | 4.232 | 0.0889 | **96.4%** |
| 80 °C | 4.075 | 0.0856 | 92.8% |

**影响面**：

| 环节 | 是否受影响 | 说明 |
|---|---|---|
| 速度/位置环稳态精度 | **否** | 环路用 iq 闭环，Kt 只影响"多少 iq 出多少力矩"，不影响转速 |
| 力矩模式（给定 iq） | 否 | 用户直接给 iq，Kt 只影响实际输出力矩 |
| **MIT 模式（给定 τ）** | **是** | `iq = τ/Kt`，50 °C 时同样 τ 需要多给 3.7% iq；不补则出力少 3.6% |
| **力矩显示 `Servo_GetTorqueEst()`** | **是** | 固件固定用 0.0910：20 °C 显示偏低 1.3%，50 °C 显示偏高 2.4%（0.0910 恰好是这段区间的中值） |
| 加速度前馈 J/Kt | 是 | Kt 偏小 → 前馈偏大 3.7%，被速度环 PI 吸收 |
| 惯量辨识结果 J | 是 | 用 Kt 换算，高温辨识会把 J 算小约 3.6% |

### 是否要补偿

**看应用精度要求**：

- 若是**力控/装配/拖动示教**（MIT 模式给 τ）：建议补，3.6% 在力控里可感知。
- 若是**位置/速度伺服**：不需要，环路本身不受影响。
- 若只是**显示力矩**：建议补，否则高温读数系统性偏高。

最小实现（不动现有控制律，只改力矩换算）：

```c
/* 1 ms 任务里由电机 NTC 更新，20 kHz 只读 */
#define KT_ALPHA_PER_K   (-0.001197f)      /* 实测 α_ψ，取 -0.12 %/K */
static volatile float s_kt_comp = 1.0f;

void Servo_UpdateKtComp(float t_mot_c)
{
    float k;
    if (t_mot_c != t_mot_c) { return; }     /* NaN：NTC 故障时保持原值 */
    k = 1.0f + KT_ALPHA_PER_K * (t_mot_c - 20.0f);
    /* 限幅 ±10%：防止 NTC 野值把力矩换算带飞 */
    if (k < 0.90f) { k = 0.90f; }
    if (k > 1.10f) { k = 1.10f; }
    s_kt_comp = k;
}

/* MIT 的 τ→iq 换算处 */
iq_ref = tau / (SERVO_KT_NM_PER_A * s_kt_comp);
/* 力矩显示处 */
tau_est = SERVO_KT_NM_PER_A * s_kt_comp * iq_now;
```

风险：`s_kt_comp` 引入后，同一 τ 在不同温度下会给不同 iq，**MIT 的刚度和阻尼手感会随温度轻微变化**（因为 kp/kd 也经 Kt 换算）。若做这个补偿，必须重新验证 MIT 在冷/热两态的阶跃响应。

## 七、顺带发现：R 的两个辨识通道不一致

同温度下两个通道给出的 R 差异显著：

| 温度 | `@` RlIdent | `+` FluxIdent | 差 |
|---|---|---|---|
| ~50 °C | 324.11 mΩ（51.08 °C） | 347.65 mΩ（50.33 °C） | **+7.3%** |

对应温度系数也矛盾：`@` 给 +0.543 %/K，`+` 给 +0.335 %/K。

猜测原因：两者对**逆变器导通压降**的处理不同——`@` 单点注入可能补偿了死区/管压降，`+` 的多点回归把 GaN 的 Rds(on) 一并算进斜率。这解释了为什么 `+` 的 R 更高、温度系数更低（GaN 的 α 比铜小）。

**结论：R 的两个通道不能混用**，同一份报告里的 R 必须注明来自哪个通道。ψ 则不受影响（它只依赖反电势项 ωe·ψ，与压降补偿无关），这也是 ψ 的重复性能做到 0.048% 的原因。

## 八、局限

1. **温度区间只有 41~50 °C**（受空载发热能力限制）。外推到 20 °C 的 ψ20 有约 1.3% 不确定度；α_ψ 是局部斜率，受外推影响小（<1.5%）。
2. **NTC 热滞后 0.5~2.0 K** 未修正，使 α 有约 ±0.01 %/K 的不确定度（≈8%）。
3. **未做带载测试**：空载 iq 仅 0.39 A，绕组铜损 0.07 W，几乎不发热；带载时绕组温度会显著高于 NTC，滞后会更大。
4. `+` 每次辨识会注入 id 3 A 共约 9 s，局部发热约 0.4 K，对相邻温度点有轻微影响。
5. 钕铁硼的 α 本身随温度略变（低温段更负），本区间（41~50 °C）内近似线性（R²=0.98~0.99）。
