# 5/7 次谐波电流抑制：实现与验证

> 2026-11-16 · X72 / STM32G474CEU6 · 固件 `Code=70512` 级，0 Error 0 Warning
> 命令：`%` 开关、`&` 采 20 kHz 波形

## 1. 结论

**算法有效，但当前的主要噪声源不是 5/7 次谐波。**

500 rpm 实测（1024 点 @20 kHz，DFT）：

| 状态 | 6 次脉动 @700 Hz |
|---|---|
| OFF | 0.01316 A |
| **ON** | **0.00362 A** |
| OFF（复测） | 0.00609 A |

相对 OFF 的较小值仍降 **40.5%**，相对较大值降 **72.5%**。但 OFF 两次之间自己就差 2 倍（0.0132 vs 0.0061），单次 51 ms 记录的谱估计方差很大，所以只能定性说"有效"，不能给出精确抑制比。

**但频谱里最大的峰根本不在 700 Hz**：

| 频率 | 幅值（OFF） | 对应次数 |
|---|---|---|
| **117 Hz** | **0.14567 A** | **基波（500 rpm × 14 / 60 = 116.7 Hz）** |
| 195 Hz | 0.08869 A | 1.67 次（非整数倍） |
| 78 Hz | 0.04388 A | 0.67 次 |
| 59 Hz | 0.04155 A | 0.5 次 |
| 234 Hz | 0.03546 A | 2 次 |

**iq 上有一个与基波同频的 0.146 A 脉动**，比 6 次谐波大 11 倍。这不是 5/7 次谐波能解决的问题——它来自电角度误差的**周期性成分**（编码器偏心、零点标定残差、或转子磁路不对称），每一转出现一次，所以频率等于基波。

这件事的意义：装好 5/7 次抑制之后，转矩脉动的主要矛盾转移到了基波偏心误差上。要压它得先测量编码器每转的角度误差曲线（MT6835 有自校准功能，或用外力匀速拖动做查表），而不是再加谐波抑制。

## 2. 原理

5 次（负序）和 7 次（正序）相电流谐波，在**静止 αβ 系**里分别是 5ωe / 7ωe 的正弦量；但变到**基波 dq 系**之后，两者都折叠成同一个 **6ωe** 的脉动——这就是 iq 上 6 次转矩脉动的来源（14 极对、500 rpm 时 700 Hz）。

抑制思路不是"提取 6 次再反推"，而是 **MSRF（多同步旋转坐标系）**：

```
实测 iα/iβ
  ├─ Park(−5θe) ─→ id5/iq5 ─→ PI ─→ InvPark(−5θe) ─→ vα5/vβ5
  └─ Park(+7θe) ─→ id7/iq7 ─→ PI ─→ InvPark(+7θe) ─→ vα7/vβ7
                                                    ↓
                        vα = vα_基波 + vα5 + vα7（vβ 同理）→ SVPWM
```

在 −5θe 与 +7θe 坐标系里，目标谐波变成**直流量**，用普通 PI 就能无静差压到 0。

**为什么不用谐振控制器（PR/VPI）**：
- 谐振器的中心频率必须等于 6ωe，变速时要重算系数；
- 离散化在 4 kHz 以上有频率畸变（3000 rpm 时 6ωe = 4.2 kHz），需要预畸变；
- MSRF 用 θe 的倍数做坐标变换，频率天然跟随转速，无离散化问题。

代价：每拍多 4 次 `sinf/cosf` + 2 组 PI，约 600 cycle（20 kHz 预算 8500）。

## 3. 实现要点

### 3.1 符号（踩过，代价是一次过流）

```c
/* 目标是让这些分量归零，所以 PI 要输出"抵消"电压 */
const float e5d = -id5;      // ← 不是 +id5
```

第一版写成 `+id5`，等于正反馈：谐波越大、补偿越大、谐波更大。实测直接触发过流保护（`f=0x01`，峰值 **16.6 A**）并封锁 MOE。**这个错误在空载低速时可能表现为"抖动但不跳闸"，必须靠带载或高速才能暴露。**

### 3.2 电角度先折回 [0,2π)

`th_e` 最大约 90 rad，直接乘 5/7 之后到 600 rad 量级，`sinf` 的参数归约会损失有效位：

```c
const float thw = th_e - BSP_TWO_PI * (float)(int32_t)(th_e * 0.159154943f);
```

### 3.3 积分限幅 0.15·vbus

谐波补偿是"锦上添花"，绝不能把电压预算吃光——主环还要压基波，高速段 BEMF 已经占了大部分。

### 3.4 叠加后二次限幅

主环在 dq 域已限到 `0.5375·vbus`，谐波补偿叠加到 αβ 后可能把它顶出 SVPWM 线性区。顶出去会削顶 → **产生新的低次谐波**，等于白干。所以叠加后按圆限幅再缩一次。

### 3.5 关掉必须清积分

否则下次开起来会带着上次的残留量冲击。

## 4. 验证方法：为什么必须片内 20 kHz 记录

100 Hz 遥测完全不够：

- 6 次脉动频率 = `6 × rpm/60 × 14` = **1.4·rpm [Hz]**
- 30 rpm → 42 Hz，已经贴着 50 Hz 的 Nyquist
- 500 rpm → 700 Hz，直接混叠
- 实测 30 rpm 下 OFF 两次测得 0.0209 与 0.0434 A，差 2 倍，**无法判读**

所以加了 `&` 命令：在 20 kHz 节拍里直接采实测 iq，1024 点 = 51 ms，分辨率 19.5 Hz、覆盖 0~10 kHz。int16 缩放 131（±250 A 不溢出），经 ASCII hex 逐行送出（43 行，约 70 ms）。

**这个记录功能本身也有个坑**：连续两次调用时，第二次会被上一轮残留的 `REC end` 提前终止，返回 0 点。必须在发命令前 `reset_input_buffer()`。

## 5. 命令

| 键 | 作用 |
|---|---|
| `%` | 5/7 次谐波抑制开关（回显 `harm ON/OFF h5=d/q h7=d/q`，是压完后的残余量） |
| `&` | 采 1024 点 iq（20 kHz，51 ms），逐行 hex 输出，末尾 `[CMD] REC end` |

要求：`%` 要在闭环里开（补偿叠加在电流环输出上）；`&` 要有输出（MOE=1）。

## 6. 参数

| 项 | 值 | 说明 |
|---|---|---|
| Kp | 0.10 V/A | 约为基波 Kp(0.713) 的 1/7 |
| Ki·Ts | 0.004 | 每拍积分增量 |
| 积分限幅 | 0.15·vbus | 约 4.6 V @30.7 V |

只测了 500 rpm 一个工况，这两组参数没做过系统性整定。Kp 再大可能在高速段与主环抢相位裕度。

## 7. 局限

| 项 | 现状 |
|---|---|
| **主要脉动不是 5/7 次** | 117 Hz（基波）处 0.146 A，是 6 次谐波的 11 倍，来自电角度周期性误差 |
| 单次记录方差大 | 51 ms 窗口，OFF 两次差 2 倍；要做定量结论需多次平均或加长记录 |
| 只测一个转速 | 500 rpm。变速段（尤其 6ωe 接近 4 kHz 时）未验证 |
| Ld/Lq 未分离 | 表贴式假设下 Ld=Lq，5/7 次只按平均电感压 |
| 参数未整定 | Kp/Ki 是保守估值，未做稳定性边界扫描 |
| 只抑制电流谐波 | 反电势本身的 5/7 次仍会产生转矩脉动，要从电机设计或前馈补偿解决 |

## 8. 下一步建议（按收益排序）

1. **编码器偏心标定** —— 117 Hz 的 0.146 A 是目前最大的一笔。MT6835 支持内部自校准（写 EEPROM 的校准寄存器），或用外力匀速拖动 + 记录 θ_meas − θ_ideal 做查表补偿。收益比谐波抑制大一个数量级。
2. **谐波抑制参数整定** —— 扫 Kp/Ki，在稳定边界内取最大抑制比。
3. **多转速验证** —— 500 / 1000 / 1500 rpm 三点，确认 6ωe 跟踪正确。

## 12. 2026-11-21 更正：117 Hz 不是编码器偏心

第 8 节把 117 Hz 的 0.146 A 归为"编码器偏心"，并用它论证"编码器标定收益比谐波抑制大一个数量级"。实测推翻了这个判断：

- 500 rpm 下 117 Hz 正好是 **14×机械频率 = 1×电频率**；偏心（磁钢中心与旋转中心不重合）的特征频率应是 1×机械（8.3 Hz），对不上。
- 用 vd 积分反推角度误差，确实测到 14 阶 1.14° 的分量；但把角度补偿到 0.23° 之后，**117 Hz 的 iq 纹波没有下降**（0.126 → 0.141 A）。
- 若这 1.14° 是真实的机械角误差，测速会纹波 28%（500 rpm 下 140 rpm），而实测转速标准差只有 0.41%。

结论：117 Hz 是**转矩/磁场谐波**（每电周期一次的磁钢不对称），不是编码器角度误差。正确对策是 **14 阶 iq 谐波注入**（与 5/7 次抑制同类），不是编码器标定。

详见 `编码器角度软件补偿_三方案实测对比_20261121.md`。
