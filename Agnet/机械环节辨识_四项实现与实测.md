## 1. 谐振扫频（`(`）

### 做法

iq 给正弦（无直流分量，平均转矩为 0，不会一直加速），扫 20–1000 Hz 共 11 点，每个频点**整周期**累加做同步解调：

```
Σv·sin = A·N/2·cosφ      Σv·cos = A·N/2·sinφ
→ 幅度 = 2√(vc²+vs²)/N   相位 = atan2(vc, vs) − 2π·f·Ts
```

不录波形再 FFT——激励频率是自己产生的，基波参考已知，单点 DFT 就够，省掉 1024 点存储和传输。

### 实测（幅值 0.2 A）

| 频率 Hz | 增益 rad/s per A | 相位 ° |
|---|---|---|
| 20.00 | 25.52 | −38.5 |
| 29.58 | 13.55 | −67.3 |
| 43.73 | 7.59 | −81.1 |
| 64.67 | 4.15 | −93.7 |
| 95.64 | 2.37 | −102.3 |
| 141.42 | 1.31 | −117.7 |
| 209.13 | 0.59 | −144.9 |
| 457.31 | 0.038 | +161.5 |
| 676.24 | 0.0004 | 67.1 |
| 1000.00 | 0.0022 | 139.0 |

**结论：20–300 Hz 内没有谐振峰**，增益单调按 1/f 下降，相位平滑下降。

60–100 Hz 附近相位穿过 −90°（纯惯性的特征），说明**在速度环带宽（3 Hz）到 200 Hz 之间，机械表现为刚性单惯量**。这意味着 **3 Hz 的带宽不是被机械谐振限制的**，而是被调速器本身或测速噪声限制的——还有很大提升空间。

高频段（>400 Hz）增益掉到 0.04 以下，**不是真实响应，是测量灵敏度不足**：速度响应只有 0.01 rad/s 量级，低于单拍差分的量化噪声（±0.06 rad/s）。要覆盖这一段需要：加大高频激励（但低频会进入摩擦/齿隙非线性）、或提高测速分辨率（多拍差分，代价是带宽）。

## 2. 折算惯量（`<`）

### 做法

两个转矩幅值（1 A / 2 A），各自从静止加速，测跨过 `w1=1 → w2=6 rad/s` 的时间：

```
t1、t2 分别对应 (T1−Tf) 和 (T2−Tf) 的加速时间
T2−T1 = J·Δw·(1/t2 − 1/t1)   →   J = (T2−T1) / (Δw·(1/t2−1/t1))
```

**摩擦项 Tf 被两式相减消掉**，不需要先知道摩擦。`T = 1.5·p·ψ·iq`，ψ 用实测 4.455 mWb（Kt=0.0936）。

### 实测

```
[MI] IG J=0.5323e-4 acc=1098.90/2857.14 tq=0.0936/0.1872
```

- 1 A 时加速度 1098.9 rad/s²，2 A 时 2857.1 rad/s²
- **J = 5.32e-5 kg·m²**

### 这个数说明什么

之前由"8x 增益最优"反推的 `J≈2.3e-4` **偏大 4.3 倍**。用 5.32e-5 重算速度环：

```
Kp = J·wc²/(Kt·|1+j·wc/ωz|)  →  同样 Kp=0.583 时带宽约 13 Hz，而不是 3 Hz
```

也就是说当前速度环**远没有用满机械能力**。加速度前馈的 `J/Kt×0.7` 现在可以改成 `5.32e-5/0.0936 = 5.68e-4`（当前是 1.72e-3，偏大 3 倍）。

⚠ **J 与 ψ 成正比**：J 是用 `Kt=0.0936` 算的，如果 ψ 有 41% 偏差，J 也偏 41%。这是单编码器方案的固有局限，只能靠"外力拖动测反电势"来独立校准 ψ。

## 3. 摩擦曲线（`)`）

### 做法

8 个转速点（1/2/3/6/12/30/80/200 rpm），每点速度环稳定 3 s、平均 500 ms 的 iq，最后线性回归 `iq = a + b·w`。

### 实测（两次）

| rpm | 第一次 iq | 第二次 iq |
|---|---|---|
| 1 | 0.0931 | −0.0266 |
| 2 | 0.1891 | −0.0307 |
| 3 | 0.4992 | −0.1366 |
| 6 | 0.1188 | 0.0241 |
| 12 | 0.0698 | 0.0718 |
| 30 | 0.1288 | 0.1394 |
| 80 | 0.1478 | 0.1506 |

**30 rpm 以上很稳（0.129–0.151 A），12 rpm 以下抖得厉害，甚至出现负值。**

### 为什么抖

1 rpm 时速度环的积分器在正负之间慢摆（这正是 3 rpm 超调 68.8% 的同一个病根）——稳态 iq 的瞬时值本来就在 ±0.1 A 量级跳动，3 s 稳定 + 500 ms 平均仍不够把慢摆平均掉。

**要改进**：低速段每个点等 5 s 以上，或者改用电流模式（给恒定 iq 等速度自然稳定，此时 iq 就是摩擦，不经过积分器）。

### 有用的结论

30–80 rpm 段：`iq ≈ 0.13–0.15 A`，与之前 `$` 两点标定的 0.30 A **差了 2 倍**。

这说明**当前的摩擦前馈幅值 0.32 A 可能偏大一倍**。不过 3 rpm 的起动确实需要 0.64 A（静摩擦），所以"稳态 0.15 + 起动助推 0.32"这个组合是合理的——只是稳态分量应该调到 0.15 左右。

## 4. 齿槽转矩（`}`）

### 做法

速度环 10 rpm 匀速，20 kHz 采样 `(θ_multi, iq)`，按机械角分 128 箱累加平均，转满一圈收集。输出 128 点后做 DFT——**128 点正好对应 1 机械圈，所以 bin k 就是第 k 阶**。

### 实测

```
箱数 128，iq 范围 -0.40 … 0.63 A
峰峰值 1.0268 A
主要阶次：
  24 阶  0.3298 A
  28 阶  0.1817 A
  56 阶  0.0439 A
  14 阶  0.0336 A
  48 阶  0.0184 A
```

### 这个结果很重要

- **24 阶 = 12 槽 × 2**，**28 阶 = 2 × 14 极对** —— 都是典型的齿槽/磁路不对称阶次
- **峰峰 1.03 A（0.096 N·m）**
- 对比：30 rpm 稳态运行电流只有 0.13–0.15 A

**齿槽转矩的幅值是低速运行电流的 7 倍。** 这就是低速段抖动、3 rpm 超调的直接来源——电流环在 0.1 A 量级做精细调节时，齿槽正在施加 ±0.5 A 的周期性扰动。

**改进方向**：齿槽前馈（按角度查表补偿），把这张 128 点表直接存进 Flash，运行中按 `θ_multi` 查表加到 iq_ref 上。这是低速平稳性最直接的手段。

## 5. 实现过程中踩的 6 个坑

| 1 | `_1` 偶尔不启动（走了查询分支） | 引导字符与数字在同一批 Poll 里，字节偶尔丢失 | 改用 4 个独立字符 `( ) < }` |
| 2 | 相位低频显示 +156°（应 −90°） | `atan2(vs, vc)` 参数顺序反了 | 改成 `atan2(vc, vs)` |

## 6. 局限

1. **谐振只在 20–300 Hz 有效**。>400 Hz 的响应低于量化噪声，测不到。要覆盖需要更高分辨率的角度差分或角度域重采样。
2. **低速摩擦数据不可信**。1–12 rpm 的 iq 被速度环慢摆污染，甚至出现负值。要改进得用电流模式或更长窗口。
3. **J 与 ψ 强耦合**。ψ 的 41% 不确定性直接传成 J 的不确定性。单编码器无法独立校准 ψ。
4. **齿槽只测了单向**。摩擦与齿槽在单向测量里混在一起（摩擦是常值偏置，齿槽是周期分量，DFT 能分开，但更严谨应该正反各测一遍取平均）。
5. **减速比/背隙/扭转刚度仍未测** —— 需要输出端编码器，单编码器原理上不可观测。

## 7. 下一步建议

按收益排序：

1. **用 J=5.32e-5 重算速度环** —— 带宽可以从 3 Hz 提到 10–13 Hz，这是所有低速问题的总收益
2. **齿槽前馈** —— 128 点表存 Flash，按角度查表，直接把 1 A 峰峰压掉大半
3. **摩擦前馈幅值从 0.32 调到 0.15** —— 稳态分量按 30–80 rpm 的实测值来
4. 改进扫频高频灵敏度（如果要找 300 Hz 以上的谐振）
