结论先行

已从三环闭环仿真模型中提取纯控制律，用 ert.tlc + ARM Compatible->ARM Cortex-M 生成自包含 ANSI C，直接落到指定的 simulink_code_gen 目录。生成代码实际编译通过， 并用 host SIL 与 Simulink 部署模型逐拍比对 3000 个 50 µs 采样点，最大占空比误差 6.20e-12；三环累计执行次数 3000 / 300 / 150，证明 20 kHz / 2 kHz / 1 kHz 的执行频率在生成代码里真实成立，而不只是模型注释。

裸机集成只需两步：three_loop_deploy_initialize() 上电调一次， three_loop_deploy_step() 由 TIM1 20 kHz 更新中断调用。 目录内已给出 integration_example.c（ADC / MT6835 / CCR 标定模板）与 README 集成步骤。

1. 生成边界：仿真模型 → 部署模型

为什么改成单速率：仿真模型用显式 1 ms / 500 µs / 50 µs 三个 SystemSampleTime + Rate Transition， 适合验证环时序；但 ERT 面向裸机时，单 ISR 更确定、无需 RTOS 调度，也避开多速率代码生成的历史问题。 位置/速度环在各自 chart 内用计数器分频并 ZOH 保持输出，积分步长仍分别用 1 ms / 500 µs，与仿真完全一致。

5. 集成到 FM_Servo_V3 / X72_FOC 工程

  1. 把 6 个生成文件（three_loop_deploy.c/.h、three_loop_deploy_private.h、three_loop_deploy_types.h、rtwtypes.h、rtmodel.h）加入 Keil MDK-ARM 工程（..\embedded_project\STM32G474_App\MDK-ARM）并加入 Include Path；只有 three_loop_deploy.c 一个 C 文件。不要加入 sil_test.c（含 main）与 ert_main.c（示例 main）。
  2. 上电调用 three_loop_deploy_initialize()；TIM1 中心对齐 20 kHz（PSC=0, ARR=4249 @170 MHz，以 X72_FOC.ioc 为准），ADC 由 TIM1_TRGO 触发。
  3. 按 integration_example.c 实现 BSP_ADC_*、BSP_MT6835_ReadRaw21()、BSP_TIM1_SetDuty()： 电流 I = (ADC_V − 1.65)/0.03（约 0.0269 A/LSB），角度 2π·code/2^21，速度差分 50 µs + 低通。
  4. 标定编码器零点偏置：控制器内部固定 +π/2 对齐；VBUS_DIV 按 VM 分压电阻实际比值填写（示例暂置 1.0，TODO）。
  5. pos_ref 为机械角 rad；21 bit 单圈编码器若跨多圈，需在 BSP 侧累积圈数并保持与 theta_m 同坐标系。
  6. 过流/过压/编码器异常时拉低 en 并封锁 PWM；用 Y.ticks 与 Y.iq_ref 做在线诊断。
编译选项：Keil AC6 --cpu Cortex-M4.fp.sp + C99 + O2；或 arm-none-eabi-gcc -mcpu=cortex-m4 -mfpu=fpv4-sp-d16 -mfloat-abi=hard -O2 -std=c99。

6. 局限与待办（按优先级）

① 数据类型仍是 double（最重要的性能待办）：ERT 默认 real_T = double， 而 Cortex-M4F 的 FPU 只支持单精度，sin/cos/sqrt 双精度会走软件库。20 kHz ISR 在 170 MHz 下约 8500 个周期， 实机请先用 DWT->CYCCNT 实测 step() 周期数再决定是否上电运行。 若超限，把三个 chart 的 persistent/输出初值改为 single(0)、Inport 与 Constant 设 OutDataTypeStr='single' 后重新 codegen，生成代码即变为 real32_T + sinf/cosf。
  • ② 未做 ARM 目标编译、链接与实机 DWT 周期测量（本机无交叉编译器）；host SIL 只证明语法与数值逻辑。
  • ③ 两个宏语义待确认：PMSM_PN=14 按极对数、Kt=225.5 mN·m/A 按每 RMS 相电流；改动需重新生成代码。
  • ④ 未建模死区、管压降、母线纹波、ADC/编码器量化、齿槽转矩、弱磁与轨迹规划；Y.duty 未做死区补偿。
  • ⑤ 48 V / 2000 rpm 电压校核是解析边界（额定点需求 23.87 V / 上限 26.33 V），部署代码未实现弱磁；满速区需额外验证。
  • ⑥ integration_example.c 是接线模板，BSP 函数与故障保护需按现有固件补齐；VBUS_DIV 为 TODO。
