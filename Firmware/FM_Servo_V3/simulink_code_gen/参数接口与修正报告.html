5. 整定公式（参数怎么设）

电流环（IMC / 极点抵消）
  wc   = kp_i / Ld = 0.7131415 / 113.5e-6 = 6283 rad/s ≈ 1000 Hz
  零点 = ki_i / kp_i = 3334.8 rad/s = R/L (0.3785Ω / 113.5µH)
  => 改 kp_i 必须同步 ki_i = kp_i × 3334.8；带宽降到 500Hz: kp_i=0.3566, ki_i=1189.1

速度环 / 位置环
  kp_w = (2ζ·ww·J − B)/Kt,  ki_w = ww²·J/Kt   (ζ=0.9, ww=2π·40)
  kp_p ≈ 2π·f_p                                (f_p=8 Hz -> 50.265)
  f_p ≲ f_w/5，否则级联失稳

推荐顺序：en=0 → 电流环（Kp 后同步 Ki）→ 速度环（空载→带载）→ 位置环（小→大阶跃）； 每步 ParamGet 回读确认，满意后由 database 保存 Flash。使能态写入会被拒 （WRITE_STATE_ERROR），越界 / NaN / 未知 ID / 只读项分别返回对应状态码。

7. 局限与后续

① 必须重测 DWT 周期数：参数改 Inport 后编译器不再能常量折叠， step() 多了数组读取与 par_c[9]==3 一类运行时分支。原实测 9282 cyc / 54.6%， 新版本需在实机重新量一次，确认仍 < 100 µs。
  • ② 根本解法仍是 single 化回 20 kHz（文档 §6.2，实测 1813 cyc）。届时把 Ts_i 改回 50e-6， dt/N_w/N_p/gain_comp 自动跟回，可调参数默认值无需改动。
  • ③ 协议层尚未落地：database/ 为空，set/get_app_* 仍是契约；参数 ID 0x01–0x08 需同步进 MAVLink 消息表与上位机字段表。
  • ④ 位置模式仍限 ±π；大范围绝对定位需按文档 §6.3 增加多圈 theta_pos 输入。
  • ⑤ 低速测速量化（§6.4）、电流环带宽实测（§6.5）未解决；未建模死区/弱磁/量化。
  • ⑥ 生成代码仍是 real_T = double（M4F 单精度 FPU）。
