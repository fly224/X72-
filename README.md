# X72

用于搭建双足机器人的关节模组控制代码和上位机程序，上位机通讯协议 MAVLink V2。

STM32G474 谐波关节模组的嵌入式固件：三环 FOC + 四种控制模式，调试走 MAVLink v2，
总线走 CAN FD。

- **固件**：`Firmware/FM_Servo_V3`（app / motor_control / communication / board_public 分层，26 个模块，约 1.7 万行）
- **硬件资料**：`Hardware/Netlist`（PG_X72_CAN 网表、引脚映射、核对报告）
- **上位机与工具**：`Agnet`（下发脚本、频谱分析、工程文档）

当前版本：**v1.1.0**（2026-11-27）。变更历史见 [CHANGELOG.md](CHANGELOG.md)，
版本号与发布规则见 [docs/版本管理规范.md](docs/版本管理规范.md)。

## 硬件平台

| 项 | 规格 |
|---|---|
| MCU | STM32G474CEUx，Cortex-M4F，170 MHz |
| 逆变 | 三相，20 kHz 中心对齐（TIM1，ARR=4250），死区 294 ns |
| 电流采样 | 双电阻：U 相（OPA1/ADC1）、W 相（OPA2/ADC2），V 相由 Iu+Iw 重构 |
| 编码器 | MT6835 磁编，2²¹ counts/rev（1 count = 3.0 µrad） |
| 电机 | 14 极对 PMSM，减速比 9:1 |
| 母线 | 设计 48 V（当前台架实测 30.8 V） |
| 通信 | USART1 @921600（MAVLink）、FDCAN1（CAN FD，SIT1042 收发器） |
| 安全 | IWDG 250 ms；无硬件 STO、无抱闸驱动 |

## 控制架构

三个闭环全部在 20 kHz 电流环 ISR 内按分频推进，**位置环与速度环严格同拍**：

| 环 | 周期 | 频率 | 说明 |
|---|---|---|---|
| 电流环 | 50 µs | 20 kHz | dq 双 PI + 解耦 + 圆限幅，与 PWM 同拍 |
| 速度环 | 500 µs | 2 kHz | `SERVO_SPD_DIV = 10`，含加速度前馈、增益调度、陷波 |
| 位置环 | 500 µs | 2 kHz | 与速度环同拍串级；每拍都算会让规划快 10 倍、末端过冲 |

四种运行模式（`APP_OP_MODE_*`）：

| 模式 | 号 | 语义 | 给定来源 |
|---|---|---|---|
| POS | 1 | 梯形/S 曲线规划 + 纯 P 位置环 | 30019 `pos_tar_p` |
| VEL | 3 | 速度闭环 + 斜坡 | 30019 `speed_tar_p_s` |
| TORQUE | 4 | 电流闭环，iq 直接给 | 30025 / 30095 |
| MIT | 12 | 阻抗：`τ = kp·(p_des−p) + kd·(v_des−v) + τ_ff` | 30065 / 30066 |

### 上位机接口（MAVLink v2）

非标准消息号（30000 段）。`crc_extra` 与长度在 `mavlink_common.c` 的 `s_meta[]` 登记，
**新增接收方向消息必须同步登记，否则 `crc_extra=0` → 静默丢帧**。

| 类别 | 消息 |
|---|---|
| 命令 | 30054 控制字、30056 模式、30068 权限、30069 系统动作 |
| 给定 | 30019 位置/速度、30025 电流、30065/30066 MIT、30095 力矩 id |
| 遥测 | 30090 控制状态（100 Hz）、30091 环路状态（100 Hz）、30100 位置环状态、30040 位置传感器 |
| 事件 | 30092 辨识结果、30093 齿槽表回读、30094 录波 |
| 配置 | 30082 运行时调参（16f+16u32+16i32）、30096 陷波、30097 速度轨迹、30098 编码器补偿 |

ASCII 单字符调试通道已于 2026-11-21 全量删除（省 12.2 KB；且两个通道曾各自演化出
不一致的切环保护）。

### 总线接口（CAN FD）

L1 协议按 `Agnet/X72关节模组_CANFD协议_工程落地_v1.1.html` 实现：

| 帧 | ID | 长度 | 周期 | 状态 |
|---|---|---|---|---|
| CMD_AGG | `0x100` | 64 B（5 槽 × q/dq/tau） | 1 ms | ✅ 解析 + 下发 |
| FB_MOTION | `0x200+n` | 24 B | 1 ms | ✅ 组帧发送 |
| FB_DIAG | `0x300+n` | 48 B | 20 ms | ✅ |
| HEARTBEAT | `0x380+n` | 8 B | 100 ms | ✅ |
| SYNC | `0x080` | 16 B | — | ✅ 计数 |

- 位定时：内核时钟 85 MHz（PCLK1 170 ÷ 2），Prescaler 5/1，17 TQ，**1 Mbit/s + 5 Mbit/s（BRS）**
- TDC：`TDCO=22`（按实测 `PSR.TDCV` 修正，不能凭经验设 13）
- 失效安全：连续 10 ms 无有效 CMD_AGG → 先阻尼（MIT 下 kp=0、kd=0.5），再 50 ms → 断使能
- bus-off 自动恢复：**必须由软件清 `CCCR.INIT`**，硬件才会走 128×11 隐性位恢复
- 主站缺席时只发 1 Hz 心跳，避免无人 ACK 导致多节点集体刷错误帧

### 保护

`bsp_servo.h` 的 11 个故障位，任一置位即封锁输出：

| 位 | 故障 | 判据要点 |
|---|---|---|
| 0 | 过流 | 双电阻瞬时值，20 ms 开通消隐 |
| 1 | 编码器 | 帧内容坏 / 跳变，两条路径分开计数 |
| 2 | ADC 同步 | 注入序列失步 |
| 3 | BSP 初始化 | |
| 4 | SPI | MT6835 通信 |
| 5 | 超速 | `1.5·|v_des| + 30` rad/s，按实测判减速而非按给定 |
| 6 | 母线过压 | 错接电源 / 回馈泵升 |
| 7 | 母线欠压 | 仅在本级输出使能时判 |
| 8 | 跟随误差 | 位置环误差 > 6 rad |
| 9 | 缺相 | 某相实测无电流 |
| 10 | 电流采样异常 | 零点不在中点 / 两相差过大 |

### 诊断

- **录波**（30094）：1024 点，`div` 可配（`div=1` → 20 kHz），通道 iq / 相电流+电角度 / vq 积分 / d 轴积分+机械角
- **齿槽表回读**（30093）：512 箱分 64 块，带回零点一致性校验
- **运行时调参**（30082）：16 float 增益 + 16 int 开关，掩码写入、回读真值
- **`PSR.LEC` 锁存**：1 ms 采样，区分 ACK / 位填充 / 位 / CRC 错误

### 构建

`bsp_servo.h` 的 `PROD_BUILD`：

| 值 | 构建 | Code | 说明 |
|---|---|---|---|
| 0 | 开发 | ≈114 KB | 含自环 / PING / ECHO / 寄存器快照 / 辨识故障注入 |
| 1 | 生产 | **111124** | 测试支架整块预处理掉；测试入口保留符号但直接拒绝 |

生产构建的尺寸口径（map 文件 `Grand Totals`）：`Code=111124 RO=3350 RW=2240 ZI=27564`。
测试支架约占 3 KB。

生产构建会在 `main.c` 输出 `#warning`，**因此 UV4 退出码为 1 —— 判成败要 grep `0 Error(s)`，
不能看 `$?`**。

## 编译与烧录

Keil MDK 5.43 / ARMCLANG V6.24。`TMP` 必须指向可写目录 —— 默认的 `C:\Windows\TEMP`
不可写会导致 UV4 直接失败：

```bash
export TMP=C:/Users/<you>/AppData/Local/Temp

# 增量编译
UV4.exe -b X72_FOC.uvprojx -j0 -o build.log
# 全量重建（改了 .uvprojx 或头文件依赖时用）
UV4.exe -r X72_FOC.uvprojx -j0 -o build.log
# 烧录
UV4.exe -f X72_FOC.uvprojx -j0 -o flash.log
```

> `-f` 有概率擦参数页（丢 cal / z / ψ / 齿槽表）。烧完先读 30090 的 `flags`，
> bit0(CAL)、bit1(ZERO)、bit7(COG) 三位齐全才算没丢。

## 安全起环顺序

任何模式起环前确认：`30090` 的 `fault = 0` 且 `flags` 含 CAL|ZERO。

**MIT**（最容易炸，必须按此顺序）：

```
30068 权限 → 30056 模式=12 → 查 flags/fault
→ 30066 {kp=0, kd=0.05}      零刚度，绝对安全
→ 30065 {p=0}                 起环，从应答里取 p_now
→ 30065 {p=p_now}             贴住当前位置
→ 30066 {kp=30, kd=0.05}      上刚度
→ 循环 30065 @200~500 Hz      必须有轨迹，不能给绝对阶跃
```

`kp=30` 配 J=5.47e-5 时，**15 mrad 误差就顶满 5 A**。目标必须是相对当前位置的偏移，
不能用界面显示的单圈角，也不能用 30040 的累计计数（缺上电首拍基准角，差整数圈）。

速度 / 力矩给定有 **2 s deadman**，必须周期保活；停止用 `30054 {halt=1}`。

## 已知限制与未完成项

按影响排序，均为实测或代码审计确认，不是推测：

1. **CAN FD 双节点不通**。单节点内部回环 1 kHz 零丢帧零错误（1 Mbit/s 与 5 Mbit/s 均通过），
   两个节点实测分别报 `LEC=ACK` 与 `LEC=CRC`。已排除位定时、TDC、轮询取帧、
   收发器供电与 TXD 走线（网表核对）；待查线束端接与总线模拟层。
2. **5/7 次谐波抑制不可用**。实测开启后 6 次频率处自激（交流 RMS 0.36 → 3.33 A，
   主峰 134 Hz / 4.31 A），而基线 6 次成分仅 1.3%（0.005 A）。
   `harm_kp/harm_ki` 没有 30082 槽位，无法在线整定。
3. **齿槽前馈只补掉 23.7%**。同一转速下关 0.609 A / 开 0.465 A，反推相位差约 42°。
   表本身正确（幅值与关断实测吻合），问题在 phase 标定或运行时相位。
4. **编码器自校准（^）失败（chip_status=2）**。转速（pp 0.14%）、区间（AUTO_CAL_FREQ=0x03）、
   磁场强度（STATUS=0）均已排除，芯片在 CAL_EN 拉高后约 1.7 s 即判失败；定位为硬件磁铁
   安装问题（AG 间隙 1.0~3.0 mm / Bpk 磁场 30~1000 mT / 偏心 ≤0.3 mm 超 MT6835 手册范围）。
   软件侧已无可调项；软件谐波补偿（30098）可部分替代，2 次/转谐波 −50~65%。
5. **`30000 READ_PARAM` 读不到应答**（46 B / 192 B 请求都不回），写入类 30082 正常。
   影响上位机"读参数表"，不影响盲写。
6. **CiA402 只做了状态字映射**（`can_cia402_sw`），八态机与控制字语义未实现。
7. **减速比是编译常量**。`ParamBlob` 已 64 B 满，加字段须升 `PS_VERSION`，
   会把现场已标定的零点 / 齿槽表 / ψ 全部作废。
8. **无多圈掉电保持、无硬件 STO、无抱闸驱动**。
9. **CAN 失效安全只覆盖"10 ms 无 CMD_AGG"**，MAVLink 侧仍是 2 s deadman。
